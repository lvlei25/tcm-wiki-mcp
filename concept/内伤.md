# 内伤

> **类型**：病因 / 病机（与外伤相对）
> **语料频次**：内伤 134 / 饥饱劳役 3 / 劳倦 21 / 房劳 13
> **分布**：丁甘仁医案（鉴别用）、傅青主男科与女科（病因论）、参西录
> **主要出处**：《傅青主男科》《傅青主女科·产后》《丁甘仁医案》
> **相对**：[[外感]]
> **相关**：[[病因]]、[[脾失健运]]、[[气血]]

## 一、概念界定

内伤指**由七情、饮食、劳倦、房劳等因素引起的疾病**，与外感六淫相对。这是语料中最基本也最常用的二分。

**核心判断**（参西录的表述最完整）：

> **至其内伤外感之辨，谓内伤则短气不足以息，尤为大气下陷之明征。**

**要点**：**内伤以「短气不足以息」为明征**——这是语料中最简洁的内外伤鉴别。

## 二、内外伤的对照

| 鉴别点 | 外感 | 内伤 |
|---|---|---|
| **病因** | 六淫、疫疠 | 七情、饮食、劳倦、房劳 |
| 起病 | 急 | 渐 |
| 表证 | 有（恶寒、发热、无汗、脉浮） | 无 |
| **短气** | 一般无 | **短气不足以息（明征）** |
| 脉象 | 浮紧／浮数 | **右寸脉大于左寸** |
| 治法 | 汗解（疏风散邪） | 补益（补中益气等） |
| 预后 | 邪退则愈 | 慢性调理 |

## 三、原文证据

**（1）脉诊判据**（《傅青主男科》）

> **凡人右寸脉大于左寸，即内伤之症**，不论左右关尺脉何如，以此方投之效验。

**要点**：**右寸（肺位）大于左寸（心位）即内伤**——这是一个可操作的脉诊规则，且语料明确说「不论左右关尺脉何如」，即以右寸/左寸的关系为准。

**（2）不可用一方治内外伤**（《傅青主男科》）

> 凡肝木郁者，此方一剂即快。人病发热，有**内伤外感**，必先**散其邪气，邪退而后补正**，则正不为邪所伤也。但**外感内伤，不可用一方也**，外感发热方见前。

**要点**：**内有外感时须先散邪后补正**，不可一开始就用补法。这是内伤与外感**兼夹**时的处理顺序。

**（3）阳虚下陷由内伤而来**（《傅青主男科·阳虚下陷》）

> 凡人**饥饱劳役，内伤正气**，以致气乃下行，脾胃不能克化，饮食不能运动，往往变为劳瘵。盖疑饮食不进为脾胃之病，肉黍之积，轻则砂仁、枳壳、山查、麦芽之品，重则芒硝、大黄、牵牛巴豆之类，纷然杂进，必致臌闷而渐成劳矣，**若先以升提之药治之，何至于成劳**。

**要点**：**内伤 → 中气下陷 → 劳瘵**的传变链。傅青主强调「若先以升提之药治之，何至于成劳」——即**早期升提可预防发展为劳瘵**。

**（4）产后内伤的特有处理**（《傅青主女科·产后总论》）

> 夫产后**忧、惊、劳、倦，气血暴虚，诸症乘虚易入**。如有气毋专耗散，有食毋专消导；**热不可用芩、连，寒不可用桂、附**；寒则血块停滞，热则新血崩流。

见 [[妇人病]]。

**（5）劳倦伤心脾肝**（《丁甘仁医案·神志案》）

> **曲运神机，劳伤乎心；谋虑过度，劳伤乎肝；持筹握算，劳伤乎脾。**

**要点**：**内伤的「劳」有三种**——劳心（曲运神机）、劳肝（谋虑）、劳脾（持筹握算），对应不同脏腑。见 [[病因]]、[[肝气与肝郁]]。

## 四、内伤的分类

| 类型 | 语料用词 | 频次 | 病机 | 代表 |
|---|---|---|---|---|
| **劳倦** | 劳倦、饥饱劳役 | 21+3 | 中气下陷 | 补中益气汤类 |
| **劳心** | 曲运神机、思想 | — | 心血耗伤 | — |
| **劳肝** | 谋虑过度 | — | 肝阴耗伤 | 柔肝熄风 |
| **房劳** | 房劳、房帏、色欲 | 13+4 | 肾精亏损、冲任损伤 | 滋肾填精 |
| **饮食** | 饮食不节、伤食 | 9 | 脾胃受损、食积 | 保和丸类 |
| **七情** | 七情、郁怒、忧思 | 14+6 | 肝气郁结 | 逍遥散类 |

**要点**：**内伤的共同特点是「先伤脾」或「耗气血」**——因脾为后天之本、气血为生化之源。见 [[脾失健运]]、[[气血]]。

## 五、内伤的诊断路径

```
疑似内伤
  ↓
① 有无表证？（恶寒、发热、无汗、脉浮）
   ├─ 有 → 可能内伤兼外感 → **先散邪，后补正**（傅青主）
   └─ 无 → 继续
      ↓
② 脉象：右寸 > 左寸？
   ├─ 是 → 内伤（语料明征）
   └─ 否 → 考虑其他
      ↓
③ 有无短气不足以息？（参西录明征）
   └─ 有 → 大气下陷可能（见大气下陷）
      ↓
④ 追问内因（须问诊）：
   ├─ 饥饱劳役 → 劳倦 → 中气下陷
   ├─ 忧思郁怒 → 七情 → 肝郁
   ├─ 房事不节 → 房劳 → 肾虚 / 崩漏
   └─ 饮食不节 → 食积 → 脾胃
```

## 六、内伤与内生五邪

**内伤日久可内生五邪**（语料线索）：

| 内因 | 内生之邪 | 语料依据 |
|---|---|---|
| 脾虚失运 | **湿**、痰 | 「脾弱不能为胃行其津液，水谷之湿生痰」 |
| 气虚 | **气陷** | 「阳虚下陷」 |
| 血虚 | **血瘀** | 「血一停滞，气化即不能健运」 |
| 心肝阴伤 | **内风** | 「肝阳内动，化风上扰」 |
| 久病 | **郁、瘀、痰**互结 | 「气阻血痹，与湿热凝聚募原」 |

**要点**：**内伤 → 病理产物 → 二次病机**，这是本语料的一条重要链路。见 [[痰]]、[[血痹]]、[[肝阳与肝风]]。

## 九、使用注意

**「内伤」在语料中含义有两层**：①病因（内因致病）；②病位（中气下陷）。傅青主男科「阳虚下陷」一篇用的是第一层，丁甘仁医案「饥饱劳役」用的是第二层。agent 引用时须按上下文判断。

**内伤与「虚劳」「劳瘵」的关系**：**内伤是因，劳瘵是果**。傅青主明确「饥饱劳役……往往变为劳瘵」，故内伤应及早升提，防止发展为劳瘵。

**内伤与外感可以兼夹**：傅青主明确「人病发热，有内伤外感」，处理原则是**先散邪后补正**。agent 不可见"内伤"就径直用补法。

**「右寸大于左寸」的脉诊规则是傅青主男科的独特表述**，语料说「不论左右关尺脉何如」，即以两寸的对比为准。现代脉诊已少用此规则，agent 宜标注为「古籍脉诊，临床参考」。

**现代内伤概念**（如内环境紊乱、免疫相关疾病）与本条的中医病因学内涵不同，agent 不应直接对应。

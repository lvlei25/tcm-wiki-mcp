# 五官科症状群

> **类型**：症状（聚合条目）
> **语料频次**：舌 748 · 目 889 · 耳 550 · 咽 356 · 喉 530 · 鼻 350 · 牙 198 · 齿 168 · 舌苔 234
> **细分实测**：耳聋 70 · 喉痹 59 · 目昏 34 · 鼻塞 34 · 鼻衄 33 · 咽痛 33 · 目赤 24 · 目痛 20 · 齿痛 21 · 目翳 16 · 鼻渊 16 · 失音 18
> **分布**：**针灸大成**（取穴体系）为主，丁甘仁医案（温病五官受累）为辅
> **主要出处**：《针灸大成》五官病取穴、《丁甘仁医案》温病后期条

## 一、概念界定

五官科在本语料中的分布有个特点：**《针灸大成》管"取穴"，丁甘仁医案管"温病五官受累"**，两条路径的病机判断不同。

## 二、五官与脏腑的对应

《针灸大成·十二经穴主治》对每脏的开窍与特性有完整记载，五脏原文如下：

| 脏 | 开窍 | 华 / 充 | 情志 | 音·数·臭·液 |
|---|---|---|---|---|
| **肝** | **开窍于目**，藏精于肝 | 华在爪，充在筋 | 在志为怒 | 角·八·臊·泣 |
| **心** | **心开窍于舌**，肾脉络舌本，脾脉络舌旁 | — | — | — |
| **脾** | 中央黄色，入通于脾，**开窍于口**，藏精于脾，故病在舌本 | 华在唇四白，充在肉 | — | 宫·五·香·涎 |
| **肺** | 西方白色，入通于肺，**开窍于鼻**，藏精与肺，故病在背 | 华在毛，充在皮 | 在志为忧忧伤肺 | 商·九·腥·涕 |
| **肾** | 北方黑色，入通于肾，**开窍于耳**，藏精于肾 | 华在发，充在骨 | 在志为恐，恐伤肾 | 羽·六·腐·唾 |

**肝经原文**（《针灸大成》）：

> 《内经》曰：『肝者，将军之官，谋虑出焉。』肝者，罢极之本，魂之居也。其华在爪，其充在筋，以生血气……东方青色，入通于肝，**开窍于目，藏精于肝**，故病发惊骇……肝主筋，筋生心，**肝主目**。

**要点**：原文用的是「**肝主目**」与「**开窍于目**」，而「肝开窍于目」这一完整表述在参西录中出现 6 次（多在解释药物归经，如「石决明……**肝开窍于目**，是其性善明目」）。

**心与舌**（丁甘仁医案的实际运用）：

> **心开窍于舌，肾脉络舌本，脾脉络舌旁**，心肾阴亏，虚风内动，挟痰浊上阻廉泉。先哲云∶**舌废不能言，足痿不良行，即是喑痱重症**。

**要点**：舌病从心肾脾三经论，且**络脉归属与开窍说并用**。见 [[心火与痰蒙]]。

**肺与鼻**（参西录的伤寒病因说）：

> 肺主气，**开窍于鼻**，有病则咳，肺伤，所以气少、咳嗽、**鼻鸣**也。

**脾与口**（《针灸大成》）：「脾主四肢，为胃行津液……**开窍于口**，藏精于脾，故病在舌本」。

**耳与肾的临床验证**（参西录）：

> **肝开窍于目，目得血而能视**，肝伤血少，所以其目暗也。

**要点**：目之视物依赖肝血——这是目病的血虚病机依据。

### 五官归属速查

| 官 | 归属 | 语料中的病理表述 |
|---|---|---|
| **目** | 肝（肝主目，肝开窍于目） | 目暗=肝血少；目直=肝风；目赤=肝火；目珠黄=肝胆湿热 |
| **舌** | 心（心开窍于舌）＋肾脉络舌本＋脾脉络舌旁 | 舌强蹇语=心肾阴亏 + 痰阻廉泉 |
| **口** | 脾（开窍于口） | 口疮=心火；口不思纳=脾虚 |
| **鼻** | 肺（肺主气，开窍于鼻） | 鼻鸣=肺伤；鼻衄=热迫血行；鼻渊=鼻部病 |
| **耳** | 肾（开窍于耳） | 耳聋好瞑=热闭；耳聋+腰酸=肾虚 |

## 三、各官症状与病机（语料所见）

### 3.1 咽喉：温病与燥邪

**丁甘仁医案·湿温案四诊**（咽喉干燥属肺阴伤）：

> 咳嗽气逆痰鸣，均已大减，**咽喉干燥，痰内带红，舌边绛**，苔薄黄，神疲肢倦，脉濡小而数，是**肺阴暗伤，痰热未楚**。今拟**清燥救肺**，化痰通络。

**要点**：咽喉干燥 + 舌边绛 + 脉濡小而数 = **肺阴暗伤**（不是热毒），治法清燥救肺而非清热解毒。

**丁甘仁医案·咳嗽案五诊**（燥邪）：

> 咳嗽亦减五六，**咳时喉有燥痒，鼻孔烘热，口干唇燥**，舌苔化而未净，**肺金之风燥，尚未清澈**；余热留恋，**燥字从火，火灼津液为痰**，书所谓**火为痰之本，痰为火之标**也。

**要点**：这是**五官症状与痰的因果链**——燥 → 火灼津液为痰 → 痰阻咽喉（燥痒）。见 [[肺气与痰]]。

### 3.2 鼻：肺的开窍

**鼻衄**（33 次）：

见 entity/衄血.md。《丁甘仁医案》中鼻衄多见于温病热迫血行。

**鼻渊**（16 次）：见 entity/鼻渊.md，属针灸大成取穴体系。

**鼻塞**（34 次）：五书均有，多见于外感。

### 3.3 耳：肾与热病

《针灸大成·刺热论》（《内经》原文）：

> 热病先身重骨痛，**耳聋好瞑**，刺足少阴，病甚为五十九刺。

**要点**：**「耳聋好瞑」是热病的一个特征**——耳聋且好闭目，为热邪闭阻清窍。

**耳聋**（70 次）在本语料中跨越两类：
- **虚证**（肾精不足，如傅青主男科的精滑梦遗案）
- **热闭**（温病邪闭，如上引）

见 [[肾气与肾水]]——肾气与耳的关系。

### 3.4 目：肝与热病

《针灸大成·五脏六腑》（五脏虚实鉴别，兼儿科）：

> 先别五脏，各有所主，次探表里虚实病之由。**肝病主风，实则目直大叫，项急烦闷；虚则咬牙呵欠**，气热则外生，气温则内生。**心病主惊**，实则叫哭，发热饮水而搐，手足动摇；虚则困卧，惊悸不安。**脾病主困**，实则困睡，身热不思乳食；虚则吐泻生风。**肺病主喘**，实则喘乱喘促，有饮水者，不饮水者；虚则哽气长，出气短，喘息。

**要点**：
- **目直大叫**是肝实证（肝风内动）——与丁甘仁医案的「肝阳内动，化风上扰」一致
- **咬牙呵欠**是肝虚——常被忽略的虚证眼征
- 这段原文出自**儿科望诊**（"不思乳食""吐泻生风"），是本库中少数儿科辨证材料，见 [[儿科]]

**目赤 24 / 目痛 20 / 目昏 34 / 目翳 16**，散见三书，多属肝胆火。

### 3.5 舌与齿：心脾肾

**舌**是语料中频次最高（舌 748、舌苔 234）——但这不是"舌病"多，而是**舌诊**普遍使用。舌象见 [[舌脉术语]]。

**齿痛**（21 次）、**齿衄**：多属胃火（胃经入齿龈）。

## 四、五官科的核心病机：燥

**本语料中五官科最突出的病机是「燥」**，且直接与痰相连：

```
燥邪 or 温病耗津
  ↓
津液被灼
  ↓
① 官窍失润 → 咽喉干燥、鼻孔烘热、口干唇燥
  ↓
② 炼液为痰 → 痰阻咽喉（喉燥痒）
  ↓
治法：清燥救肺（不可清热解毒）
```

原文：

> **燥字从火，火灼津液为痰**，有**一分之燥，则一分之痰不能清澈也**。

见 [[肺气与痰]]。

## 五、五官科取穴（《针灸大成》）

《针灸大成》对五官病有系统的取穴体系，**是本语料中最完整的五官治疗部分**。

### 5.1 头面病取穴（《杂病穴法歌》《百症赋》）

> **耳闭须听会而治也，眼痛则合谷以推之。**
>
> 头偏痛：率谷；头顶痛：百会；目盲无精：曲池?（详见 entity/各穴）
>
> 睛明、攒竹、丝竹空、瞳子髎、承泣、四白、迎香、耳门、听宫、听会、颊车、承浆——**五官各有专穴**。

### 5.2 五官与经脉的关系

```
目 → 足少阳胆经（瞳子髎）、足太阳膀胱经（睛明）
耳 → 足少阳胆经（听会、听宫）、手少阳三焦经（耳门）
鼻 → 手阳明大肠经（迎香）
口 → 足阳明胃经（颊车、地仓）
舌 → 足太阴脾经（廉泉）
```

**要点**：**五官病多取手足阳明、少阳经**，与「头面诸阳之会」的判断一致（见 [[脏腑辨证取穴]]）。

### 5.3 五官病的禁忌

见 [[腧穴操作与禁忌]]——禁针穴歌中**攒竹、睛明、丝竹空、承光、临泣、头维、丝竹**等均列，属颜面部浅刺禁忌。

## 六、诊断 agent 的应用要点

### 6.1 五官症状的常见病机归属

| 症状组合 | 病机 | 治法方向 |
|---|---|---|
| **咽喉干燥 + 舌边绛 + 脉濡小** | **肺阴暗伤** | 清燥救肺（**不是**清热解毒） |
| 喉有燥痒 + 鼻孔烘热 + 口干唇燥 | 肺金风燥，炼液为痰 | 清燥化痰 |
| **耳聋好瞑 + 热病** | 热邪闭阻清窍 | 清泄开窍 |
| **耳聋 + 腰酸 + 遗精** | 肾精不足 | 滋肾（见 [[肾气与肾水]]） |
| **目直大叫 + 项急** | 肝风内动 | 平肝息风（见 [[肝阳与肝风]]） |
| **目赤 + 苔黄 + 脉数** | 肝胆火 | 清肝泻火 |
| **鼻衄 + 舌红 + 脉数** | 热迫血行 | 清凉止血 |
| **口疮 + 心烦 + 舌红** | 心火上炎 | 清心泻火（见 [[心火与痰蒙]]） |
| **齿痛 + 齿龈红肿** | 胃火 | 清胃泻火 |

### 6.2 关键鉴别：热毒 vs 燥邪

**这是五官科最重要的误判点**。丁甘仁医案明确区分：

| | 热毒（实热） | 燥邪（津伤） |
|---|---|---|
| 咽喉 | 红肿疼痛 | **干燥**（不肿不痛） |
| 舌 | 苔黄厚 | **舌边绛、苔薄** |
| 脉 | 数而有力 | **濡小而数**（重按无力） |
| 治法 | 清热解毒 | **清燥救肺** |
| 方药 | 银花、连翘、板蓝根 | 沙参、麦冬、桑叶、枇杷叶 |

**要点**：误把燥邪当热毒，用苦寒攻伐会进一步伤阴。这是温病中后期的常见错误。

### 6.3 五官科在语料中的局限

**丁甘仁医案中的五官症状多为温病后期**，属「余邪未清 + 阴液已伤」。而五官本身的独立病证（如鼻渊、喉痹、目翳）主要来自针灸大成的**取穴体系**，缺乏内科辨证的详细论述。

**因此 agent 处理五官病时应分两条路**：
- 温病背景下的五官症状 → 判燥邪/津伤，用清燥救肺
- 独立五官病证（鼻渊、喉痹、目翳）→ 查 entity/ 对应病名与针灸取穴

## 八、使用注意

**「舌」的高频是舌诊不是舌病**：舌 748 次、舌苔 234 次，但几乎全是诊察记录（「舌红」「苔腻」），不是舌部病证。agent 不应把「舌」当作症状检索。

**五官科在语料中偏「针刺主治」，轻「内治辨证」**：《针灸大成》给的是"某穴主某病"，丁甘仁给的是温病中的五官受累，两者不能直接合并成辨证体系。

**喉痧与白喉是温病专科**：见 entity/喉痧、白喉。丁甘仁医案中属「温毒」而非普通咽喉病，须与一般咽痛鉴别——见 [[病名鉴别]]。

**耳聋须分虚实**：本语料中「耳聋」既用于热病闭窍（针灸大成《内经》引文），也用于肾虚（傅青主男科），还有中风后遗（丁甘仁类中案）。agent 必须先辨虚实。

**现代五官科疾病（结膜炎、中耳炎、鼻窦炎等）不在语料范围**：本库只记载传统五官辨证与取穴，agent 不应将古籍证型直接对应现代病名。

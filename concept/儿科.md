# 儿科

> **类型**：专科辨证（小儿）
> **语料频次**：小儿 235 · 惊风 61 · 啼 38 · 囟门 24 · 孩 26 · 疳（含于各病名）
> **分布**：**《针灸大成》卷十「保婴神术（按摩经）」与「小儿门」为主**，其余三书极少
> **主要出处**：《针灸大成·保婴神术》《针灸大成·小儿门》《针灸大成·雷火针法；蒸脐治病法》

## 一、本库的儿科语料特点（重要）

**儿科内容高度集中于《针灸大成》**，且有两个特点：

1. **治疗以灸法与推拿为主**，方药极少（这与三傅一录以方药为主恰好相反）
2. **有独立的辨证纲领**——《保婴神术》开篇即立「要诀」

《针灸大成》儿科相关篇目：

| 篇目 | 内容 |
|---|---|
| **保婴神术（按摩经）** | 儿科辨证纲领 + 推拿手法歌 |
| **小儿门** | 灸法主治条目（五痫、惊风、疳、杂证） |
| **雷火针法；蒸脐治病法** | 脐疗（灯火灸、神阙） |
| 治小儿诸惊推揉等法 | 惊风推拿 |
| 小儿针 | 小儿针法 |

**要点**：本库的儿科知识**不能与温病医案类比**——丁甘仁、傅青主、参西录基本不涉儿科，agent 处理儿科病例时须回到针灸大成体系。

## 二、儿科辨证纲领（《保婴神术》原文）

> **夫小儿之疾，并无七情所干，不在肝经，则在脾经；不在脾经，则在肝经，其疾多在肝、脾两脏，此要诀也。**

**这是本库儿科辨证的总纲**，与成人体质论有本质差异：

| | 成儿 | 小儿 |
|---|---|---|
| 病因 | 五志七情 + 六淫 + 饮食劳倦 | **无七情**，病多在肝脾 |
| 病理 | 五脏并重 | **肝、脾两脏为主** |

**要点**：小儿"无七情"是本条的核心判断——这直接决定了儿科**情志致病**的辨治不适用。

## 三、急惊风与慢惊风 ★核心鉴别

《保婴神术》对两种惊风有完整的病因病机与鉴别：

### 3.1 急惊风（实证，肝木）

> **急惊风属肝木，风邪有余之症，治宜清凉苦寒，泻气化痰。** 其候或**闻木声而惊，或遇禽兽驴马之吼**，以致**面青口噤**，或声嘶啼哭而厥。发过则容色如常，良久复作，其身热面赤，因引口鼻中气热，**大便赤黄色，惺惺不睡**。盖**热甚则生痰，痰盛则生风**，偶因惊而发耳。内服**镇惊清痰**之剂，外用**掐揉按穴**之法，无有不愈之理。

**急惊风特征**：

| 指征 | 表现 |
|---|---|
| 病机 | **热甚生痰 → 痰盛生风**（痰为本，风为标） |
| 诱因 | **闻声而惊**（惊为诱因，非病本） |
| 面色 | **面青** |
| 身热 | 身热面赤、**大便赤黄色** |
| 神志 | 惺惺不睡（**躁动**） |
| 治法 | **清凉苦寒、泻气化痰** |
| 转归 | 发过后容色如常，良久复作（**可反复**） |

### 3.2 慢惊风（虚证，脾土）

> 至于**慢惊，属脾土中气不足之症，治宜中和，用甘温补中之剂**。其候多因**饮食不节，损伤脾胃，以泻泄日久，中气太虚**，而致发搐，**发则无休止**，其**身冷面黄，不渴，口鼻中气寒，大小便青白，昏睡露睛，目上视，手足瘈疭，筋脉拘挛**。盖**脾虚则生风，风盛则筋急**，俗名天吊风者，即此候也。**宜补中为主**，仍以掐揉按穴之法，细心运用，**可保十全**矣。

**慢惊风特征**：

| 指征 | 表现 |
|---|---|
| 病机 | **脾虚则生风，风盛则筋急** |
| 病因 | 饮食不节 → 泻泄日久 → 中气太虚 |
| **寒热** | **身冷、不渴、口鼻中气寒、大小便青白**（**全部为寒象**） |
| 面色 | **面黄** |
| 神志 | **昏睡露睛**（**嗜睡**，与急惊的躁动相反） |
| 抽搐 | **发则无休止**（急惊则发过后如常） |
| 治法 | **甘温补中** |
| 预后 | 「可保十全」 |

### 3.3 急慢惊风的鉴别要点 ★

| 鉴别点 | 急惊风 | 慢惊风 |
|---|---|---|
| **脏** | 肝木 | **脾土** |
| **虚实** | **实证**（风邪有余） | **虚证**（中气不足） |
| **寒热** | **热**（身热面赤、大便赤黄） | **寒**（身冷不渴、大便青白） |
| **神志** | 躁动（惺惺不睡） | **嗜睡**（昏睡露睛） |
| **抽搐频率** | 发过后如常，良久复作 | **无休止** |
| **治法** | 清凉苦寒、**泻气化痰** | **甘温补中** |
| **预后** | 易治 | 危重（「可保十全」已属乐观） |

**要点**：**寒热与虚实是鉴别核心**——急惊身热面赤属实热，慢惊身冷面黄属虚寒。这与成儿科别（肝风内动）的处理截然不同，agent 须严格按此表判断。

### 3.4 慢惊的预防（治未病实例）

> 又有**吐泻未成慢惊者，急用健脾养胃之剂**，外以手法按掐对症经穴，脉络调和，**庶不致变慢惊风也**。

**要点**：吐泻阶段即须健脾养胃防其发展为慢惊——这是明确的**治未病**表述。

## 四、推拿手法（小儿推拿）

《保婴神术·手法歌》按脏腑给出手法：

> **心经有热作痰迷，天河水过作洪池；肝经有病儿多闷，推动脾土病即除。**
>
> 脾经有病食不进，推动脾土效必应；
> 肺经受风咳嗽多，即在肺经久按摩。
> 肾经有病小便涩，推动肾水即救得；
> 小肠有病气来攻，板门横门推可通。
> 胆经有病口作苦，好将妙法推脾土；
> 大肠有病泄泻多，脾土大肠久搓摩。
> 膀胱有病作淋疴，肾水八卦运天河；
> 胃经有病呕逆多，脾土肺经推即和。
> 三焦有病寒热魔，天河过水莫蹉跎。
> 命门有病元气亏，脾上大肠八卦推。

**推拿的三条规律**：

1. **多推脾土**——脾经病、肝经病、胆经病、大肠病都推脾土
2. **肾水/天河水为通用**——肾、膀胱、三焦病皆用
3. **虚证用补（脾上、大肠八卦推），实证用泻（天河水过）**

**要点**：与成儿用药"虚则补其母"一致，小儿推拿也遵循**脾为后天之本**的判断。

**歌诀中的具体手法**（见 entity/ 各穴）：

- **天河水**——清心热（心经有热作痰迷）
- **板门、横门**——通小肠
- **三关**——见 entity/三关
- **八卦**——顺逆辨虚实

**儿科灸法的三个特点**：

1. **多取百会**——夜啼、囟门不合、脱肛、赤游风都用百会
2. **小儿艾炷特小**——「炷如小麦大」，因小儿皮薄
3. **多用奇穴与经验穴**——顶上旋毛、耳后青络、大指次指间后一寸五分等

## 六、蒸脐疗法（儿科特色）

《针灸大成》有「雷火针法；**蒸脐治病法**」专篇。

**代表用法**：

> **囟门不合**：脐上、脐下各五分，二穴各三壮，**灸疮未发，囟门先合**。

> 卒患腹痛，肚皮青黑：灸**脐四边各半寸**、**鸠尾骨下一寸**，三壮。

> 惊痫：顶上旋毛中（灸三壮），**耳后青络**（灸三壮，炷如小麦大）。

**要点**：**脐疗是本库儿科最具特色的治法**——神阙、脐周、鸠尾构成一个以脐为中心的灸法体系，用于腹痛、囟门不合、惊痫等。

**「灸疮未发，囟门先合」是判断疗效的客观标准**——这在儿科治疗中尤为重要，因为小儿不能主诉。

## 七、五脏虚实的儿科望诊（《针灸大成·五脏六腑》）

除惊风外，《针灸大成》还给出五脏在小儿的虚实表现：

> 面**青**眼青肝之病，面**赤**心之病，面**黄**脾之病，面**白**肺之病，面**黑**肾之病。先别五脏，各有所主，次探表里虚实病之由。

> **肝病主风**，实则**目直大叫，项急烦闷**；虚则**咬牙呵欠**，气热则外生，气温则内生。
>
> **心病主惊**，实则**叫哭，发热饮水而抽搐**，手足动摇；虚则**困卧，惊悸不安**。
>
> **脾病主困**，实则**困睡，身热不思乳食**；虚则**吐泻生风**。
>
> **肺病主喘**，实则**喘乱喘促**，有饮水者，不饮水者；虚则**哽气长，出气短，喘息**。
>
> **肾病主虚无实**，目无精光，畏明，体骨重，痘疹黑陷。

**儿科望诊三招**：

1. **面色**——青（肝）赤（心）黄（脾）白（肺）黑（肾）
2. **行为**——咬牙呵欠（肝虚）、困卧惊悸（心虚）、困睡不乳（脾实）、吐泻生风（脾虚）、哽气长出气短（肺虚）
3. **目**——目无精光、畏明 = 肾虚（肾病主虚无实）

### 7.1 预后判断——五色定吉凶（原文）

> **五位色白者**，肺气不实，滑泄吐利；**五位色黑者，脏腑欲绝，为疾危。**

> 以上之症，更当别其虚实症候。假如肺病，又见肝症，**咬牙多呵欠者易治，肝虚不能胜肺故也**。若**目直大叫哭，项急烦闷难治**。盖肺久病则虚冷，**肝强实而胜肺**也。视病之虚实，**虚则补其母，实则泻其子**也。

**要点（儿科预后判断，本库少见的完整论述）**：

| 表现 | 预后 | 病机 |
|---|---|---|
| **色白** | 滑泄吐利（较重） | 肺气不实 |
| **色黑** | **脏腑欲绝，为疾危**（最危） | 肾气将绝 |
| 咬牙多呵欠 | **易治** | 肝虚不能胜肺（**虚胜虚**） |
| **目直大叫哭、项急烦闷** | **难治** | 肝强实而胜肺（**实胜虚**） |

**核心判断规则**：**虚胜虚者为顺，实胜虚者为逆**。这是五脏生克在预后判断中的应用。

**要点**：**预后好坏取决于「谁胜谁」而非「病多重」**。咬牙呵欠（肝虚）看着是虚象反而易治；目直大叫（肝实）看着是实证反而难治。这是儿科与成儿科别最大的判断逻辑。

### 7.2 论色歌——望诊要点

《针灸大成·论色歌》：

> **眼内赤者心实热，淡红色者虚之说；青者肝热浅淡虚；黄者脾热无他说；白面混者肺热侵；目无精光肾虚诀。**
>
> 儿子人中青，多因果子生；色若人中紫，果食积为痞。人中现黄色，宿乳蓄胃成。
>
> **龙角青筋起，皆因四足惊**；若然虎角黑，水扑是其形。**赤色印堂上，其惊必是人**；**眉间赤黑紫，急救莫沉吟**。**红赤眉毛下，分明死不生。**

**要点**：
1. **五色主心肝脾肺肾**——青（肝热或肝虚，淡则虚）、赤（心实热，淡红则虚）、黄（脾热）、白（肺热）、目无精光（肾虚）
2. **人中色主病源**——青（惊）、紫（食积成痞）、黄（宿乳积胃）
3. **预后警示**——**眉间赤黑紫，急救莫沉吟；红赤眉毛下，分明死不生**（这是明确的危重征象）

### 7.3 认筋法歌——小儿指纹诊断 ★

**这是本库中唯一的儿科指纹（食指络脉）诊断记载**，也是儿科最具特色的诊法。

原文（《针灸大成·认筋法歌》）：

> **囟门八字甚非常，筋透三关命必亡。**
> 初关乍入或进退，次部相侵亦何妨。
> **赤筋只是因膈食，筋青端被水风伤，筋连大指是阴症，筋若生花定不祥**（此有祸祟之筋）。
> **筋带悬针主吐泻，筋纹关外命难当。**
> 四肢痰染腹膨胀，吐乳却因乳食伤。
> 鱼口鸦声并气急，犬吠人諕自惊张，诸风惊症宜推早，如若推迟命必亡。

**指纹的三关与预后**：

| 指纹表现 | 判断 |
|---|---|
| **筋透三关**（透关射甲） | **命必亡**（最危） |
| 初关乍入或进退 | 可治（病浅） |
| 次部相侵 | 可治（病稍深） |
| **筋纹关外** | **命难当** |
| 囟门八字 | 甚非吉兆 |

**指纹颜色主病因**：

| 指纹色 | 病因 |
|---|---|
| **赤筋** | **膈食**（饮食积滞） |
| **筋青** | **水风**（水湿/惊风） |
| **筋连大指** | **阴症** |
| **筋若生花** | **不祥**（有祸祟之筋） |
| 筋带悬针 | **吐泻** |

**要点**：**指纹的三关深度比颜色更重要**——「筋透三关命必亡」是硬性预后指标。agent 处理小儿病例时若见到指纹透关，应立即提示危重。

**配套的望诊（原文续）**：

> 鱼口鸦声并气急，犬吠人諕自惊张。

即**鱼口（口形如鱼）、鸦声（声音嘶哑）、气急、犬吠声**皆为惊风危征，见 [[心火与痰蒙]]的癫狂鉴别。

### 7.4 鼻梁观筋——指纹的时相预后

《针灸大成》除指纹（食指）外，还述**鼻梁上筋**的观察：

> **凡看鼻梁上筋，直插天心一世惊。** 初生时，**一关有白，谨防三朝**；**二关有白，谨防五日之内**；**三关有白，谨防一年之外**。
>
> **凡筋在坎上者即死，坎下者三年。** 又有**四季本色**之筋，虽有无害。
>
> **青者是风，白者是水，红者是热，赤者乳食所伤。**

**鼻梁观筋的两条判断**：

| 判据 | 含义 |
|---|---|
| **筋在坎上** | **即死** |
| **筋在坎下** | 三年（久病） |
| 四季本色之筋 | 无害（正常） |

**白筋的时相预后（关键）**：

| 位置 | 发病时间 |
|---|---|
| 初生时**一关**有白 | **三朝**（3 天内） |
| **二关**有白 | **五日之内** |
| **三关**有白 | **一年之外** |

**颜色主病因**：

| 色 | 病因 |
|---|---|
| **青** | **风** |
| **白** | **水** |
| **红** | **热** |
| **赤** | **乳食所伤** |

**要点**：这是**按筋的位置预测发病时间**的特殊诊法，与食指指纹的三关深度判断不同（一个看时间，一个看轻重）。

## 八、惊风的急救处理（推拿与灸法）

《针灸大成》给出急慢惊风的**急救方案**：

> **凡慢惊将危，不能言，先灸三阴交，二泥丸，三颊车，四少商，五少海穴**，看病势大小，或三壮、五壮、一壮、至七七壮，辨男女左右，十有十活。
>
> 如**急惊、天吊惊**，**掐手上青筋，煅脐上下，掐两耳，又掐总心穴**。
>
> **内吊惊，掐天心穴。慢惊不省人事，亦掐总心穴。急惊如死，掐两手筋。**
>
> **眼闭，瞳子髎泻。牙关紧，颊车泻。口眼俱闭，迎香泻。**

**慢惊急救的灸穴顺序**（原文明确次序）：
1. **三阴交** 2. **泥丸**（泥丸宫，见下注） 3. **颊车** 4. **少商** 5. **少海**

**关于「泥丸」**：语料中「泥丸」另见于《针灸大成》**尸鬼卒死复苏咒**文中（「太乙帝君，**泥丸总神**，丹无黑气，来复其真」），指**泥丸宫**（额部）。此处按原文保留列名，**具体灸法语料未详载**，agent 宜标注为「原文列名，方法未详」。

**急惊的推拿急救**：
1. 掐手上青筋 2. 煅脐上下 3. 掐两耳 4. 掐总心穴

**急闭的对症取穴**：

| 症状 | 穴位（泻法） |
|---|---|
| 眼闭 | **瞳子髎** |
| 牙关紧 | **颊车** |
| 口眼俱闭 | **迎香** |

> **以上数法，乃以手代针之神术也。亦分补泻。**

**要点**：**这是本库中最完整的儿科急救方案**，且强调「以手代针」——推拿可代针刺。急慢惊风的急救都以灸法或推拿为主，不用药物。

## 八、诊断 agent 的应用要点

### 8.1 儿科必须走独立路径

```
儿科病例
  ↓
① 是否有七情致病？
   └─ **否**（小儿无七情）→ 排除情志因素，转辨肝脾
      ↓
② 是急惊还是慢惊？（核心鉴别，见 3.3 表）
   ├─ 身热面赤 + 躁动 + 脉数有力 → 急惊（肝木实证）
   │    └─ 治法：清凉苦寒、泻气化痰 + 推拿（天河水过）
   └─ 身冷面黄 + 昏睡露睛 + 大便青白 → 慢惊（脾土虚证）
        └─ 治法：甘温补中 + 推拿（脾上、大肠八卦推）
      ↓
③ 兼证辨脏
   ├─ 咳喘 → 肺
   ├─ 泄泻/不乳 → 脾
   ├─ 呕吐 → 胃（推脾土肺经）
   ├─ 小便涩 → 肾（推肾水）
   └─ 口苦 → 胆（推脾土）
```

### 8.2 小儿推拿是本库儿科的主要手段

**语料中儿科的推拿内容远多于方药**。agent 若只生成方剂，会偏离语料实际。建议：
- 儿科首选**推拿 + 灸法**建议
- 方药仅在推拿不效或急重时考虑

### 8.3 关键判断：急慢惊风不可混淆

**这是儿科最危险的误判**：

| 若误判 | 后果 |
|---|---|
| 慢惊误按急惊治（清苦寒） | **脾虚更甚**，可致厥脱 |
| 急惊误按慢惊治（甘温补） | **热闭益盛**，可致神昏 |

**判别的核心是寒热与虚实，不是症状的严重程度**——慢惊的抽搐"发则无休止"看起来更重，但预后更差且不能温补。

### 8.4 治未病的前置干预

**吐泻阶段即须健脾养胃防慢惊**（原文明确）。agent 遇到小儿吐泻应主动提示这一预防措施，而非仅处理当下的泄泻。

## 十、使用注意

**本库儿科语料单一来源**：几乎全部出自《针灸大成》卷九、卷十（保婴神术、小儿门、灸法），其余四部医案书基本不涉儿科。这意味着：
- ✅ 儿科辨证纲领、急慢惊风鉴别、推拿手法、灸法治病——**可用**
- ❌ 儿科方药（尤其是儿科方剂与药物配伍）——**本库严重不足**

**儿科灸法在小儿与成人的标准不同**：「炷如小麦大」是小儿专用规格，不可套用成人灸壮数。见 [[腧穴操作与禁忌]]。

**「小儿之疾并无七情所干」是古代儿科的基本判断**：不适用于现代儿科（现代儿科高度重视儿童心理因素）。agent 使用此判断时应限于中医辨证体系内。

**急慢惊风相当于现代的惊厥/癫痫**：急惊风近于小儿惊风（多为高热惊厥），慢惊风近于慢惊（多为佝偻病、营养不良导致的惊厥）。但两者病因机制不同，不可等同。见 [[病名鉴别]]的癫狂条。

**本库儿科内容以明代针灸著作的视角为主**，与清代儿科专著（如《幼科铁镜》《保婴撮要》）的儿科体系不同，agent 引用时须注明出处体系。

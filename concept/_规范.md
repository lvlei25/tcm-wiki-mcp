# Concept 文档规范

> 本目录存放**跨文档可复用的抽象概念**：辨证体系、病机、证候、病因、治法、理论术语。
> 具体事物（药、方、穴、病名）放 `entity/`。
> 被引用的古籍与医家放 `source_ref/`（知识来源，不是诊断实体）。

## 命名
概念名.md，概念名用原文用字，简体（已通过 OpenCC 统一）。

## 必备结构

```markdown
# 概念名

> **类型**：辨证体系 / 病机 / 证候 / 病因 / 治法 / 理论
> **语料频次**：N次（分布：丁x / 傅女x / 傅男x / 参西录x / 针灸x）
> **主要出处**：《书名》…

## 一、概念界定
用 2~4 句说清这个词在语料中的确切含义。**必须有原文依据**，不引经义。

## 二、原文证据
≥3 条原文摘录，标注出处。逐字引用，不改写。

> 原文（《某书》）：「……」

## 三、构成 / 分类
若语料中有明确的分类法（如八纲、四证），列出并标注来源。

## 四、相关条目
- 上位概念 / 下位概念
- 相关 `[[概念名]]`、`[[entity名]]`

## 五、使用注意
记录该概念在古籍中的**歧义点与陷阱**，这是本库的价值所在。
```

## 硬性要求

1. **所有内容必须来自 source/ 五部书**，不得凭现代教材补充定义
2. **原文引用逐字准确**，标出处——**引文必须回查核实，人名、术语尤须核对**
3. **频次数据来自 keywords.txt**，不估算
4. 记录**各书差异**（同一术语在不同书中的含义偏移）
5. 交叉链接用 ``[[双链]]``
6. **标注文本缺口**：若某词在语料中不存在（如「卫分」0 次、「八纲」0 次），须明确写出，不得编造内容填补

## 层次安排

本库面向**中医诊断 agent**，concept 按诊断推理的层次组织：

```
病因          → 病因.md
     ↓
病位          → 八纲辨证 / 六经辨证 / 三焦辨证 / 脏腑辨证
     ↓
病性          → 寒热 / 气血 / 痰 / 血痹 / 伏邪
     ↓
脏腑定位      → 五脏·六腑 + 各脏专条
                 （肝气与肝郁 / 肝阳与肝风 / 脾气与脾虚 /
                   肺气与痰 / 心火与痰蒙 / 肾气与肾水）
     ↓
治法          → 针灸补泻与得气 / 腧穴操作与禁忌
     ↓
方药（entity）
```

新增 concept 时先判断它属于哪一层，避免层级重复。

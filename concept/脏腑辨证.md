# 脏腑辨证

> **类型**：辨证体系（诊断核心）
> **语料频次**：五脏证型合计约 1,200 次（肝气 257／胃气 283／肾气 148／相火 138／肝火 108／脾气 55／脾虚 51／肾阴 48 等）
> **分布**：丁甘仁医案与傅青主医案为主体，参西录次之
> **主要出处**：《丁甘仁医案》各案、《傅青主女科》《傅青主男科》

## 一、体系地位

**脏腑辨证是本库中最重要的辨证体系**，因为：
1. 语料中它是**唯一以脏腑名直接命名证型**的体系
2. 丁甘仁医案几乎每案都以脏腑病机收尾（「脾胃鼓舞无权」「心肝之火内炽」「肝阳内动」）
3. 它是八纲、六经、三焦的**落点**——前三者都最终指向某个脏腑

**结构**：八纲定病性 → 六经定经脉 → 三焦定部位 → **脏腑定器官与病机** → 治法与方药。

## 三、各脏核心病机（原文）

### 3.1 肝：体阴用阳，肝为刚脏

> **肝为将军之官，其性阴，其体阳，其发病也速。** 操劳过度，**肝阳内动，化风上扰，痰热随之，清窍被蒙**，神明不能自主，陡然神糊不语，牙关紧闭，四肢抽搐，脉沉似伏，良由血亏不能养肝，肝热生风，**肝主筋，肝风入筋，所以四肢抽搐**，痰气闭塞，脉道亦为之不利也。**此为痉厥重症，肝属刚脏，非柔不克。当拟柔肝熄风，清神涤痰。**

**肝的证型链**：
```
肝血不足 → 肝失所养 → 肝阳内动 → 化风上扰 → 痰随风动 → 痉厥
```
治法：**柔肝熄风**（白芍、白薇、钩藤）。

> 心肝之阴已伤，**暗吸肾阴，水不涵木，厥阴独亢**。

**要点**：肝肾同源，肝阴耗则吸肾阴，致水不涵木。治法须滋肾柔肝同用。

**肝气与肝郁**（语料中高频）：

> 疏肝解郁、调气和肝是丁甘仁治法中最常见的一类，适用于情志致病。

### 3.2 脾：孤脏以灌四旁，脾主运化

> **脾者，仓禀之本，荣之居也；其华在唇四白，其充在肌，至阴之类，通于土气，孤脏以灌四旁。**

**脾的两大病理**：

| 方向 | 语料表述 | 症状 |
|---|---|---|
| **脾气不运** | 「脾胃鼓舞无权」 | 纳呆、谷食无味、倦怠 |
| **脾阳下陷** | 「阳虚下陷」（傅青主男科） | 久泻、脱肛、坠胀 |

> 湿温二十二天，身灼热已退，寐安神清……**邪退正虚，脾胃鼓舞无权**。今拟养正和胃，寒凉慎用，**虑过犹不及也**。

**要点**：温病后期见"脾胃鼓舞无权"是**转危为安的节点**，治法是扶正和胃而非继续清泄。丁甘仁强调「寒凉慎用」——过度苦寒会进一步伤脾。

### 3.3 肺：气之本，主皮毛

> **肺者，气之本，魄之处也。其华在毛，其充在皮，为阳中之太阴，通于秋气。**

**肺的病理关键词**：

> **肺金输布无权**、**肺金化源欲绝**、**清肃之令不行**

```
肺气不足 → 化源欲绝 → 输布无权 → 津液不布 → 痰湿内生
```

> 痧后肺有伏邪，**痰气壅塞**，脾有湿热，不能健运，积湿生水，泛滥横溢，无处不到，以致面目虚浮，腹膨肢肿，咳嗽气逆。

**要点**：本语料中肺病常与脾病**合看**（肺脾同病导致痰湿、水肿）。

### 3.4 心：君主之官，神明出焉

> 心为君主之官，神明出焉。

**心的病理**：

> **心火内炽**：口疮、舌尖红、烦躁、失眠
>
> **心血不足**：心悸、失眠、多梦
>
> **痰蒙心窍**：神呆不语、类乎癫也

**心病的核心判断**是**神志改变**——因为心主神明：

> 神呆不语，**类乎癫也**，时或多言，类乎狂也……皆由**顽痰积热，阻于上中二焦**，神明被蒙。

**要点**：丁甘仁治神志病不单纯开窍，而是**先治痰**（涤痰清神）。这是心与痰的联结。

### 3.5 肾：肾气、肾水、相火

**肾气**（148 次，本语料肾的主证）。傅青主男科的论述最完整，且强调**心肾同治**：

> **无肾之水则火炽，心必得肾水以滋润，肾必得心火以温暖**，如人惊惕不安，梦遗精泄，**皆心肾不交之故**。人以惊惕为心之病，我以为肾之病；人以梦泄为肾之病，我以为心之病，非颠倒也，实有至理焉……此方之妙，**治肾之药，少于治心之味**，盖心君谧静，肾气自安，何至心动，此治肾正所以治心，治心即所以治肾也，所谓**心肾相依**。

**要点**：肾的证候（惊惕不安、梦遗精泄）在本语料中常与心同病，治法是**心肾兼治**而非单补肾。这是傅青主与丁甘仁的共同倾向。

**肾水与相火**（肾水 112、相火 138）：

> 人身之热力，方书恒责重相火，而不知**君火之热力，较相火尤胜**。盖生育子女以相火为主，消化饮食以君火为主。**君火发于心中，为阳中之火**，其热下济，大能温暖脾胃，助其消化之力，此火一衰，脾胃消化之力顿减。若君火旺而相火衰者，其人仍能多饮多食可享大寿，是知君火之热力，关于人身者甚大也。

**要点**：张锡纯明确区分**君火（心火，主消化）与相火（肾中火，主生殖）**，并指出君火虚者多"寒饮留滞为恙"，治以辛热升补（理饮汤）。这是与教材"命门火"不同的表述。

**肾与水液代谢**（肾水 112 次）：

> **膀胱必得气化而出**，气化者何，心包络之气也……膀胱之开合，**肾司其权也**。

见[[水液代谢与水肿]]。

## 四、脏腑之间的传变

### 4.1 五脏劳伤链（丁甘仁原案）

> 曲运神机，**劳伤乎心**；谋虑过度，**劳伤乎肝**；持筹握算，**劳伤乎脾**。心肝之阴已伤，暗吸肾阴，水不涵木，厥阴独亢，**脾弱不能为胃行其津液，水谷之湿生痰**。

**要点**：这条完整展示了**情志→五脏→痰**的传变链，是本语料中最有价值的脏腑传变论述。

### 4.2 肝脾同病（最常见）

丁甘仁医案中「肝脾不和」类证型极多：

> 形瘦色苍，木火体质，**抑郁不遂，气阻血痹**，与湿热凝聚募原。

> **肝木横恣，侵侮脾土之象**，故知其脾胃虚也。

**要点**：见[[气血]]与[[血痹]]。

### 4.3 肺脾同病（痰湿同源）

> 脾有湿热，不能健运，**积湿生水**，泛滥横溢。

> 脾弱不能为胃行其津液，**水谷之湿生痰**。

**要点**：脾虚生湿 → 湿聚成痰 → 痰饮影响肺（咳嗽、喘）。这是"脾为生痰之源"的语料表述。

## 五、脏腑辨证与其他体系的关系

```
八纲辨证 → 病性（寒热虚实表里阴阳）
     ↓ 落实
脏腑辨证 → 具体器官病机 ★核心
     ↑
六经辨证 → 经脉归属（哪条经）
三焦辨证 → 上下部位
卫气营血 → 邪热浅深（温病）
```

**语料实例（三套并用）**：

> 卫左　始由发热恶寒起见，继则**表不热而里热**（八纲），口干不欲饮，四肢逆冷，脉沉苔腻……**外邪由太阳而陷于太阴**（六经），不得泄越，阳气被遏，**胃阳不宣**也（脏腑）。

## 六、诊断 agent 的应用要点

### 6.1 脏腑辨证在本库中的优先级最高

原因：
1. 语料中的证型名直接就是脏腑名（肝气、肝火、脾气…），无需二次映射
2. 治法与方药直接对应脏腑（柔肝→白芍钩藤；健脾→白术茯苓）
3. 相比八纲（不显于语料）、三焦（粗略），脏腑辨证颗粒度最细

### 6.2 常见误判与规避

| 误判 | 语料警示 | 正确做法 |
|---|---|---|
| 神志病→单纯开窍 | 「皆由顽痰积热，阻于上中二焦」 | 先涤痰 |
| 温病后期→继续清泄 | 「寒凉慎用，虑过犹不及」 | 转扶正和胃 |
| 阴囊潮湿→肾阳虚 | 湿热下注亦可 | 辨舌苔脉 |
| 便秘→攻下 | 「腹无燥实坚满之形，安有可下之理」 | 查腹部体征 |

### 6.3 五脏证型的组合判断

语料中最常见的**多脏同病**组合：

| 组合 | 病机 | 治法 | 语料例 |
|---|---|---|---|
| 心肝（阴） | 心肝之阴已伤 | 柔肝宁心 | 丹甘怡神类 |
| 肝肾（阴） | 水不涵木 | 滋肾柔肝 | 见 3.1 |
| 肝脾 | 木土相争 | 疏肝健脾 | 逍遥散类 |
| 肺脾 | 生痰之源 | 健脾化痰 | 参苓白术类 |

## 八、使用注意

**脏腑证型在语料中多为「XX + 病机词」的组合，而非固定证型名**：如"肝气郁结""肝阳内动""脾气不运"是三个不同层面（气机、阳气、运化功能），不可混同。这是与教材式证型命名的最大差异。

**肾的证型在本语料中偏少**：肾阳 8、肾精 4 次，远少于肝与胃。这与丁甘仁医案属温病学派（重阴液、轻阳虚）有关，傅青主男科补足了这部分。

**「相火」不是单纯的"肾火"**：参西录明确区分君火与相火，见[[肾气与肾水]]专条的辨析。

**心与痰的联结在本语料中特别强**：「心为君主之官」＋「痰蒙心窍」的组合解释了神志病的治痰取向，这与现代"心神"概念不同。

**脏腑辨证与症状群交叉**：如[[发热症状群]]中的"午后热、颧红"实为阴虚内热（肾阴虚），须转用脏腑辨证才能确定治法。

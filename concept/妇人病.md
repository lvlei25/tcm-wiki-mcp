# 妇人病

> **类型**：专科辨证（妇科）
> **语料频次**：经 3281 · 产 703 · 胎 478 · 乳 455 · 崩 145 · 带下 57 · 胞 238
> **分布**：**《傅青主女科》为专书**（上卷经带种子、下卷胎产，80 症 83 方），另三书有零散妇科内容
> **主要出处**：《傅青主女科》全篇

## 一、体系定位与全书纲领

《傅青主女科》的自述纲领（简介原文）：

> 上卷列**带下、血崩、鬼胎、调经、种子**；下卷列**妊娠、小产、难产、正产、产后**，附产后编等。
>
> **辨证论治以肝、脾、肾三脏立论，重视奇经。**

**这是本库中唯一的妇科专书**，也是理解妇人病的核心。其内容特色（简介原文）：

1. 体例新颖，处方要而不繁
2. **以肝脾肾三脏立论，重视奇经**
3. 产科贡献：**生化汤及其运用**、**重视用药忌宜**

**与成科辨证体系的差异**：

| | 妇科 | 杂病 |
|---|---|---|
| 病机中心 | **肝脾肾三脏 + 冲任督带** | 五脏六腑 |
| 病性特点 | 气血易亏、易滞、易下陷 | 依病种而定 |
| 用药忌宜 | **忌攻伐、忌耗散** | 视病邪正而定 |

## 二、妇科三脏的分工

### 2.1 脾：主运化与统血

**带下总病机在脾**（傅青主反复强调）：

> 夫**白带乃湿盛而火衰，肝郁而气弱，则脾土受伤，湿土之气下陷**，是以脾精不守，不能化荣血以为经水，反变成白滑之物，由阴门直下。

**要点**：白带的病机链是「肝郁→脾受伤→湿土下陷→脾精不守→带下」，**脾是枢纽**。

治法与方义（完带汤）：

> 治法宜**大补脾胃之气，稍佐以舒肝之品**，使风木不闭塞于地中，则地气自升腾于天上，脾气健而湿气消。方用**完带汤**（白术、山药、人参、白芍、车前子、苍术、甘草、陈皮、黑芥穗、柴胡）。
>
> 此方**脾、胃、肝三经同治之法，寓补于散之中，寄消于升之内**。开提肝木之气，则肝血不燥，何至下克脾土；补益脾土之元，则脾气不湿，何难分消水气。至于补脾而兼以补胃者，**由里以及表也**。脾非胃气之强，则脾之弱不能旺，**是补胃正所以补脾耳**。

**完带汤的组方逻辑**（agent 可直接复用）：

| 治法 | 药 | 作用 |
|---|---|---|
| **大补脾胃** | 白术（一两土炒）、山药（一两炒）、人参 | 补脾元 |
| **补胃以强脾** | 白术、山药 + 苍术、陈皮 | 由里及表 |
| **稍佐舒肝** | 柴胡、黑芥穗 | **风木不闭塞于地中** |
| **升提** | 柴胡、黑芥穗 | 地气自升腾于天上 |
| **分消水湿** | 车前子 | 利水 |

**要点**：**「寓补于散之中，寄消于升之内」**是完带汤的配伍总纲——补而不滞、升而不燥。

### 2.2 肝：主疏泄与藏血

**肝郁是妇科的常见起点**（见 [[肝气与肝郁]]）：

> 妇人当行经之际，腠理大开，适逢风之吹寒之袭，则**肝气为之闭塞**，而经水之道路亦随之而俱闭。

> **气欲上升，而湿下带青欲下降，两相牵掣，以停住于中焦之间**。

**肝与胞宫的直接联系**（乳汁例）：

> 夫阳明属胃，乃多气多血之府也。**乳汁之化，原属阳明**，然**必得肝木之气以相通，始能化成乳汁**，未可全责之阳明也。

**要点**：**乳汁属阳明而化于肝气**——这是傅青主的独特判断，说明**肝病可致乳病**。

**肝肾同源在妇科的运用**：

> 心肝之阴已伤，暗吸肾阴，**水不涵木，厥阴独亢**。

见 [[肝阳与肝风]]。

### 2.3 肾：主胞宫与生殖

**肾气与胞宫**（[[肾气与肾水]]）：

> 膀胱病而**胞胎亦病**矣。然水湿之气必走膀胱，而膀胱不能自化，必得肾气相通，始能化水，以出阴器。倘膀胱无肾气之通，则膀胱之气化不行，水湿之气必且渗入胞胎之中，而成汪洋之势矣。

**要点**：**胞胎（胞宫）的病机核心在肾气与水湿的关系**——肾气不足则水湿内侵胞宫导致不孕。

## 三之二、带脉：傅青主重视奇经的落点

傅青主「辨证论治以肝、脾、肾三脏立论，**重视奇经**」——而**带脉是其中最核心的一条**（《傅青主女科·带下》开篇）：

> **夫带下俱是湿症。而以"带"名者，因带脉不能约束而有此病，故以名之。盖带脉通于任、督，任、督病而带脉始病。带脉者，所以约束胞胎之系也。带脉无力，则难以提系，必然胎胞不固，故曰带弱则胎易坠，带伤则胎不牢。**

**带脉的三个要点**：

1. **带下全部属湿**——「夫带下俱是湿症」，这是傅青主的定论
2. **带脉约束胞胎**——带脉无力则胎胞不固，故带下与胎孕相关
3. **带脉通任督**——「带脉通于任、督，**任、督病而带脉始病**」，即带病可上溯至任督

**带脉受伤的病因**（原文，注意「暗耗」之说）：

> 然而带脉之伤，**非独跌闪挫气已也**，或**行房而放纵**，或**饮酒而颠狂**，虽无疼痛之苦，而有**暗耗**之害，则气不能化经水，而反变为带病矣。
>
> 故病带着，惟**尼僧、寡妇、出嫁之女**多有之，而在室女则少也。况加以**脾气之虚，肝气之郁，湿气之侵，热气之逼**，安得不成带下之病哉！

**要点**：
1. **带脉伤有"暗耗"一说**——房劳、饮酒虽无疼痛，但暗耗气血，与跌闪挫气同等重要
2. **发病有群体倾向**——尼僧、寡妇、出嫁女多见，**在室女少见**（房劳/情志因素的可证）
3. **四因叠加**：脾虚 + 肝郁 + 湿侵 + 热逼 → 带下

**这与 [[病因]]的房劳致病完全对应**——傅青主把房劳作为带下的首要病因之一。

## 四、产后：生化汤为枢纽 ★

### 4.1 产后总论（傅青主纲领）

> 凡病起于**血气之衰，脾胃之虚**，而**产后尤甚**。是以**丹溪先生论产后，必大补气血为先，虽有他症，以末治之**，斯言尽治产之大旨。
>
> 若能扩充立方，则治产可无过矣。夫产后**忧、惊、劳、倦，气血暴虚，诸症乘虚易入**。

**要点**：**产后病的总纲是「气血暴虚」，故一切兼症皆为末**。这是与内科辨证最大的差别。

### 4.2 产后用药忌宜 ★（agent 必须遵守）

原文逐条列举：

| 忌 | 原文 |
|---|---|
| **忌耗散** | 「如有气毋专耗散」 |
| **忌消导** | 「有食毋专消导」 |
| **忌苦寒** | 「**热不可用芩、连**」 |
| **忌温热** | 「**寒不可用桂、附**；寒则血块停滞，热则新血崩流」 |
| **忌发汗** | 「见三阳表症之多，似可汗也，在产后而用麻黄，则**重竭其阳**」 |
| **忌攻下** | 「见三阴里症之多，似可下也，在产后而用承气，则**重亡阴血**」 |

**要点**：**寒热两极都忌**——因为「寒则血块停滞，热则新血崩流」。

### 4.3 产后逐症治法（原文）

| 症状 | 病机 | 治法 |
|---|---|---|
| 耳聋胁痛 | **肾虚恶露之停** | **休用柴胡** |
| 谵语出汗 | **元弱似邪**，非胃实 | 非承气 |
| 厥（阳气衰） | 无分寒热 | **非大补不能回阳而起弱** |
| 痉（阴血亏） | 不论刚柔 | **非滋荣不能舒筋而活络** |
| 乍寒乍热，症似疟 | 「若以疟治，**迁延难愈**」 | 不可当疟治 |
| 言论无伦，神不守舍 | 「病似邪也，若以邪治，**危亡可待**」 | 不可当邪治 |
| 大便燥结（去血过多） | 津血亏 | **肉苁蓉加于生化**，**非润肠承气之能通** |
| 小便短涩（去汗过多） | 津液伤 | **六君子倍加参、耆** |
| 颠疝脱肛 | **气虚下陷** | 补中益气之方 |
| 口噤拳挛 | **血燥类风** | 加参生化之剂 |

**要点**：**「似邪非邪」的鉴别是产后辨证的核心**——谵语、痉、寒热往来、言语无伦都**不是邪**，是虚。误当邪治则「危亡可待」。

### 4.4 生化汤及其变化

**生化汤组成**：当归、川芎、桃仁、黑姜、炙草。

**加减即治法**：

| 加减 | 治法 |
|---|---|
| 加参生化汤 | 救产后之危（亡阳） |
| 加参生化汤 + 参、耆 | 益气固脱 |
| 生化汤 + 定志 | 治怔忡惊悸 |
| 生化汤 + 木香 | 治因气闷满虚烦 |
| 生化汤 + 芒麻虫 | 产后血块 |
| 加荆芥穗（炒黑） | 止血 |

**加减原则**：

> 大抵**新产后，先问恶露如何**。块痛未除，不可遽加参术；腹中痛止，补中益气无疑。

**要点**：**生化汤的加减须先问恶露**——恶露未净不可补。这是产后用药的第一原则。

### 4.5 产后治法的经典依据（丹溪与太仆）

傅青主产后治法的理论出处，原文点明是承继前人：

> **王太仆云：「治下补下，治以急缓，缓则道路达而力微，急则气味厚而为重。」** 故**治产当遵丹溪而固本，服法宜效太仆以频加**。

**两条经典的分工**：

| 出处 | 主张 | 在本库中的体现 |
|---|---|---|
| **朱丹溪** | 产后**大补气血为先**，虽有他症以末治之 | 产后总论的开篇纲领 |
| **王太仆** | 补下宜**急缓**——缓则道路达而力微，急则气味厚而为重 | **「加参生化汤频服」**的频次原则 |

**要点**：**「服法宜效太仆以频加」是本库中关于「服药频次」最明确的记载**——补虚药须频服（频加），而非一日一剂。这是产后用药的操作要点。

**语料频次**：「大补气血」15 次、「丹溪」4 次、「太仆」2 次——可见丹溪论是傅青主产后治法的直接来源。

### 6.2 产后禁忌是硬约束

**agent 生成产后方剂时必须遵守**：

- ❌ 不用芩、连、栀、柏（苦寒）
- ❌ 不用桂、附（温热）——除非明确是亡阳证且已大补
- ❌ 不用麻黄（发汗）
- ❌ 不用承气（攻下）
- ❌ 不用枳壳、牛膝、枳实（消块）
- ❌ 不用山楂汤攻块定痛（「反损新血」）

**原文依据**（《傅青主女科·产后用药十误》）：

> 二因伤气而误用消导，反损胃气，至绝谷，禁**枳壳、大黄、蓬、棱、曲、朴**。
>
> 三因身热而误用寒凉，必致损胃增热，禁**芩、连、栀、柏、升、柴**。
>
> 七便秘毋用大黄、芒硝。九毋用山楂汤以攻块定痛，而反损新血。

**要点**：**这套禁忌是本库中最明确的用药限制**，agent 必须硬编码。

### 6.3 「似邪非邪」的产后鉴别 ★

**这是本库中产后辨证最容易出错的地方**：

| 症状 | 误判为 | 实为 | 误治后果 |
|---|---|---|---|
| 谵语汗出 | 阳明腑实 | **元弱似邪** | 「危亡可待」 |
| 乍寒乍热 | 疟疾 | 产后阴阳不和 | 「迁延难愈」 |
| 言论无伦 | 邪陷心包 | 血虚神不守舍 | 「危亡可待」 |
| 痉（抽搐） | 风邪 | **阴血亏** | 误用辛散更伤阴血 |

**判断依据**：**产后的一切「实证」表现先假定为虚**，除非有明确邪实证据（如恶露不下、瘀血块痛）。

### 6.4 种子（不孕）的三条路径

见 [[肾气与肾水]] 与 [[痰]]：

```
不孕
 ├─ 肾气不足 → 肾水不足，胞宫失养（滋肾水+ 平肝木）
 ├─ 痰湿内阻 → 胞宫"汪洋之水窟"（泄水化痰 + 补脾胃）
 └─ 肝气郁结 → 土木相结，气血不畅（疏肝解郁）
```

**要点**：傅青主的种子方**三个路径常合用**，且强调「补肾之火而非补肾之水」。

## 八、使用注意

**本库妇科内容近乎单一来源**：几乎全部出自《傅青主女科》。其余四书（丁甘仁、傅青主男科、参西录、针灸大成）的妇科内容零散且多为产后调理。agent 遇妇科病例应优先检索傅青主女科。

**傅青主的妇科观有其特色，与其他三家不同**：他重视**肝脾肾三脏 + 奇经**，尤其重视**肝气疏泄**（认为妇科病多因肝郁）与**带脉**（带下、胎孕皆与带脉相关）。这与丁甘仁温病派的思路差异明显。

**带脉是妇科的关键经脉**（傅青主重视奇经的具体体现）：

> 带脉……一在腰脐之间，环绕一周……故带脉之伤，……则气不能化经水，而反变为带病矣。

**产后「似邪非邪」的判断规则不可简化**：这是傅青主的经验性判断，语料中以「危亡可待」「迁延难愈」这样的措辞强调其严重性。agent 应把它作为**强先验**——产后出现这些症状，默认按虚证处理。

**现代妇科疾病（不孕、习惯性流产、子宫内膜异位等）不在语料范围**：本库只记载传统妇科辨证，agent 不应将古籍证型直接对应现代病名。

**绝经期（经断）问题本库完全未涉及**：「傅青主女科》成书于清代，不含现代关注的围绝经期调理内容。

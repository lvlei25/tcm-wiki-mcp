# 脾失健运

> **类型**：病机
> **语料频次**：「脾胃鼓舞无权」为丁甘仁医案高频判断；「脾不健运」「脾失健运」散见各书
> **分布**：丁甘仁医案最多（温病中后期），傅青主妇科次之
> **主要出处**：《丁甘仁医案》各案、《傅青主女科》《傅青主男科》
> **上位**：[[脾气与脾虚]] · **相关**：[[脾胃]]、[[痰]]、[[湿浊]]、[[水液代谢与水肿]]

## 一、概念界定

脾失健运指**脾的运化与升清功能减退**，导致水谷不化、湿浊内生。语料中的同义表述：

| 表述 | 出处倾向 |
|---|---|
| **脾胃鼓舞无权** | 丁甘仁医案（最常用） |
| **脾不健运／脾失健运** | 通用 |
| **中气不运** | 医案叙述 |
| **太阴清气不升** | 丁甘仁医案 |
| **脾阳不振** | 傅青主男科 |

**核心判断**：「鼓舞无权」强调的是**动力不足**——不是脾本身有病，而是**推不动**。这与「脾虚」的静态描述有区别。

## 二、原文证据

**（1）标准表述与治法**（《丁甘仁医案》）

> 进小柴胡合桂枝白虎汤加减，寒热渐退，谵语亦止，白疹布而渐多，脉象濡数，苔薄黄。太少之邪，已有外达之势，口干不多饮，精神疲倦，**谷食衰微，正气已夺，脾胃鼓舞无权**。今拟**制小其剂，扶正祛邪，理脾和胃**，冀胃气来复，自能入于坦途。

**要点**：
1. **「谷食衰微」是外在指征**——食欲与消化功能减退
2. **治法是「理脾和胃」而非健脾益气**——以恢复胃气动力为主
3. **「制小其剂」**——温病后期不宜重剂，防止再伤脾胃
4. **转归判断**：「冀胃气来复」——以胃气恢复为好转标志

**（2）与外邪的关系：清气不升、浊气不降**（《丁甘仁医案·伤寒案》）

> 太阳之经邪，虽有外解之势，少阴之伏邪未达，**中焦之食滞互阻，太阴清气不升，阳明浊气不降也**，恙势尚在重途，还虑增剧。

**（3）与痰湿的关系：脾为生痰之源**（《丁甘仁医案·神志案》）

> **脾弱不能为胃行其津液，水谷之湿生痰。** 阳升于上，痰浊随之，蒙蔽清窍，堵塞神机。

**要点**：**脾失健运 → 湿聚 → 生痰**，这是本语料中最重要的病理链条。见 [[痰]]。

**（4）与水肿的关系：脾虚生水**（《丁甘仁医案·肿胀案》）

> 痧后肺有伏邪，痰气壅塞，**脾有湿热，不能健运，积湿生水**，泛滥横溢，无处不到，以致面目虚浮，腹膨肢肿，咳嗽气逆，苔薄腻，脉濡滑，势成肿胀重症。

**（5）傅青主的妇视角**（《傅青主女科·带下》）

> **夫白带乃湿盛而火衰，肝郁而气弱，则脾土受伤，湿土之气下陷**，是以脾精不守，不能化荣血以为经水，反变成白滑之物。

见 [[妇人病]]。

**（6）脾不健则外邪易入**（《傅青主男科》）

> 此方妙在君白术，盖**人之脾胃健，而后皮毛腠理始得开合自如**，白术健脾去湿，而邪已难存。

**要点**：脾健则腠理固，不易感邪；脾虚则腠理松，易受外邪——这是脾与卫表防御的语料表述。

## 三、脾失健运的诊断指征

语料中的判断依据（agent 可直接采用）：

| 指征 | 语料表述 | 说明 |
|---|---|---|
| **纳呆** | **谷食衰微**、不思纳食、食欲减少 | 最直接的标志 |
| **体倦** | 精神疲倦、神疲乏力 | 气虚表现 |
| **苔腻** | 苔薄腻、苔腻不化 | 湿浊内生 |
| **脉濡** | 脉濡数、濡滑 | 湿的脉象 |
| **湿浊症状** | 泛恶、脘痞、肠鸣、大便溏 | 脾失运化 |
| **痰象** | 痰多、喉中痰鸣 | 湿聚成痰 |
| **口淡** | 口干不多饮 | 湿困（与热病口渴不同） |

**关键鉴别**：脾失健运的「口干不多饮」与热病的「口渴欲饮」不同——前者是湿阻津不上承，后者是热伤津。

## 四、脾失健运的三条路径

```
脾失健运
 ├─ 湿浊内停 → 泛恶、脘痞、肠鸣、苔腻、脉濡
 │    └─ 聚湿成痰 → 痰多、神志蒙蔽（见心火与痰蒙）
 ├─ 运化水液失职 → 水湿泛滥 → 面目浮肿、腹膨肢肿
 │    └─ 下注 → 带下（见妇人病）
 └─ 升清失职 → 清阳不升 → 头晕、中气下陷
      └─ 统血失职 → 便血、崩漏
```

**要点**：**同一「脾失健运」，出路不同则病位不同**——上行头目、中焦壅滞、下注胞宫、下泄大肠。agent 需根据症状落点判断。

## 五、治法（语料所载）

| 治法 | 语料表述 | 常用药 |
|---|---|---|
| **理脾和胃** | 丁甘仁温病后期主法 | 党参、白术、茯苓、陈皮、佩兰 |
| **健脾化湿** | 「白术健脾去湿」 | 白术、苍术、薏苡仁、茯苓 |
| **补中升提** | 中气下陷用 | 补中益气汤类 |
| **温运脾阳** | 阳虚下陷用 | 附子、干姜、肉桂 |
| **滋阴健脾** | 阴虚脾泄用 | 熟地、山药、山萸 + 升麻 |

**丁甘仁的用药原则**：

> 今拟**养正和胃，寒凉慎用，虑过犹不及也**。

**要点**：温病见脾失健运，**必须减苦寒、增扶正**，这是硬约束。见 [[卫气营血辨证]]。

## 六、与「脾虚」的区分

| | 脾虚（静态） | 脾失健运（动态） |
|---|---|---|
| 侧重 | 体质虚弱 | 功能减退 |
| 常见于 | 素体不足 | **病中转机**（温病后期最常见） |
| 治法 | 补脾益气 | **理脾和胃**（重在恢复动力） |
| 预后 | 慢性调理 | **可随病势恢复** |

**要点**：在丁甘仁医案中，「**脾胃鼓舞无权**」多出现在**温病恢复期**，是转机信号而非病危信号——与「脾虚」作为体质性诊断不同。

## 八、使用注意

**「脾胃鼓舞无权」是丁甘仁医案的特色判断**，其他三书少用此表述。检索时须用同义词：脾不健运、脾失健运、中气不运、太阴清气不升。

**本条与 [[脾气与脾虚]] 内容有重叠**：区别在于前者是「功能减退」（动态、常见于病中），后者是「体质虚弱」（静态、素体）。agent 宜按语境选择，不必强行区分时可统一指向 [[脾气与脾虚]]。

**脾失健运是「因」，不是「证」**：它常是其他病机的结果（如湿温后、产后、久病），agent 用它时应向上追问病因，见 [[病因]]。

**不要与「脾阳虚」混淆**：脾失健运强调**动力不足**，脾阳虚强调**温煦不足**（怕冷、便溏清稀）。语料中前者更常见，后者仅 12 次（见 [[脾气与脾虚]]）。

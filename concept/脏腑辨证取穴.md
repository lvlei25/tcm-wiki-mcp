# 脏腑辨证取穴

> **类型**：治法 / 取穴体系
> **语料频次**：《针灸大成》卷五「治病要穴」篇为主体
> **主要出处**：《针灸大成·看部取穴》《针灸大成·治病要穴（医学入门）》

## 一、体系概览

这是本库中**把穴位、病位、脏腑连成一条链的原始依据**。完整链路为：

```
症状 → 部位（上部/中部/下部/前膺/后背）→ 经脉 → 脏腑 → 该经腧穴
```

原文三条原则：

**（1）按部位取经**（《针灸大成·看部取穴》引《灵枢·杂症论》）

> 『人身上部病取手阳明经，中部病取足太阴经，下部病取足厥阴经，前膺病取足阳明经，后背病取足太阳经。取经者，取经中之穴也。**一病可用一二穴**。』

**要点**：明确「一病可用一二穴」，反对多穴堆叠——这是本体系最实用的原则。

**（2）俞募配穴（表里同取）**

| 脏 | 背俞穴 | 募穴 |
|---|---|---|
| 肺 | 肺俞 | 中府 |
| 心 | 心俞 | 巨阙 |
| 肝 | 肝俞 | 期门 |
| 脾 | 脾俞 | 章门 |
| 肾 | 肾俞 | 京门 |
| 心包 | 厥阴俞 | 膻中 |
| 大肠 | 大肠俞 | 天枢 |
| 胃 | 胃俞 | 中脘 |
| 小肠 | 小肠俞 | 关元 |
| 膀胱 | 膀胱俞 | 中极 |
| 三焦 | 三焦俞 | 石门 |
| 胆 | 胆俞 | 日月 |

原文引《难经》「脏会章门，腑会中脘」，并明确：**「胆者，肝之腑，肝能藏血，故亦取是俞也」**——表里两经同取。

**（3）五输穴母子补泻**（《针灸大成·十二经病井荥俞经合补虚泻实》）

以肺经为例：

> 手太阴肺经，属辛金。起中府，终少商，多气少血，寅时注此……**补用卯时，太渊，为俞土，土生金，为母。经曰：『虚则补其母。』泻用寅时，尺泽，为合水，金生水，为子，实则泻其子。**

**要点**：这是「虚则补其母，实则泻其子」在具体经脉上的落实，且必须同时绑定**时辰**（补用卯时、泻用寅时）。

## 二、按部位取穴的临床应用

《针灸大成·治病要穴》把手足分部，各穴列主治：

**手部要穴（原文节录）**

> ◎合谷： 主中风，破伤风，痹风，筋急疼痛，诸般头病，水肿，难产，小儿急惊风。

> ◎间使： 主脾寒症，九种心痛，脾疼，疟疾，口渴。如瘰疬久不愈，患左灸右，患右灸左。

> ◎内关： 主气块，及胁痛，劳热，疟疾，心胸痛。

> ◎劳宫： 主痰火胸痛，小儿口疮，及鹅掌风。

> ◎神门： 主惊悸怔忡，呆痴，卒中鬼邪，恍惚振禁，小儿惊痫。

> ◎列缺： 主咳嗽风痰，偏正头风，单蛾风，下牙疼。

**足部要穴（原文节录）**

> ◎足三里： 主中风中湿，诸虚耳聋，上牙疼，痹风，水肿，心腹鼓胀，噎膈哮喘，寒湿脚气。**上、中、下部疾，无所不治。**

> ◎丰隆： 主痰晕，呕吐哮喘。

> ◎三阴交： 主痞满痼冷，疝气，脚气，遗精，妇人月水不调，久不成孕，难产，赤白带下，淋漓。

> ◎公孙： 主痰壅胸膈，肠风下血，积块，妇人气蛊。

> ◎太冲： 主肿满，行步艰难，霍乱，手足转筋。

> ◎内庭： 主痞满。患右灸左，患左灸右，觉腹响是效。

**要点**：内庭、公孙、内关等穴记载了**左右交替取穴法**（"患右灸左"），这是本书特有的操作细节。

## 三、这套体系与临床医案的衔接

《丁甘仁医案》《医学衷中参西录》中，参西录明确使用了脏腑取穴：

> 一人，年近五旬，心中常常满闷，呕吐痰水。时觉有气起自下焦，上冲胃口。其脉弦硬而长，右部尤甚，此冲……

> 冲脉上隶阳明，故冲气与胃气原相贯通。

**衔接点**：三傅一录（临床医案）基本不用针灸，但仍共享「脏腑—病机—治法」的框架。参见[[五脏]]、[[六腑]]、[[气化]]。

## 五、使用注意

**这套体系只属于《针灸大成》，三傅一录不用**：三傅一录是临床医案，治法以药物为主，几乎不谈针刺取穴。引用本条时须注明出自针灸体系，不能套用于方药治疗。

**「一病可用一二穴」是本体系的灵魂**：《针灸大成》反复强调取穴要精。这与今天动辄十穴配伍的习惯相反，语料中给出的理由是「取经者，取经中之穴也」——选对经比选对穴更重要。

**左右交替取穴法不可忽略**：内庭、公孙、瘰疬等条目明确记载"患右灸左，患左灸右"，且内庭以"觉腹响是效"作为得气判断。这是可操作的验证标准。

**俞募配穴与五输穴补泻是两套并行体系**，前者重空间对应（背俞在背、募穴在腹），后者重时间与五行母子关系。原文未把二者合用，实际应用时也不宜简单叠加。

# 五输穴

> **类型**：取穴体系（五输穴母子补泻）
> **语料频次**：《针灸大成》卷四「十二经病井荥俞经合补虚泻实」专篇，十二经完整记载
> **主要出处**：《针灸大成·十二经病井荥俞经合补虚泻实》《难经·六十九难》
> **补全说明**：本条为全库**唯一完整的五输穴对照表**，十二经无缺

## 一、五输穴的五行配属

五输穴是每条经脉上的五个特定穴，按「井—荥—俞—经—合」排列，对应五行母子相生：

| 五输 | 穴名后缀 | 五行 | 阴阳属性 |
|---|---|---|---|
| **井** | 木（阴经）／金（阳经） | 阴木／阳金 | 阴井阳井 |
| **荥** | 火（阴经）／水（阳经） | 阴火／阳水 | |
| **俞** | 土（阴经）／木（阳经） | 阴土／阳木 | |
| **经** | 金（阴经）／火（阳经） | 阴金／阳火 | |
| **合** | 水（阴经）／土（阳经） | 阴水／阳土 | |

**要点**：**阴经与阳经的五行顺序相反**（阴经井木荥火俞土经金合水；阳经井金荥水俞木经火合土）。这是判断穴位五行的基础。

## 二、母子补泻的原理

### 2.1 总则（《难经》）

> **虚则补其母，实则泻其子。**

操作方式（《难经·七十三难》）：

> 补用**随而济之**（先浅后深，母气到而邪气退）；泻用**迎而夺之**（先深后浅，邪气退而母气存）。

### 2.2 跨经补泻（先判虚实在何经）

《难经·六十九难》举例：

> 假设心之虚者，取本经少冲以补之，**少冲者井木也，木能生火也**；实取神门以泻之，**神门者俞土也，火能生土**也。

**推演举例（原文）**：

> 然脏腑居位乎内，而经络播行乎外，**虚则补其母也，实则泻其子也**。若心病，**虚则补肝木也**（心属火，木生火，肝为心之母）；**实则泻脾土也**（火生土，脾为心之子）。

**要点**：**跨经补泻必须先判本经虚实**，然后按五行生克找母子经。例如心虚要补肝（不是直接补本经），心实要泻脾。

### 2.3 本经补泻（五输穴推演）

《难经》继续：

> 至于本经之中，而亦有子母焉。假如心之虚者，取本经少冲以补之……**诸经莫不皆然，要之不离乎五行相生之理，当细思之！**

**要点**：**本经之内也有母子关系**——五输穴的五行随本经属性而定，故本经虚也可选本经的特定穴。

1. **补穴与泻穴的时辰恰好相邻**（如肺经补卯时、泻寅时），符合气血流注次序

3. 每经的补泻穴均为本经五输穴之一

## 五、经脉流注次序与时辰

《针灸大成》记一日一夜气血流行一周：

> 原夫起自中焦，水初下漏，太阴为始，至厥阴而方终。穴出云门，抵期门而最后。
>
> 每日**寅时，手太阴肺经**生自中焦中府穴，出于云门起，至少商穴止；**卯时手阳明大肠经**，自商阳起至迎香止；**辰时足阳明胃经**，自头维至厉兑；**巳时足太阴脾经**，自隐白至大包；**午时手太阴心经**，自极泉至少冲；**未时手太阳小肠经**，自少泽至听宫；**申时足太阳膀胱经**，自睛明至至阴；**酉时足少阴肾经**，自涌泉至俞府；**戌时手厥阴心包络经**，自天池至中冲；**亥时手少阳三焦经**，自关冲至耳门；**子时足少阳胆经**，自瞳子髎至窍阴；**丑时足厥阴肝经**，自大敦至期门。

**流注次序**（供 agent 按时辰选经）：

```
肺（寅）→ 大肠（卯）→ 胃（辰）→ 脾（巳）→ 心（午）→ 小肠（未）
→ 膀胱（申）→ 肾（酉）→ 心包络（戌）→ 三焦（亥）→ 胆（子）→ 肝（丑）
```

## 六、原络配穴（十二经主客原经）

《针灸大成·十二经治症主客原经（杨氏）》的完整配对表。**规则：主经取原穴，客经取络穴，两者交叉配对。**

| 主经 | 原穴 | 配客经 | 络穴 |
|---|---|---|---|
| 肺主大肠客 | **太渊**（肺脉所过为原，掌后内侧横纹头，动脉相应寸口） | 大肠 | **偏历**（去腕三寸，别走太阴） |
| 大肠主肺客 | **合谷**（歧骨间） | 肺 | **列缺**（去腕侧上寸半，交叉盐指尽，别走阳明） |
| 脾主胃客 | **太白**（足大趾内踝前，核骨下隐中） | 胃 | **丰隆**（去踝八寸，别走太阴） |
| 胃主脾客 | **冲阳**（足跗上五寸，骨间动脉） | 脾 | **公孙**（去足大趾本节后一寸，内踝前，别走阳明） |
| 心主小肠客 | **神门**（手掌后锐骨端陷中） | 小肠 | **支正**（腕上五寸，别走少阴） |
| 小肠主心客 | **腕骨** | 心 | **通里** |
| **心包主三焦客** | **大陵**（掌后横纹中） | 三焦 | **外关**（去腕二寸，别走厥阴） |
| 三焦主心包客 | **阳池** | 心包 | **内关**（去掌二寸两筋间，别走少阳） |
| 胆主肝客 | **丘墟**（足外踝下从前陷中，去临泣三寸） | 肝 | **蠡沟**（去内踝五寸，别走少阳） |
| **肝主胆客** | **太冲**（足大趾节后二寸，动脉陷是） | 胆 | **光明**（去外踝五寸，别走厥阴） |
| 膀胱主肾客 | **京骨**（足小趾大骨下，赤白肉际陷中） | 肾 | **大钟**（当踝后绕跟，别走太阳） |
| 肾主膀胱客 | **文本未见此组** | 膀胱 | **文本未见此组** |

**关于「肾主膀胱客」**：查《针灸大成·十二经治症主客原经》全篇，**该组未被收录**——「膀胱主肾之客」段落之后直接接「九宫歌」，缺「肾主膀胱客」一条。原文可核：

> 膀胱主肾之客：膀胱颈病目中疼……**京骨、大钟任显能**。可刺足太阳膀胱原，复刺足少阴肾经络。①原者，京骨穴……②络者，大钟穴，当踝后绕跟，别走太阳。

**要点**：本表**只录十一组，非十二组**。按表里推演，缺的一组应为「肾经原穴太溪 + 膀胱经络穴飞扬」，但**原文无此记载，故不填**（agent 若需此配对，应标注为「依表里推演，原文未载」）。

**已核实的十一组**（均逐条回查原文）：

| 主经 | 原穴 | 配客经 | 络穴 |
|---|---|---|---|
| 肺主大肠客 | 太渊 | 大肠 | 偏历 |
| 大肠主肺客 | 合谷 | 肺 | 列缺 |
| 脾主胃客 | 太白 | 胃 | 丰隆 |
| 胃主脾客 | 冲阳 | 脾 | 公孙 |
| 心主小肠客 | 神门 | 小肠 | 支正 |
| 小肠主心客 | 腕骨 | 心 | 通里 |
| 心包主三焦客 | 大陵 | 三焦 | 外关 |
| 三焦主心包客 | 阳池 | 心包 | 内关 |
| 胆主肝客 | 丘墟 | 肝 | 蠡沟 |
| 肝主胆客 | 太冲 | 胆 | 光明 |
| 膀胱主肾客 | 京骨 | 肾 | 大钟 |

**要点（三个易错点）**：

1. **主客是交叉的**：「肺主大肠客」取**肺经原穴太渊 + 大肠经络穴偏历**；「大肠主肺客」取**大肠原穴合谷 + 肺经络穴列缺**。两组不同，不可混用。
2. **原穴与络穴不可混淆**：肺经原穴是**太渊**（列缺是肺经络穴，但出现在「大肠主肺客」组中作为大肠侧配穴）；肝经原穴是**太冲**（光明是胆经络穴）。
3. **心包与三焦一组**：心包原穴**大陵**、三焦原穴**阳池**；心包经络穴**内关**、三焦经络穴**外关**。

**原文举例**：

> 肺之主大肠客：太阴多气而少血，心胸气胀掌发热，喘咳缺盆痛莫禁，咽肿喉干身汗越，肩内前廉两乳疼……**太渊、偏历与君说**。可刺手太阴肺经原，复刺手阳明大肠络。

> 包络为病手挛急，臂不能伸痛如屈，胸膺胁满腋肿平……**大陵、外关**病消释。可刺手厥阴心包经原，复刺手少阳三焦经络。

**与八脉八穴的区别**（易混淆）：

| | 原络配穴 | 八脉八穴 |
|---|---|---|
| 配对依据 | **表里经**（肺↔大肠） | **八脉**（公孙通冲脉↔内关通阴维） |
| 是否固定 | **固定**（十二组不变） | 固定（八组） |
| 是否配时辰 | 否 | **是**（灵龟八法推算开穴） |
| 典型配对 | 太渊+偏历 | 公孙+内关 |

## 八、使用注意

**本表为《针灸大成》原文体系，不可与《内经》其他篇章混用**：《难经》讲补泻原理，《针灸大成》给出具体对应穴位与时辰，后者是前者的应用。

**「大三倍」「大再倍」的具体倍数在《难经》与《针灸大成》中表述不一**：本表按《十二经病井荥俞经合补虚泻实》原文照录，agent 若用于诊断应注明出处。

**五输穴的时辰绑定是本书特色**：《内经》只讲母子生克不讲时辰，《针灸大成》将补泻与经脉流注结合，故**补泻必须在对应时辰进行**。

**心包络与三焦同属相火**：原文明确「手厥阴心包络经，**配肾**，属相火」「手少阳三焦经，**配心包络**，属相火」——与[[肾气与肾水]]的君火相火说可互参。

**现代临床已少用按时辰补泻**：本表作为理论模型与选穴依据仍有价值，但时辰条件在现代难以满足，agent 宜标注为「古籍理论，临床参考」。

**原络配穴与八脉八穴不可混用**：前者表里经相配（如内关配外关是表里），后者八脉相配（公孙配内关是主客）。两套体系的配对逻辑不同。

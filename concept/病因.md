# 病因

> **类型**：病因学（诊断推理的起点）
> **语料频次**：劳倦 21 / 房劳 13 / 七情 14 / 饮食不节 9 / 郁怒 6 / 饥饱劳役 3 / 情志 3 / 房帏 4
> **分布**：丁甘仁医案（情志与劳倦）、傅青主女科（房劳与情志）、傅青主男科（饥饱劳役）
> **主要出处**：各书医案首述

## 一、体系界定

病因是诊断推理的**第一环**：先判病因，再定病位，最后定治法。本库语料中的病因分两大类：

| 类别 | 语料用词 | 频次 |
|---|---|---|
| **内因**（内伤） | 七情、劳倦（劳心/劳力/房劳）、饥饱劳役 | 约 55 |
| **外因**（外感） | 六淫、疫疠、时邪 | 见[[外感]] |

**要点**：**本语料的病因观以内因为重**。丁甘仁医案中情志致病极多，这与温病学派的学术倾向有关。

## 二、情志致病（本语料最重视）

### 2.1 七情与脏腑

原文（《丁甘仁医案·肝之积》）：

> **肝之积，名为肥气。肝气横逆，有升无降**，胁部作痛，按之有块，泛泛作恶，头内眩晕，纳谷衰少。**多愁善郁，症属七情，非易图治**。**若能怡情悦性，更以药石扶助，或可消散于无形。**

**要点**：
1. **"肝之积，名为肥气"**——《难经》五积理论：肥气属肝，积在胁下
2. **"肝气横逆，有升无降"**——本语料对情志致病的核心判断
3. **"若能怡情悦性"**——明确指出**情志病须以情志治疗为主，药物为辅**。这对诊断 agent 很重要：不可只开方

治法：平肝理气、和胃畅中（柴胡、香附、金铃子、延胡索、青皮、木香）。

### 2.2 五脏劳伤对应五志

原文（《丁甘仁医案·神志案》）：

> **曲运神机，劳伤乎心；谋虑过度，劳伤乎肝；持筹握算，劳伤乎脾。**

| 情志 | 劳伤心 | 语料症状 |
|---|---|---|
| 忧思（曲运神机） | 心 | 心悸、失眠、忘 |
| 谋虑（谋虑过度） | 肝 | 胁胀、眩晕、抽搐 |
| 思虑（持筹握算） | 脾 | 纳呆、倦怠、腹胀 |

**要点**：**情志通过"劳"伤心脾**，不是直接伤脏。这是本语料情志致病论的中间环节。

### 2.3 羞愤与气郁

原文（《傅青主女科·产后郁结乳汁不通》）：

> 少壮之妇，于生产之后，或闻丈夫之嫌，或听翁姑之谇，遂致两乳胀满疼痛，乳汁不通，人以为阳明之火热也，谁知是**肝气之郁结**乎！……明明是**羞愤成郁，土木相结**。

**要点**：情志致病**以郁为先**，继则影响他脏。见[[肝气与肝郁]]。

### 2.4 情志病的治法原则

**"怡情悦性，更以药石扶助，或可消散于无形"**——这是本库中关于情志病最重要的治疗原则：

1. **主**：怡情悦性（心理调节）
2. **辅**：药石扶助（疏肝理气）
3. **目标**：消散于无形（避免成形积块）

诊断 agent 应据此在输出方剂时**附带情志调适建议**。

## 三、劳倦致病

### 3.1 饥饱劳役（傅青主男科）

> 凡人**饥饱劳役，内伤正气，以致气乃下行，脾胃不能克化**，饮食不能运动，往往变为**劳瘵**……若先以**升提之药**治之，何至于成劳！

**要点**：**中气下陷是劳瘵的起点**。治法为升提（补中益气汤类）。见[[脾气与脾虚]]。

### 3.2 产后劳倦（傅青主女科）

> 产后忧、惊、劳、倦，**气血暴虚，诸症乘虚易入**……

**要点**：**产后"气血暴虚"是所有产后病的共同前提**，因此产后病的首要判断是气血虚而非邪实。见[[气血]]。

### 3.3 劳倦与劳瘵

见[[血痹]]——张锡纯主张**治虚劳必先治血痹**，即劳倦日久生瘀，瘀血内阻。

## 四、房劳致病

### 4.1 房劳与崩漏

原文（《傅青主女科·年老血崩》）：

> 妇人有**年老血崩**者，其症亦与前血崩昏暗者同，人以为老妇之虚耳，谁知是**不慎房帏之故**乎！

方用加减当归补血汤。原文并强调：

> **然必须断欲始除根**，若再犯色欲，未有不重病者也。

**要点**：房劳伤精是崩漏的**可复发原因**，故治疗须"断欲"。这对诊断 agent 意味着：崩漏患者若房劳史明显，须提示这一根本处理。

### 4.2 房劳与不孕（瘦怯不孕）

原文（《傅青主女科·身瘦不孕》）：

> 妇人有**瘦怯身躯，久不孕育**，一交男子，即卧病终朝。人以为气虚之故，谁知是**血虚**之故乎。……以**肾为肝之母**，母既泄精，不能分润以养其子，则**木燥乏水，而火且暗动以铄精**，则肾愈虚矣。况瘦人多火，而又泄其精，则水益少而火益炽……成**火在水上之卦**，所以倦怠而卧也。此等之妇，偏易动火。然此火因**贪欲而出于肝木之中，又是偏燥之火，绝非真火**也……此**阴虚火旺不能受孕**。即偶尔受孕，必致逼干男子之精，随种而随消者有之。治法必须**大补肾水而平肝木**，水旺则血旺，血旺则火消，便成**水在火上之卦**。

**要点**：①房劳的完整链条——泄精 → 肾虚不能养肝 → 木燥乏水 → 火动铄精 → 阴虚火旺；②此火"偏燥、非真火"，不可用苦寒；③治法是**滋肾水兼平肝木**，与一般"清火"不同。

**要点**：傅青主认为房劳致的不孕是**阴虚火旺**，且此火"偏燥、非真火"——不可用苦寒直折。

### 4.3 房劳与精滑

见[[肾气与肾水]]——精滑梦遗在傅青主看来是**心肾同病**。

## 五、饮食致病

### 5.1 饮食不节伤脾胃

| 语料表述 | 后果 |
|---|---|
| 「饮食不节，损伤脾胃」 | 小儿慢惊（脾土中气不足） |
| 「饮食不能运动」 | 劳瘵 |
| 「脾胃不能克化」 | 臌闷、渐成劳 |

### 5.2 食积与痰

> 脾弱不能为胃行其津液，**水谷之湿生痰**。

**要点**：**饮食 → 脾虚 → 湿 → 痰**是本语料的重要链条，见[[痰]]。

### 5.3 产后饮食禁忌

《傅青主女科·产后用药十误》专列忌口，核心是**忌消导、忌攻下**：

> 二因伤气而**误用消导，反损胃气**，至绝谷，禁枳壳、大黄、蓬、棱、曲、朴。

> 三因身热而**误用寒凉，必致损胃增热**，禁芩、连、栀、柏、升、柴。

**要点**：**产后不可见热即清热、见积即消导**——这是本语料中最明确的用药禁忌。

## 六、疫疠与时邪

见[[外感]]、[[伏邪]]。丁甘仁医案中"疫疠之邪""温邪疫疠"属此类：

> 温邪疫疠，郁而化火，肺胃被其熏蒸，心肝之火内炽，白喉腐烂……

治法：**气血双清而解疫毒**。

## 七、诊断 agent 的病因推理框架

```
症状输入
  ↓
【第一步】判内因外感
  ├─ 有表证（恶寒、发热、无汗、脉浮） → 外感（见六经/卫气营血）
  └─ 无表证                              → 内伤（继续）
  ↓
【第二步】查内因线索（诊时须问）
  ├─ 情志异常？→ 肝郁（见[[肝气与肝郁]]）
  ├─ 劳倦史（饥饱劳役、思虑过度）→ 脾虚/中气下陷（见[[脾气与脾虚]]）
  ├─ 房劳史 → 阴虚火旺/肾精亏（见[[肾气与肾水]]）
  ├─ 饮食不节 → 食积/痰湿（见[[痰]]）
  └─ 无明显内因 → 考虑痰、瘀等病理产物
  ↓
【第三步】定病位
  └─ 脏腑辨证为主（见[[脏腑辨证]]）
```

## 九、使用注意

**本语料的病因观偏重情志与劳倦**：与六淫外感的记载数量相当甚至更多。这与丁甘仁医案属温病学派（重视内伤）有关，不代表一般规律。

**「七情」在语料中仅 14 次，但「肝气」257 次**：说明情志致病在语料中主要以**"肝气郁滞"这一具体病机**呈现，而非以"七情"这个病因名呈现。检索病因时须查病机词。

**房劳在本语料中是明确的病因**：傅青主女科多处以"不慎房帏""断欲"立论，说明其对房劳致病有清晰认识。这与现代妇科病因观有相通处。

**产后病须优先考虑气血虚**：傅青主明确「产后忧、惊、劳、倦，气血暴虚，诸症乘虚易入」，且列"产后用药十误"——诊断 agent 处理产后症状时应先判气血虚，而非直接祛邪。

**情志病必须输出心理调适建议**：这是丁甘仁原案明确的原则（"若能怡情悦性，更以药石扶助"），也是本语料区别于纯方药医案的特点。

**疫疠属外感但治法特殊**：丁甘仁用"气血双清而解疫毒"，不同于一般温病的"卫气营血"层次，因疫疠兼秽浊。

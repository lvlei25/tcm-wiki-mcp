# 小儿推拿

> **类型**：治法（儿科推拿）
> **语料频次**：《针灸大成》卷十「保婴神术（按摩经）」专篇，含手法歌、观形察色法、认筋法歌
> **分布**：**《针灸大成》为本库唯一来源**（其余四书基本不用推拿）
> **主要出处**：《针灸大成·保婴神术（按摩经）》《针灸大成·治小儿诸惊推揉等法》
> **相关**：[[儿科]]、[[腧穴操作与禁忌]]、[[脾失健运]]

## 一、体系定位

小儿推拿是本库中**儿科的主要治疗手段**，地位与成儿的方药相当甚至更重。《保婴神术》开篇即定调：

> 急惊风……**内服镇惊清痰之剂，外用掐揉按穴之法**，无有不愈之理。
>
> 至于慢惊……**宜补中为主，仍以掐揉按穴之法，细心运用，可保十全矣。**

**要点**：**「内服 + 外用」双轨**，而推拿是外用的主体。急慢惊风都强调推拿。

## 二、推拿的适用总则

原文三条纲领：

> **五脏六腑受病源，须凭手法推即痊，俱有下数不可乱。**
>
> 用心记此**精宁穴**，看来危症快如风。

**要点**：
1. **以脏腑为纲**——按脏腑选手法
2. **次数不可乱**——每法有定量
3. **精宁穴**是关键穴（见下）

## 三、按脏腑的手法人数（原文全录）

### 3.1 手法歌总纲

> **心经有热作痰迷，天河水过作洪池**；**肝经有病儿多闷，推动脾土病即除**。
>
> **脾经有病食不进，推动脾土效必应**；
> **肺经受风咳嗽多，即在肺经久按摩**。
> **肾经有病小便涩，推动肾水即救得**；
> **小肠有病气来攻，板门横门推可通**。
>
> **胆经有病口作苦，好将妙法推脾土**；
> **大肠有病泄泻多，脾土大肠久搓摩**。
> **膀胱有病作淋疴，肾水八卦运天河**；
> **胃经有病呕逆多，脾土肺经推即和**。
>
> **三焦有病寒热魔，天河过水莫蹉跎**。
> **命门有病元气亏，脾上大肠八卦推。**

**要点（三条规律）**：

| 规律 | 说明 |
|---|---|
| **多推脾土** | 肝、胆、大肠、胃病皆推脾土 |
| **肾水/天河水为通用** | 肾、膀胱、三焦、命门病皆用 |
| **三关/横纹为基础方** | 几乎所有病证都配三关+横纹+天河水 |

### 3.2 具体手法与次数（原文）

| 病证 | 手法与次数 |
|---|---|
| **肺经病** | 掐**肺经**边 |
| **心经病** | 掐**天河水** |
| **泻**（整体） | 掐**大肠脾土** |
| **呕吐** | 掐**肺经**、推**三关** |
| **目昏** | 须掐**肾水** |
| **横纹** | 数十次，**天河兼之**功必完 |
| **头痛** | 推**三关穴**，再掐横纹、天河 |
| **天心** | 揉数次，「其功效在片时间」 |
| **齿痛** | 揉**肾水穴** |
| **颊车痛** | 推**颊车**自然安 |
| **鼻塞伤风** | **天心穴** |
| **总筋脾土** | 推**七百** |
| **耳聋**（肾水亏） | 掐取**肾水**、**天河**穴，**阳池**兼行**九百**功 |
| **咳嗽**（受风寒） | **先要汗出沾手边**，次掐**肺经横纹内**，干位须要**运周环** |
| **心经有热** | 运**天河** |
| **六腑有热** | 推**本科** |
| **饮食不进** | 推**脾土** |
| **小水短少** | 掐**肾**（多） |
| **大肠作泻** | 运多移，**大肠脾土**病即除；次取**天门入虎口**，揉**脐、龟尾七百** |
| **肚痛**（寒气攻） | 多推**三关**、运**横纹**；**脐中**可揉数十下 |
| **火眼** | 推**三关一百二十数**；**六腑退之四百下**；再推**肾水四百**；兼取**天河五百遍**；终补**脾土一百** |

**要点（数量化的实操特征）**：
1. **每个手法都有定量**——总筋脾土 700、阳池 900、揉脐龟尾 700、火眼一套 120+400+400+500+100
2. **火眼是最完整的成套操作**（五步，合计 1520 次）
3. **强调「汗出沾手边」**——推拿取效的验证标准是**微微汗出**

## 四、推拿的补泻（原文）

原文明确推拿亦分补泻：

> **以上数法，乃以手代针之神术也。亦分补泻。**

**要点**：**推拿有补泻之分**——这与成儿推拿不同，明代小儿推拿已纳入经络补泻体系（见 [[五输穴]]的「虚则补其母」）。

## 五、急症推拿（急慢惊风）

**慢惊将危的灸法**（非推拿）：

> 凡**慢惊将危，不能言**，先灸**三阴交**，二泥丸，三颊车，四少商，五少海穴……**十有十活**。

**急惊的推拿急救**：

> 如**急惊、天吊惊**：掐手上青筋，**煅脐上下**，掐两耳，又掐**总心穴**。
>
> **内吊惊**：掐**天心穴**。
> **慢惊不省人事**：亦掐**总心穴**。
> **急惊如死**：掐**两手筋**。
>
> **眼闭**：瞳子髎泻。**牙关紧**：颊车泻。**口眼俱闭**：迎香泻。

**要点**：**急闭用泻法**（瞳子髎泻、颊车泻、迎香泻）——与成儿开窍同理。

## 六、观形察色（推拿的前提）

《保婴神术》强调**先望诊后推拿**：

> 凡看小儿病，**先观形色，切脉次之**。

**五色主病**：

| 面部色 | 主病 |
|---|---|
| **青** | 惊积不散，欲发风候 |
| **红** | 痰积壅盛，惊悸不宁 |
| **黄** | 食积症伤，疳候痞癖 |
| **白** | 肺气不实，滑泄吐利 |
| **黑** | **脏腑欲绝，为疾危** |

详见 [[儿科]]。

## 七、关键穴位手法（原文「掐法」各穴）

《针灸大成·治小儿诸惊推揉等法》载各掐法穴：

> ○**掐二人上马**，能**补肾**，清神顺气，苏醒沉疴，**性温和**。
>
> ○**掐外劳宫**，和脏腑之热气，遍身潮热，肚起青筋揉之效。
>
> ○**掐一窝风**，治肚疼，唇白眼白一哭一死者，除风去热。
>
> ○**掐五指节**，伤风被水吓，四肢常掣，面带青色用之。
>
> ○**掐精宁穴**，**气吼痰喘，干呕痞积**用之。
>
> ○**掐威灵穴**，治**急惊暴死**。**掐此处有声可治，无声难治。**
>
> ○**掐阳池**，止头痛，清补肾水，大小便闭塞或赤黄，眼翻白，**又能发汗**。
>
> ○**推外关、间使穴**，能止转筋吐泻。**外八卦**，通一身之气血，开脏腑之秘结，穴络平和而荡荡也。

**精宁穴的定位与主治（补上缺口）**：

| 穴 | 主治 | 手法特点 |
|---|---|---|
| **精宁穴** | **气吼痰喘、干呕痞积** | 掐法；原文称「**精宁穴能治气吼**」 |
| 二人上马 | 补肾、清神顺气 | **性温和**，可久用 |
| 外劳宫 | 和脏腑热气、遍身潮热、肚起青筋 | 掐法 |
| 一窝风 | 肚疼、唇白眼白 | 除风去热 |
| 五指节 | 伤风被水吓、四肢掣、面青 | 掐法 |
| 威灵穴 | **急惊暴死** | **有声可治，无声难治**（诊断价值） |
| 阳池 | 头痛、大小便闭塞、眼翻白 | **又能发汗** |

**要点**：
1. **威灵穴的「有声可治，无声难治」**是急惊预后的即时判断标准——掐后有无声音
2. **阳池既清又汗**——「清补肾水……又能发汗」，双向作用
3. **二人上马「性温和」**——原文特别标注，意味着可长时间使用

## 八、成套操作示例（原文「肚膨惊」「夜啼惊」）

### 8.1 肚膨惊

> **因食伤脾土**，夜间饮食太过，胃不克化，气吼，肚起青筋膨胀，眼翻白，五脏寒。
>
> 推**三关一百**，推**肺经一十**，推**脾土二百**，运**八卦、分阴阳各五十**，将手**揉脐五十**，按**弦搓摩、精宁穴一十**，**青筋缝上煅四壮**。如泻，**龟尾骨上一壮**；若吐，**心窝上下四壮**；脚软，**鬼眼穴一壮**；手软、曲池侧拐各一壮；头软，天心、脐上下各一壮；若不开口，心窝一壮。

**要点**：**这是本库中最完整的儿科成套方案**——推拿（多穴定量）＋艾灸（辨症状分穴）＋灯火灸（青筋缝）。

### 8.2 夜啼惊

> 因吃甜辣之物，耗散荣卫，临啼四肢掣跳，哭不出，即是被吓，**心经有热**。一推**三关二十**，清……（原文接续处见《针灸大成》）

**要点**：夜啼惊的辨证要点是**心经有热**（见 [[心火与痰蒙]]）。

## 十、使用注意

**本库小儿推拿内容单一来源**：几乎全部出自《针灸大成》卷十「保婴神术（按摩经）」与「治小儿诸惊推揉等法」，明代著作。现代小儿推拿（清代《幼科铁镜》《保婴撮要》等）的手法体系不同，agent 引用时须注明出处体系。

**原文只给手法与次数，未讲适应证的辨证逻辑**（除了急慢惊风与肚膨惊、夜啼惊三例）：多数条目是「某经有病→推某穴」的对应，agent 应结合 [[儿科]]的肝脾纲领理解，不可机械套用。

**「以手代针之神术」是本篇的自我定位**——说明作者认为推拿可替代针刺。但这不是所有推拿手法的通例，明代其他儿科著作多主张针药并用。

**现代小儿推拿流派（捏脊、四指揉、小儿推拿特定穴）与本库体系有重合但不完全对应**，agent 若引用现代流派须另行说明，不可混为一谈。

**原文的手法次数不可直接照搬现代临床**：「总筋脾土七百」「阳池九百」等剂量在当代儿科推拿中已大幅调整，agent 应标注为「明代原方剂量」。

# 肝阳与肝风

> **类型**：病机 / 证候
> **语料频次**：肝风 40 / 肝阳 23（另肝火 108 见[[肝气与肝郁]]）
> **分布**：丁甘仁医案专设「肝气肝阳案」，参西录亦重此证
> **主要出处**：《丁甘仁医案·肝气肝阳案》《医学衷中参西录》

## 一、概念界定

「肝阳」指肝的阳气偏亢，「肝风」指肝阳化风。语料中的传变链是：

```
肝血不足（血亏不能养肝）
  └─ 肝失所养 → 肝阳内动 → 化风上扰 → 痰随风动 → 痉厥
```

**核心判断**：「肝阳」的根在**血虚**，「肝风」是**动风**的阶段。治疗必须**柔肝熄风**而非平肝潜阳——这是丁甘仁的明确主张。

## 二、原文证据

**（1）肝阳内动的完整病机**（《丁甘仁医案·肝气肝阳案》）

> 虞左　肝为将军之官，其性阴，其体阳，其发病也速。操劳过度，**肝阳内动，化风上扰，痰热随之，清窍被蒙**，神明不能自主，陡然神糊不语，牙关紧闭，四肢抽搐，脉沉似伏，**良由血亏不能养肝，肝热生风，肝主筋，肝风入筋，所以四肢抽搐**，痰气闭塞，脉道亦为之不利也。此为痉厥重症，**肝属刚脏，非柔不克**。当拟柔肝熄风，清神涤痰。

方用：生白芍（二钱，柔肝）、朱茯神、鲜竹茹、煨牡蛎、石决明、酒炒黄连、羚羊角粉（息风）、橘红、竹沥（涤痰）。

**要点**：**"肝属刚脏，非柔不克"**是本条的治疗原则——用白芍柔肝而非用重镇药压肝阳。

**（2）水不涵木与厥阴独亢**（《丁甘仁医案·神志案》）

> 心为君主之官，神明出焉；肝为将军之官，谋虑出焉；脾为谏议之官，思想出焉。**曲运神机，劳伤乎心；谋虑过度，劳伤乎肝；持筹握算，劳伤乎脾。心肝之阴已伤，暗吸肾阴，水不涵木，厥阴独亢**，脾弱不能为胃行其津液，水谷之湿生痰。**阳升于上，痰浊随之，蒙蔽清窍，堵塞神机**，神呆不语，类乎癫也。

**要点**：**心肝之阴伤 → 吸肾阴 → 水不涵木 → 厥阴独亢**，这是肝阳上亢的**肾阴亏损**根源。治法须滋肾柔肝并用。

**（3）肝风内动的实证**（类中风案）

丁甘仁医案中的类中（中风）案多属肝阳化风：

> 肝为将军之官，其性阴，其体阳，**其发病也速**。……盖**肝阳内动，化风上扰，痰热随之，清窍被蒙**。

**（4）肝阳与肝气上逆的区别**（丁甘仁）

丁甘仁在「肝气肝阳案」中明确区分二者：

| | 肝气（郁） | 肝阳（亢） |
|---|---|---|
| 病机 | 疏泄失常，气行不畅 | 阴虚阳亢，气逆上冲 |
| 症状 | 胀痛、抑郁、善太息 | 眩晕、头痛、面赤、抽搐 |
| 脉 | 弦而无力（肝郁） | 弦而有力（肝阳） |
| 治法 | 疏肝理气（辛散） | 柔肝潜阳（甘寒酸收） |

> 冲脉上隶阳明，故冲气与胃气原相贯通。今因胃气虚而不降，**冲气即易于上干**。

**要点**：肝阳上亢常与**冲气上逆**并见，故丁甘仁医案常配[[代赭石]]降冲。

**（5）参西录论肝阳虚**（与肝阳亢相对）

> 生麦芽炒用能消食，**生用则善舒肝气**也。

> 远志、菖蒲者，取其能开心窍、利痰涎，且能通神明也；用朱砂、铁锈水者，以其皆能**镇安神经，又能定心平肝**也……诚以肝为将军之官，中寄相火，若但知敛之镇之，或激动其响应之力，故又加生麦芽，**以将顺其性**。

**要点**：参西录对肝的处理强调「**将顺其性**」——反对单纯镇抑，与丁甘仁"非柔不克"一致。

## 三、肝风的三种类型（语料所见）

| 类型 | 病机 | 症状 | 治法 | 代表方药 |
|---|---|---|---|---|
| **血虚生风** | 血亏不能养肝 | 手足蠕动、肢麻、筋惕 | 养血柔肝 | 白芍、当归、阿胶 |
| **热极生风** | 邪热炽盛引动肝风 | 高热、抽搐、神昏 | 清热息风 | 羚羊角、钩藤、石决明 |
| **阴虚动风** | 肝肾阴亏、阳亢 | 眩晕、手足震颤 | 滋阴潜阳 | 大定风珠类 |

**丁甘仁医案的热极生风实例**（湿温案六诊）：

> 两进清解伏温、清化燥痰之剂，昨日申刻得汗不畅，**伏温有外达之势**，肌热较轻，而未尽退……无如**阴液亏耗之体，木火易炽，津少上承，肺失输化之权，燥痰胶结难解**，口干欲饮，唇燥溲赤，脉象寸关滑数不靖，**尺部无力**，舌苔化而复薄腻，**王孟英先生称第二层之伏邪**，有类乎斯，真阴如此之亏，温邪若斯之重，安有不肌肉消瘦，皮毛憔悴者乎！

治法：清余焰以化痰热，生津液而滋化源。

**要点**：此处"木火易炽"即**肝火亢盛**（木为肝），"尺部无力"是**肾阴亏**的脉象——与[[伏邪]]条下的"第二层伏邪"是同一医案的诊断表述，可见肝火、伏邪、肾阴三者在本语料中常合并判断。

## 四、肝阳上亢的常见兼证

```
肝阳上亢
 ├─ 兼痰 → 痰随风动 → 抽搐、神昏（丁甘仁案核心）
 ├─ 兼冲气上逆 → 呃逆、面赤、头晕（配赭石）
 ├─ 兼阴液亏损 → 舌绛少苔、脉细数
 └─ 兼肝肾阴虚 → 水不涵木、厥阴独亢（须滋肾）
```

**治疗顺序**（丁甘仁案）：

1. 先治**标**（涤痰、清神）——「痰浊有下降之路」
2. 继治**本**（柔肝、滋肾）
3. 始终顾护**阴液**——「津少上承，肺失输化之权」

## 六、使用注意

**「肝阳」既指亢进也指衰退**：语料中"肝阳内动""肝阳独亢"是亢进；"阳虚下陷"（傅青主男科）是肝阳不足。检索时须看搭配。

**「肝风」不必有抽搐才算**：丁甘仁医案中"肝阳内动"的初期只有眩晕、头胀，尚未抽搐。"肝风入筋，所以四肢抽搐"——**抽搐是肝风已重的标志**，早期诊断不应以此为必需条件。

**肝阳与肝气郁的误治风险最高**：肝气郁用辛散（柴胡、香附），若误判为肝阳而用重镇（龙骨、牡蛎），郁气更闭；反之肝阳用辛散会助阳亢。丁甘仁专设一章辨析，正是为此。

**本语料中肝阳证多属虚热**：几乎都是肝肾阴虚所致，与肝火实证（108次）不同。诊断agent 宜优先考虑阴虚阳亢路径。

**与[[伏邪]]的联结**：温病过程中"肝阳内动"常是伏邪深入营血后的表现，两者需联合判断。

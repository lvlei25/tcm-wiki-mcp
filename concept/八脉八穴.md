# 八脉八穴

> **类型**：取穴体系 / 治法
> **语料频次**：八穴在《针灸大成》中合计约 400 次；病症配穴 513 条
> **分布**：**仅见于《针灸大成》**，三傅一录不用
> **主要出处**：《针灸大成·八法交会八穴歌》《八脉图并治症穴》《八法五虎建元日时歌》

## 一、体系内容

八脉八穴是最能体现《针灸大成》「主客配穴」思想的体系：**八个穴分属八脉，两两配对，共通奇经八脉。**

**歌诀原文**：

> 公孙冲脉胃心胸，**内关阴维下总同**；
> 临泣胆经连带脉，**阳维目锐外关逢**；
> 后溪督脉内眦颈，**申脉阳跷络亦通**；
> 列缺任脉行肺系，**阴跷照海膈喉咙**。

《八穴配合歌》：

> 公孙偏与内关合，列缺能消照海疴，临泣、外关分主客，后溪、申脉正相和。**左针右病知高下**，以意通经广按摩，补泻迎随分逆顺，五门八法是真科。

| 主穴 | 所属经 | 通八脉 | 配穴（客） | 配穴通 | 主治病位（原文） |
|---|---|---|---|---|---|
| **公孙** | 足太阴脾经 | 冲脉 | **内关** | 阴维 | 胃心胸 |
| **内关** | 手厥阴心包经 | 阴维 | **公孙** | 冲脉 | 心胆脾胃 |
| **足临泣** | 足少阳胆经 | 带脉 | **外关** | 阳维 | 胆经连带脉 |
| **外关** | 手少阳三焦经 | 阳维 | **足临泣** | 带脉 | 阳维目锐 |
| **后溪** | 手太阳小肠经 | 督脉 | **申脉** | 阳跷 | 目内眦颈 |
| **申脉** | 足太阳膀胱经 | 阳跷 | **后溪** | 督脉 | — |
| **列缺** | 手太阴肺经 | 任脉 | **照海** | 阴跷 | 肺系 |
| **照海** | 足少阴肾经 | 阴跷 | **列缺** | 任脉 | 膈喉咙 |

**《八脉图并治症穴》原文对主客关系的表述**：

> 公孙二穴，脾经……**主心腹五脏病，与内关主客相应**。
>
> 内关二穴，心包经……**主心胆脾胃之病，与公孙二穴，主客相应**。
>
> 临泣二穴，胆经……**主四肢病，与外关主客相应**。
>
> 外关二穴，三焦经……**主风寒经络皮肤病**，与临泣主客相应。
>
> 后溪二穴，小肠经……**主头面项颈病**，与申脉主客相应。

**要点**：每对主客分管**相邻的两个病位**（公孙/内关同治心腹脾胃，列缺/照海同治肺系膈喉），这是八脉八穴的选穴逻辑。

## 三、主客配穴的体例

原文体例极为明确：

> **凡治后症，必先取公孙为主，次取各穴应之**（徐氏）

即：**主穴固定 → 配穴随症加减**。这与[[脏腑辨证取穴]]的"一病可用一二穴"是同一原则的两种应用。

**公孙穴下配穴实例**（共 135 条，节录）：

| 病症 | 配穴 |
|---|---|
| 九种心疼，一切冷气 | 大陵、中脘、隐白 |
| 痰膈涎闷，胸中隐痛 | 劳宫、膻中、间使 |
| 气膈五噎，饮食不下 | 膻中、三里、太白 |
| 脐腹胀满，食不消化 | 天枢、水分、内庭 |
| 胁肋下疼，起止艰难 | 支沟、章门、阳陵泉 |
| 泄泻不止，里急后重 | 下脘、天枢、照海 |
| 肺疟，令人心寒怕惊 | 列缺、肺俞、合谷 |
| 脾疟，令人怕寒腹痛 | 商丘、脾俞、三里 |
| 肾疟，令人洒热，腰脊强痛 | 大钟、肾俞、申脉 |
| 胆疟，令人恶寒怕惊，睡卧不安 | 临泣、胆俞、期门 |

**要点**：配穴高度**辨证化**——同为疟疾，按心疟、脾疟、肺疟、肾疟、胆疟分别配不同穴（心俞、脾俞、肺俞、肾俞、胆俞），这实际是把**五脏辨证投射到了取穴上**。

**内关穴下配穴实例**（共 110 条，节录）：

| 病症 | 配穴 |
|---|---|
| 中满不快，胃脘伤寒 | 中脘、大陵、三里、膻中 |
| 脾胃虚冷，呕吐不已 | 内庭、中脘、气海、公孙 |
| 脾胃气虚，心腹胀满 | 太白、三里、气海、水分 |
| 大肠虚冷，脱肛不收 | 百会、命门、长强、承山 |
| 脏毒肿痛，便血不止 | 承山、肝俞、膈俞、长强 |
| 五种痔疾，攻痛不已 | 合阳、长强、承山 |
| 心惊发狂，不识亲疏 | 少冲、心俞、中脘、十宣 |

**要点**：内关主治从"心胸"扩展到"脾胃""大肠""痔疾"，说明**内关通过阴维通冲脉，而冲脉与胃气相通**——这与参西录「冲脉上隶阳明」的论述一致。

## 四、开穴推算（灵龟八法）

八穴并非任意取用，需按日时推算何穴开。原文有三首推算歌：

**八法五虎建元日时歌**：

> 甲己之辰起丙寅，乙庚之日戊寅行，丙辛便起庚寅始，丁卯壬寅亦顺寻，戊癸甲寅定时候，五门得合是元因。

**推算示例（原文）**：

> 假如甲子日、戊辰时，以日上甲得十数，子得七数，以时上戊得五数，辰得五数，共成二十七数，此是阳日。以九除去，二九一十八，余有九数，合离卦，即**列缺穴开**也。假如乙丑日、壬午时……共成三十四数。此是阴日，以六除去，五六三十数，零下四数，合巽四，即**临泣穴开**也。

**要点**：阳日除九、阴日除六，余数配八卦（乾坎艮震巽离坤兑），得出开穴。这是本书中最复杂的择时体系，与[[针灸补泻与得气]]的按时补泻可参看。

## 六、使用注意

**本体系仅见于《针灸大成》**：三傅一录（丁甘仁/傅青主/参西录）均不使用八脉八穴，检索时须注明体系来源。

**八穴配对是固定不可拆的**：原文明确"分主客""正相和"，临床应用时不应把八穴当作普通配穴随意组合。

**申脉与照海的病症配穴在本书中缺失**：《八脉图并治症穴》只收了冲脉、阴维、督脉、带脉、阳维、任脉六脉的病症配穴（共 513 条），阳跷、阴跷二脉未收。这两穴的配穴须参其他歌诀篇目或《标幽赋》。

**灵龟八法的推算依赖干支历法**，若仅用文本统计难以验证其正确性，本库只记录原文推算规则，不作实证检验。

**与「五输穴母子补泻」是并列的两套择时体系**：五输穴按经络归属定补泻（见[[脏腑辨证取穴]]），八脉八穴按日时定开穴，二者判据不同（前者看经脉虚实，后者看干支），原文未把二者合用。

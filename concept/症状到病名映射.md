# 症状到病名映射

> **类型**：诊断索引（供 agent 检索）
> **数据来源**：source/ 五部书**段落级共现矩阵** + **PMI 显著性筛选**
> **样本量**：4,745 组症状×病名共现，筛出显著关联（PMI≥1.0 且共现≥4 次）48 个症状 → 39 个病名

## 一、方法与可靠性说明

### 数据怎么来的

1. 把五部书按**空行切分为段落**（保留原始语境）
2. 在每段内检测症状词与病名词，**同段共现即计一次**
3. 用 **PMI（互信息）** 剔除偶然共现：
   ```
   PMI(s,d) = log2[ P(s,d) / (P(s)·P(d)) ]
   ```
   PMI > 1 表示该关联至少 2 倍于偶然；本表取 PMI≥1.0 且共现≥4 次

### 为什么用 PMI 而不是频次

原始共现里有大量假关联：「肿→咳嗽」出现 427 次，但那是段落窗口过宽导致的连带，不具诊断意义。加 PMI 筛选后，「肿」的正确关联变成**白喉、疮疡、黄胆、肿胀、痈疽**——都是真正与肿相关的病名。

### 局限性（重要）

**共现 ≠ 主诉**。语料中病名极少出现在患者主诉里（实测：医案首句抽取只得到 32 组，且质量低）。原因是**中医病名由医生在辨证后给出，不是患者自述**。因此：

- ✅ 本表可用于**从症状反查可能的病名**（agent 诊断时的候选生成）
- ❌ 本表**不能反推"患者会主诉什么"**

## 四、由本表得出的诊断规则

### 规则 1：单症状 → 多病名，须靠兼症收敛

**咳嗽**是本语料最高频症状（共现 491 次），但对应至少 4 个病名。收敛靠兼症：

```
咳嗽
 ├─ 兼 壮热/神昏/谵语 → 温病（气分）
 ├─ 兼 身热不扬/泛恶/谵语 → 湿温
 ├─ 兼 痰臭脓血/苔黄滑数 → 肺痈
 ├─ 兼 咳血 → 吐血
 └─ 兼 痰多 → 风温/痰嗽
```

### 规则 2：某些症状高度特异，可直接提示病名

| 症状 | 提示病名 | 依据 |
|---|---|---|
| **半身不遂** | 中风（PMI 3.6） | 语料中近乎专属于中风 |
| **里急后重** | 痢疾 | 《丁甘仁医案·痢疾案》："赤白相杂，**里急后重**……噤口痢之重症" |
| **崩漏**（作症状） | 崩漏（PMI 8.0） | 本库最高 PMI |
| **便血** | 便血（PMI 5.3） | |
| **眩晕** | 麻木（PMI 4.5） | 痰湿阻络所致 |
| **消谷** | 消渴 | 《丁甘仁医案·消渴案》："**消灼胃阴则消谷**"（消渴主症，非「三多」） |
| **肠鸣 + 腰痛** | 霍乱 | 见下条鉴别 |

**注意**：本语料中「三多」（多饮多食多尿）**未作为消渴的判据出现**（"多尿"全语料仅 1 次）。消渴在《丁甘仁医案》中的实际表现是：

> 尹左　诊脉左三部弦数，右三部滑数，**太溪细弱，趺阳濡数**。见症**饮食不充肌肤**，神疲乏力，虚里穴动。自汗盗汗，头眩眼花。皆由**阴液亏耗，不能涵木**，肝阳上僭，心神不得安宁，**虚阳逼津液而外泄则多汗，消灼胃阴则消谷**。头面烘热，汗后畏冷，营虚失于内守，卫虚……

**要点**：本语料的消渴是**阴虚为本**（太溪细弱），主症是**消谷、饮食不充肌肤、自汗盗汗**，而非教科书式的三多。诊断 agent 不宜套用"三多"。

### 规则 3：病名之间的鉴别要点（语料原文）

**（1）泄泻 vs 痢疾**

> 王妪　寒热呕恶，饮食不进，腹痛痢下，日夜五六十次，**赤白相杂，里急后重**，舌苔腻布，脉象浮紧而数。感受时气之邪，袭于表分，**湿热挟滞，互阻肠胃，噤口痢之重症**。

**鉴别点**：痢疾有「**里急后重 + 赤白相杂**」，泄泻无。这是本语料最明确的鉴别。

**（2）霍乱 vs 泄泻/呕吐**

> 陈左　夏月阳外阴内，偏嗜生冷，腠理开发，外邪易袭。骤触**疫疠不正之气**，由口鼻而直入中道，以致寒暑湿滞，互阻中焦，**清浊混淆，乱于肠胃**，胃失降和，脾乏升运，而**大吐大泻，挥霍撩乱**。阳邪锢闭于内，中阳不伸，**不能鼓击于脉道，故脉伏；不能通达于四肢，故肢冷，两足转筋**。……汗多烦躁，欲坐井中之状，**口渴不欲饮，是阴盛于下，格阳于上，此阴躁也**。形肉陡然削瘦，脾土大伤，谷气不入，**生化欲绝**。

**鉴别点**：霍乱特征——
- **脉伏**（不是普通吐泻的脉象）
- **两足转筋**（腓肠肌痉挛）
- **阴躁**：汗多烦躁、**口渴不欲饮**（渴但不欲饮是格阳的关键指征）
- 病势急骤：形肉**陡然**削瘦

**（3）伤寒 vs 温病**

| 病名 | 特异症状 |
|---|---|
| **伤寒** | 恶寒(44)、**汗出(49)**、恶风、干呕 |
| **温病** | 壮热、神昏、谵语、烦躁 |
| **湿温** | 身热、泛恶、谵语 |
| **风温** | 发热、痰多、自汗 |

**要点**：伤寒以**恶寒、汗出**为主（腠理疏松），温病以**壮热、神昏、谵语**为主（热入营血）。这与丁甘仁原按一致：

> **伤寒可以化热，温病亦能化寒**，皆随六经之气化而定。

**（4）黄胆 vs 黄疸（丁甘仁医案作「黄胆」，针灸大成作「黄疸」）**

《丁甘仁医案·黄胆案》两条：

> 温病初愈，因**饮食不谨**，湿热滞互阻中焦，太阴健运无权，阳明通降失司，以致**脘腹胀闷，不思纳谷，一身尽黄，小溲短赤如酱油色**，苔薄腻黄，脉濡滑而数，黄胆已成，非易速痊。

> 陈左　喉痧之后，**滋阴太早，致伏温未发**，蕴湿逗留募原，着于内而现于外，遂致**遍体发黄，目珠黄，溺短赤，身热晚甚，渴喜热饮，肢节酸疼，举动不利**，苔薄腻黄，脉濡数。**温少湿多**，互阻不解，缠绵之症也。

**鉴别点**：
- **黄胆主症**：一身尽黄 + **小溲短赤如酱油色**（尿色深重）+ 苔薄腻黄 + 脉濡滑而数
- 第二例「目珠黄」——**黄疸的体征定位在目**
- 病因不同：第一例是**饮食不谨、湿热滞中焦**（脾失健运）；第二例是**滋阴太早、伏温未发**（误治）
- 共同点：两者**腹胀**显著，与带下/瘕的腹胀需区分——**黄胆腹胀必兼身黄尿赤**，这是最简判据

**（5）带下/白带 vs 黄疸的「肿」**

「肿」的关联病名中出现黄疸、黄胆，而两者都关联腹胀。**区分要点**：黄疸/黄胆的肿 accompanied by **身黄 + 尿赤**；带下/白带是**阴门分泌物**为主征，与身黄无关。

## 五、给诊断 agent 的检索建议

```
输入：症状组合
  ↓
① 查本表「症状 → 可能病名」，取 PMI 最高的 3~5 个作候选
  ↓
② 用「病名 → 核心症状」反向验证：候选病名是否解释了全部症状？
      解释不了的症状 → 该病名不成立
  ↓
③ 查「病名之间的鉴别要点」，排除混淆项（如泄泻 vs 痢疾）
  ↓
④ 确定病名后，转 concept 层辨证：
      八纲辨证 → 病性
      脏腑辨证 → 病位（见 concept/脏腑辨证.md）
  ↓
⑤ 查病名 entity 文档，取原文主治与方剂
```

## 七、使用注意

**本表是候选生成工具，不是诊断规则**：PMI 高只说明两个词在语料中常同现，不代表两者有因果关系。必须经第②步反向验证。

**PMI 值受语料分布影响**：本语料以温病医案为主，因此「发热、汗出、神昏」等温病症状的 PMI 偏高，而食积、虫证等冷门内容缺失。**本表对温病类病名的覆盖优于杂病。**

**症状词库有限**：本表基于约 120 个高频症状词构造，罕见症状（如耳流脓、皮肤斑疹）未纳入。agent 遇到表外症状应回原文检索。

**妇科症状归属需人工确认**：带下、腹痛在语料中大量属傅青主女科妇科医案，与内科腹痛易混。诊断 agent 宜先按妇科辨治（见 [[带下]]相关条目）。

**「产后」在表中既是病名也是症状修饰**：它与其他症状的共现（如浮肿、气喘、自汗）反映的是**产后病**，不是"生产"这一事件。agent 须区分。

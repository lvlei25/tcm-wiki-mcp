# 外科疮疡

> **类型**：病机 / 治法（外科门类）
> **语料频次**：疮疡 38 · 溃烂 38 · 生肌 45 · 脓 208 · 痈疽 27 · 疔疮 7 · 肺痈 31 · 乳痈 28 · 瘰疬 22 · 瘿 32
> **分布**：**《医学衷中参西录》为主**（溃烂 38/38、生肌 45/45、脓 121 全在参西录），针灸大成次之（痈疽 20、瘰疬 22、瘿 29）
> **主要出处**：《医学衷中参西录·论治疔宜重用大黄》《丁甘仁医案·肺痈案》

## 一、体系定位

**本语料的外科以参西录为一枝独秀**——丁甘仁医案仅涉肺痈（5 次），其余外科内容集中在张锡纯一人。这与《医学衷中参西录》全书「治阳为主」的取向一致。

外科的核心命题是**分期**：

```
初起（未成脓）→ 不可用补益/收涩药，须解毒消散
   ↓
成脓（脓成）  → 须透脓，托毒外出
   ↓
溃后（已溃）  → 补气血、生肌收口
```

**这个分期是本条最实用的部分**，原文有明确论证。

## 二、原文证据

**（1）外科药物的时机判断——分期用药的明确论证**（《医学衷中参西录·论治疔宜重用大黄》）

> 《神农本草经》不又谓其治痈肿乎？然**痈肿初起，服之必无效，惟痈肿溃后，生肌不速，则用之甚效**。

**要点**：**补气药（如黄耆）在痈肿初起时无效，溃后才有效**——这是外科分期的核心判断。

**（2）疔毒的危险性——最紧急的一类**（《论治疔宜重用大黄》）

> **疮疡以疔毒为最紧要，因其毒发于脏腑，非仅在于经络。其脉多见沉紧。紧者毒也，紧在沉部，其毒在内可知也。** 至其重者，发于鸠尾穴处，名为**半日疔**，言半日之间即有关于人性命也。

**要点**：
- **疔毒的危险性远高于普通疮疡**——因为「毒发于脏腑，非仅在于经络」
- **半日疔**（发于鸠尾穴）可在半日内致命
- **脉沉紧 = 毒在里**（紧为毒，不是寒）

**（3）早期预防——治未病的实例**（同上）

> 若系此种疔毒，**当于未发现之前**，其人或心中怔忡，或**鸠尾处隐隐作疼**，或其处若发炎热，似有漫肿形迹，其脉象见沉紧者，即宜预防鸠尾穴处生疔，而投以大剂解毒清血之品。

**要点**：**这是本库中最明确的「治未病」案例**——尚未成疮时即根据「心怔 + 鸠尾隐疼 + 脉沉紧」三联征预判并干预。

**（4）大黄扫毒汤——重用大黄降毒**（同上）

> 忆愚少时，见同里患疔者二人，一起于脑后，**二日死**；一起于手三里穴，**三日死**。……后愚堂侄女于口角生疔，疼痛异常，心中忙乱。投以清热解毒药不效，脉象沉紧，大便三日未行。恍悟寒温之证，若脉象沉洪者，可用药下之，以其热在里也。今脉象沉紧，**夫紧为有毒（非若伤寒之紧脉为寒也）**，紧而且沉，其毒在里可知……遂为疏方∶**大黄、天花粉各一两，皂刺四钱，穿山甲、乳香、没药各三钱，薄荷叶一钱，全蜈蚣三大条**。煎服一剂，大便通下，疼减心安。遂去大黄，又服一剂，全愈。

**要点**：
1. **脉沉紧须下**——与寒温的「沉洪可下」同理，只是紧为毒
2. **大黄不必等到便秘才用**——「凡脉象沉紧，其大便不滑泻者，皆可用」
3. **体弱者大黄可减量**
4. 方中穿山甲、皂刺、全蜈蚣是**透脓通络**药

**（5）外用方（参西录外科专方）**

| 方名 | 原文主治 | 用法 |
|---|---|---|
| **化腐生肌散** | 「治**瘰已溃烂者**，用此药擦之。他疮破后者亦可用之」 | 「共研细，收贮瓶中勿令透气。**日擦患处三四次**，用此药长肉。将平时**收口不速**者，可加**珍珠**一分，研细搀入」 |
| **内托生肌散** | 溃后肉芽不生（内托法） | 内服 |
| 消瘰丸 / 消瘰膏 | 瘰疬 | 内服 + 外敷 |
| 大黄扫毒汤 | 疔毒 | 内服（见上） |

**外治法要点（化腐生肌散原文）**：
- **用法**：研细粉剂，**日擦患处三四次**
- **保存**：「收贮瓶中勿令透气」——防止药性挥发
- **加减**：收口不速者**加珍珠**
- **适应**：不限于瘰疬，「**他疮破后者亦可用之**」

**要点**：参西录外科有**内外并重**的特点——内服托里生肌，外用化腐生肌粉剂搽擦，且明确外治法的通用性。

**（6）肺痈——丁甘仁的温病路径**（《丁甘仁医案·肺痈案》）

> 沈左　**外感风温，内蕴湿热，熏蒸于肺，肺脏生痈**，咳嗽胸膺牵痛，痰臭脓血，身热口干，脉滑数，苔黄，重症也。急拟辛凉清温，而化痰瘀。

> 闻左　外感风寒，袭于肺胃，**膏粱浓味，酿成痰浊，血瘀凝滞，壅结肺叶之间**，致成肺痈。是以咳嗽气粗，**痰秽如脓**，胁痛难于转侧，振寒发热，舌苔白浓而腻，脉象浮紧而滑。

**要点**：肺痈的病机是**痰瘀互结于肺叶**——故治法须「化痰**瘀**」，与普通咳嗽不同。

**（7）乳痈与乳岩——傅青主的分型与五阶段治法**（《傅青主女科·乳痈》）

> **乳头属足厥阴肝经，乳房属足阳明胃经。** 若乳房臃肿，结核色红，数日外肿痛溃稠脓，脓尽而愈，此属**胆胃热毒，气血壅滞**，名曰乳痈，**易治**。若初起内结小核，**不红不肿不痛**，积之岁月，渐大如巉岩石，破如熟榴，**难治**。
>
> 治法：**痛肿寒热，宜发表散邪；痛甚，宜疏肝清胃；脓成不溃，用托里；肌肉不生，脓水清稀，宜补脾胃；脓出及溃，恶寒发热，宜补血气；饮食不进，或作呕吐，宜补胃气。**
>
> **乳岩初起，用益气养荣汤加归脾汤，间可内消；若用行气破血之剂，速亡甚矣。**

**要点**：
1. **归属**：乳头属肝（厥阴）、乳房属胃（阳明）——这是外科的经脉归属基础
2. **易治/难治的分界**：红肿溃脓为易治，**不红不肿不痛、渐大如巖岩石**为难治（后者即乳岩）
3. **五阶段治法序列**（agent 可直接用作分期决策表）：

| 阶段/症状 | 治法 |
|---|---|
| 痛肿寒热 | **发表散邪** |
| 痛甚 | **疏肝清胃** |
| 脓成不溃 | **托里** |
| 肌肉不生、脓水清稀 | **补脾胃** |
| 脓出及溃、恶寒发热 | **补血气** |
| 饮食不进或呕吐 | **补胃气** |

4. **乳岩禁忌**：初起用益气养荣汤加归脾汤，**若用行气破血之剂，速亡甚矣**——与外科总论「痈肿初起忌补」相反，因为乳岩是无红无肿的虚证

**要点**：乳痈（红肿热毒，实证）与乳岩（无红无肿，虚证）的治法**完全相反**，误治可致死。这是本语料中最鲜明的外科辨证对照。

**（8）瘰疬与瘿——针灸大成体系**（各 22/32 次，全在针灸大成）

《针灸大成》有「瘰疬门」「瘿病」相关取穴，属外科的**针灸治疗**路径：

> **瘰疬门** —— 见 entity/瘰疬.md

**要点**：外科在针灸大成中主要靠**直接灸疮疡穴**（如灯火灸、骑竹马灸），见 [[腧穴操作与禁忌]] 的灸法部分。

## 四、诊断 agent 的应用要点

### 4.1 外科首要判断：是否「毒在里」

语料给出**可直接操作的判据**：

| 判据 | 毒在里（需下） | 毒在表（忌下） |
|---|---|---|
| **脉象** | **沉紧**（紧为毒） | 浮数（热在表） |
| 寒温鉴别 | 沉洪 → 热在里，可下 | — |
| **紧 vs 寒** | **紧为有毒**（非伤寒之紧脉为寒） | — |

**要点**：本语料明确「紧为有毒，非若伤寒之紧脉为寒」——这是外科脉诊的关键辨析，误判会导致反向治疗。

### 4.2 外疮治疗前必须判断分期

```
初起（未溃）：
  ✗ 不用补气药（「痈肿初起，服之必无效」）
  ✓ 解毒散结、透脓
      ↓
成脓：
  ✓ 皂刺、穿山甲透脓（参西录大黄扫毒汤）
      ↓
溃后：
  ✓ 补气血、生肌收口（化腐生肌散 / 内托生肌散 / 黄耆）
  ✗ 仍用苦寒攻伐
```

**要点**：**最常见的错误是初起即用补药**，参西录专门论述此事。

### 4.3 鸠尾穴的预警意义

**鸠尾穴**（心之募穴）是人体的疮疡预警位：

| 表现 | 判断 |
|---|---|
| 心中怔忡 + 鸠尾隐隐作疼 + **脉沉紧** | **将生半日疔**（可在半日致命） |

**治疗**：**未发之前**即投大剂解毒清血 + 大黄下之，使「疔即可暗消于无形」。

**要点**：这是本库中唯一有明确预警-干预机制的病例，值得 agent 单独建模。

### 4.4 外科与温病的交叉

肺痈在丁甘仁医案中属**温病变证**：

> 外感风温，内蕴湿热，熏蒸于肺，肺脏生痈。

即**肺痈可由温病失治演变而来**。见 [[卫气营血辨证]]——邪入营血、灼津成痰、痰瘀壅肺，是肺痈的温病路径。

## 六、使用注意

**外科在本语料中极不均衡**：参西录一人占了溃烂、生肌的几乎全部，针灸大成占瘰疬、瘿的大部，傅青主女科占乳痈。丁甘仁医案基本不涉外科（仅肺痈 5 次）。**agent 遇外科病例应优先检索参西录。**

**「脓」的高频（208 次）不等于重视化脓**：其中 121 次在参西录，多为方药组成描述（某药能排脓、生肌），而非病机论述。不可据词频判断倾向。

**外科药物的时机性是本条的核心价值**：初起不可补、溃后必须补——这条在《医宗金鉴》等外科专书中有系统论述，但**本语料中它以「论治疔宜重用大黄」一文集中呈现**，篇幅有限。agent 宜把它作为原则性提示，具体方药须谨慎。

**瘰疬与瘿在针灸大成中是取穴体系**（灯火灸、骑竹马灸等），与内科瘰疬（参西录消瘰丸）不是同一套治法，见 entity/ 对应条目。

**现代外科感染（蜂窝织炎、脓毒症等）不在语料范围**：本库只记载传统疮疡辨证，agent 不应将古籍证型直接对应现代疾病诊断。

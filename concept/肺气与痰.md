# 肺气与痰

> **类型**：病机 / 证候
> **语料频次**：肺气 75 / 肺热 20 / 肺金输布无权 13 / 肺阴 12 / 肺燥 6 / 肺寒 3
> **分布**：丁甘仁医案最多（肺病专章：咳嗽、咳嗽案、肺痈案）
> **主要出处**：《丁甘仁医案·咳嗽案》《丁甘仁医案·暑温案》《针灸大成》

## 一、概念界定

肺在本语料中承担三个功能：

1. **主气司呼吸**——肺为「气之本」
2. **主宣发肃降、通调水道**——津液输布的起点
3. **主皮毛、司卫气**——体表防御

**核心病机链**：

```
肺气不足（或邪热耗气）
  └─ 肺金化源欲绝 → 输布无权 → 津液不布 → 痰湿内生
       └─ 肺虚不能下荫于肾 → 肾不纳气 → 喘促
            └─ 肺主皮毛失职 → 卫气失守 → 汗出
```

## 二、原文证据

**（1）肺的生理地位**（《针灸大成·十二经穴主治》）

> 《内经》曰：**『肺者，相傅之官，治节出焉。』**

> **肺者，气之本，魄之处也。其华在毛，其充在皮，为阳中之太阴，通于秋气。**

> 西方生燥，**燥生金，金生辛，辛生肺，肺生皮毛，皮毛生肾。肺主鼻，其在天为燥，在地为金，在体为皮毛，在脏为肺，在声为哭，在变动为咳，在志为忧，忧伤肺，喜胜忧**，热伤皮毛，寒胜热，辛伤皮毛，苦胜辛。

**要点**：**"肺生皮毛，皮毛生肾"**是肺肾同源的经典表述，也是肺病及肾的理论依据。

**（2）肺气虚的完整病机**（《丁甘仁医案·暑温案》）

> 张左　发热汗多，气短而喘，脉数而乱，舌红，**暑热伤津耗气，肺金化源欲绝，肺为水之上源，肺虚不能下荫于肾，肾不纳气，肺主皮毛，肺伤则卫气失守，是以汗出甚多**。经云∶因于暑，汗，烦则喘喝是也。症势危笃，勉拟**生脉散，益气生津，而清暑热**。

**要点**：这段把肺气虚的**三个后果一次讲清**——①肺为水之上源（影响津液）②肺虚不能下荫于肾（影响纳气）③卫气失守（影响汗出）。治法是**益气生津**而非止汗。

**（3）肺输布无权与燥痰**（《丁甘仁医案·湿温案》）

> 惟阴分本亏，**津少上承，余焰留恋气分，肺金输布无权，厥阳易于升腾**，口干唇燥，头眩且痛……皆系余燥为患。**燥字从火，火灼津液为痰**，有**一分之燥，则一分之痰不能清澈也**。

**要点**：这是本语料中「肺→痰」最直接的表述——**火灼津液为痰**。燥痰与普通痰不同，**一分燥则一分痰不清**，故燥痰难治。

**（4）肺与痰的同源性**（《丁甘仁医案·神志案》）

> 脾弱不能为胃行其津液，**水谷之湿生痰**。阳升于上，**痰浊随之，蒙蔽清窍**。

**要点**：痰源自脾（湿），蒙于肺（清窍）。**脾生痰、肺受痰**，这是痰的脏腑归属。

**（5）肺痈的肺热路径**（《丁甘仁医案·肺痈案》）

> 沈左　**外感风温，内蕴湿热，熏蒸于肺**，肺脏生痈，咳嗽胸膺牵痛，痰臭脓血，身热口干，脉滑数，苔黄，重症也。急拟辛凉清温，而化痰瘀。

**要点**：肺痈是**肺热壅盛＋痰瘀互结**，治法需**化痰与化瘀并用**（不只是清热）。

**（6）肺与大肠相表里**（《针灸大成》）

> 手太阴肺经：起中府，终少商……**脉起中焦，下络大肠**，还循胃口，上膈属肺。

**要点**：肺与大肠相表里，肺气不降则大肠传导失常。语料中「肺与大肠」的联结主要用于解释二便异常。

## 三、肺病的三条路径（语料所见）

### 路径一：肺气虚 → 气不布津 → 痰生

```
肺气不足（暑热耗气，久病体虚）
  └─ 肺金化源欲绝 → 输布无权
       └─ 津液不布，聚而为痰
            └─ 咳嗽痰多、气短
```

治法：**益气生津**（生脉散类）、**健脾化痰**（四君子+二陈）

### 路径二：肺热 → 灼津成痰 → 痰热壅肺

```
邪热犯肺（或外感风温内蕴湿热）
  └─ 熏蒸于肺 → 肺失宣降
       └─ 火灼津液为痰（燥痰）
            └─ 咳嗽、痰黄稠、发热
```

治法：**清肺化痰**（苇茎汤类）、**辛凉清解**

### 路径三：肺气虚 → 子病及母 → 肾不纳气

```
肺气虚 → 肺不能下荫于肾
  └─ 肾不纳气 → 喘促、气息停顿
```

治法：**补肺纳肾**（人参、胡桃肉、蛤蚧类）

**丁甘仁医案关键案例**（肺病及肾）：

> 气短而喘，脉数而乱……**肺虚不能下荫于肾，肾不纳气**。

治用生脉散——**益气生津**，因肾不纳气源于肺气虚，故从肺治而非从肾治。

## 四、肺病的治法（语料所载）

| 治法 | 适应 | 语料例方 |
|---|---|---|
| **宣肺化痰** | 邪在肺卫、痰阻肺络 | 杏苏散类、丁甘仁咳嗽案 |
| **清肺化痰** | 肺热痰黄 | 苇茎汤、千金苇茎汤 |
| **肃肺降气** | 肺气上逆、咳喘 | 旋覆花、代赭石 |
| **润肺化痰** | 燥痰、津少 | 沙参、麦冬、石斛 |
| **益气生津** | 肺气虚、化源欲绝 | 生脉散 |
| **温肺化饮** | 寒饮犯肺 | 小青龙汤类 |
| **排脓解毒** | 肺痈 | 苇茎汤+千金苇茎汤、皂荚丸 |

## 五、肺与痰的诊断要点

诊断 agent 宜按以下顺序辨：

```
1. 有无咳嗽痰多？
   └─ 无 → 肺病可能但非主症
   └─ 有 → 2. 痰的质地？
            ├─ 白稀清冷 → 寒饮（温肺化饮）
            ├─ 白稠而黏、难咯 → 燥痰（润肺）
            ├─ 黄稠臭秽 → 肺热痰热（清肺）
            └─ 痰多而身体困重 → 脾虚生痰（健脾）
3. 痰从哪来？
   ├─ 肺系症状为主（咳、喘、胸痛） → 肺生痰
   └─ 脾虚纳呆为主               → 脾生痰（治脾为主）
```

**依据**：丁甘仁医案反复强调「脾为生痰之源」，而痰的质地决定治法方向（见[[痰]]）。

## 七、使用注意

**肺气虚与肺阳虚不同**：语料中「肺气虚」（75次）指功能低下，「肺寒」（3次）指受寒。「肺阳虚」一词在语料中不存在——温肺的治法散在「寒饮」「痰饮」条目下。

**「肺金化源欲绝」是重症指征**：丁甘仁用以描述暑热耗气后的危候，与「肺气不足」的轻症不同，不可混用。

**燥痰比普通痰更难治**：语料明确「一分之燥，则一分之痰不能清澈也」。这意味着**燥痰不能单纯化痰，须先润燥**，否则痰越化越稠。

**肺与大肠相表里在本语料中用得较少**：主要见于针灸大成理论部分，临床医案少用。诊断 agent 宜以肺系症状为主判断，不必强求表里传导关系。

**肺病在丁甘仁医案中占比很大**（有专门的咳嗽案章），但多为**温病后期**的肺，与单纯外感咳嗽不同。

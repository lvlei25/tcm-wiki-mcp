# 心火与痰蒙

> **类型**：病机 / 证候
> **语料频次**：心火 58 / 心气 39 / 心血 29 / 心神 25 / 心阳 12
> **分布**：丁甘仁医案（专设神志案章）最集中，傅青主男科次之
> **主要出处**：《丁甘仁医案·神志案》《傅青主男科·癫痫狂证》

## 一、概念界定

心的病变在本语料中集中于**神明受扰**，因此形成一条独特的路径：

```
五脏劳伤 → 心气/ 心血不足
  └─ 心主神明失守 → 神志症状（呆、语乱、癫狂）
       └─ 但治疗不单纯宁心，而是先治「痰蒙心窍」
```

**核心病机链**：

```
五脏劳伤 → 脾虚生痰 → 痰浊随风/火升 → 蒙蔽心窍 → 神志症状
```

**要点**：**心病的治法核心是治痰**，而非单纯安神。这是本语料最鲜明的特色。

## 二、原文证据

**（1）心的生理地位**（《丁甘仁医案·神志案》）

> 心为**君主之官**，神明出焉；肝为**将军之官**，谋虑出焉；脾为**谏议之官**，思想出焉。

**（2）五脏劳伤致痰蒙的完整链条**（《丁甘仁医案·神志案》）

> 曲运神机，**劳伤乎心**；谋虑过度，**劳伤乎肝**；持筹握算，**劳伤乎脾**。**心肝之阴已伤，暗吸肾阴，水不涵木，厥阴独亢，脾弱不能为胃行其津液，水谷之湿生痰。阳升于上，痰浊随之，蒙蔽清窍，堵塞神机**，神呆不语，类乎癫也，时或多言，类乎狂也。

**要点**：这条链完整展示了**心→肝→脾→肾→痰→窍**的传变，是本语料中最核心的病机论述。

**（3）痰火标本与痰色辨析**（《丁甘仁医案·神志案》）

> 前哲云，**阴并于阳则狂，阳并于阴则癫**，癫则如醉如痴，皆由**顽痰积热，阻于上中二焦**，神明无出入之路。夫**痰为火之标，火为痰之本**，痰得热而色应黄，今反白而粘腻者何也？盖**肺津不能输布，聚液为痰**，津液之痰，与湿浊之痰，**互结为援**，**肺色属白，故痰色白而粘也**。

**要点**：这段包含三个层次：
1. **癫狂的阴阳判别**——阴并于阳则狂（狂属阳），阳并于阴则癫（癫属阴）
2. **痰火标本**——"痰为火之标，火为痰之本"，标本俱治
3. **痰色反常的辨析**——痰本应黄而反白粘腻，是因肺津不能输布与湿浊互结，**肺色属白**

**这是本库中关于痰的质地诊断最精细的一处**，见[[痰]]。

**（4）本虚标实的判断**（同上）

> **腑气五日不行，痰浊不得下达也**；小溲短少而黄，**肺为水之上源，源不清则流不洁也**。脉尺部沉濡，左寸关弦滑而数依然如昨，右部寸涩关滑，舌质红，苔薄黄，**本虚标实，显然可见**，况素有肢麻腿足无力等症，非本虚之明证乎。

**要点**：
- **便秘5 日** → 痰浊不得下达（腑气不通则痰无出路）
- **小溲短少** → 肺失通调（肺为水之上源）
- **尺部沉濡＋素有肢麻腿足无力** → 本虚（肾阳不足）
- 合起来 = **本虚标实**（肾虚为本，痰热为标）

**诊断 agent 应用**：见精神症状时，须同时检查二便与舌脉以判标本。

**（5）心神失守的表现**（丁甘仁医案）

| 症状 | 病机 |
|---|---|
| 神呆不语 | 痰浊蒙窍 |
| 多言、语乱 | 痰火扰心（类乎狂） |
| 善忘 | 心血虚 |
| 惊悸| 心神不宁 |
| 昏迷谵语 | 痰热蒙蔽心包 |

## 三、心病的三条路径（语料所见）

### 路径一：痰蒙心窍（实证，最常见）

```
五脏劳伤 → 脾虚生痰
  └─ 痰浊随风火升 → 蒙蔽心窍
       └─ 神呆、不语、类癫
           └─ 或多言、语乱、类狂（痰火）
```

治法：**涤痰开窍、清神**（半夏、南星、郁金、石菖蒲、远志、竹沥）

**丁甘仁方药**：酒炒木通、远志、鲜石菖蒲（化痰开窍）；保心丹（安神）

**要点**：**不单纯用安神药，须先涤痰**。这是丁甘仁治神志病的主导思路。

### 路径二：心火亢盛（热证）

```
心火亢 → 口疮、舌尖红、烦躁、失眠
  └─ 或下移小肠 → 小便赤涩（心与小肠相表里）
```

治法：**清心泻火、导热下行**

**丁甘仁方药**：川连、川雅连、酒炒黄连（清心）

**要点**：丁甘仁用**川雅连**（黄连的产地规格）清心火，与清脾胃的黄连有别。

### 路径三：心血不足（虚证）

```
心血不足 → 心悸、失眠、多梦、健忘
```

治法：**养血安神**（当归、酸枣仁、柏子仁、远志、茯神）

**傅青主男科的表达**：

> 治肾之药，少于治心之味……盖心君谧静，肾气自安，何至心动。

**要点**：见[[肾气与肾水]]——傅青主把心悸失眠归到心肾同病，须心肾兼治。

## 四、癫狂的阴阳判别（语料明确的鉴别）

| 证候 | 阴阳归属 | 症状特征 | 病机 |
|---|---|---|---|
| **狂** | **阴并于阳** | 躁扰多言、登高而歌、弃衣而走 | 阳并于阴则狂（痰火扰心） |
| **癫** | **阳并于阴** | 如醉如痴、神呆不语 | 阴并于阳则癫（痰浊蒙窍） |
| **痫** | — | 发作性、醒后如常 | 见 [[伏邪]] 与痫风条 |

**《针灸大成·百症赋》的取穴对应**：

> **痫发癫狂兮，凭后溪而疗理**；疟生寒热兮，仗间使以扶持。

**要点**：针灸体系把癫狂归到**后溪**（手太阳小肠经，通督脉）——与丁甘仁的"痰蒙心窍"路径不同。两套体系可对照：针灸重经络（后溪通督脉治癫狂），临床重痰浊（涤痰开窍）。

## 五、心病的治法（语料所载）

| 治法 | 适应 | 语料例方 |
|---|---|---|
| **涤痰清神** | 痰蒙心窍、类癫 | 半夏、南星、竹沥、郁金 |
| **清心泻火** | 心火亢、口疮 | 川连、川雅连、竹叶 |
| **养血安神** | 心血虚、心悸失眠 | 当归、酸枣仁、柏子仁 |
| **开窍醒神** | 痰闭心窍、昏迷 | 远志、石菖蒲、郁金 |
| **滋阴降火** | 心肾不交 | 生地、麦冬、黄连、阿胶 |
| **补心丹** | 心气虚 | 保心丹（丁甘仁案） |

## 六、诊断 agent 的应用要点

### 6.1 见神志症状，先查痰

本语料中神志病案的高频判断是「痰蒙清窍」。诊断顺序应是：

```
1. 有无神志症状（呆、语乱、癫狂、谵语）
   └─ 有 → 2. 有无痰的证据？
            ├─ 苔腻、脉滑、喉中痰鸣 → 痰蒙（先涤痰）
            ├─ 舌红苔黄、脉数、面赤 → 痰火扰心（清热化痰）
            └─ 舌淡、脉细、心悸失眠 → 心血虚（养血安神）
3. 标本判断
   ├─ 二便通畅？→ 痰浊有出路
   └─ 二便不通（腑气五日不行）→ 痰浊不下，须先通腑
4. 查本虚
   └─ 尺部沉濡、肢麻腿足无力 → 肾阳不足（本虚）须标本兼顾
```

### 6.2 「本虚标实」是常见格局

丁甘仁神志案多为**本虚标实**：
- 本虚：心肝阴伤、肾阳不足（尺部沉濡、肢麻无力）
- 标实：痰浊、湿热蒙窍

治法必须**标本兼顾**，单纯涤痰则伤正。

### 6.3 痰色是重要的诊断线索

| 痰色质地 | 判断 |
|---|---|
| 黄稠 | 痰热（当清热化痰） |
| **白而粘腻（反常）** | **肺津不输 + 湿浊互结**（燥痰夹湿，宜润燥化湿） |
| 白稀清冷 | 寒饮（宜温化） |

### 6.4 通腑是排痰的关键路径

「腑气五日不行，痰浊不得下达」——**便秘则痰无出路**。神志病见便秘时须先通腑，再涤痰。

## 八、使用注意

**「心火」与「相火」不可混**：心为君火（主消化），肾为相火（主生殖），见[[肾气与肾水]]的辨析。语料中「心火」58 次指心之火，非泛指火热。

**「心神失守」不等于心血虚**：本语料中多数神志症状的成因是**痰蒙**，不是心血不足。诊断agent 若见精神症状便归"心血虚"，会漏掉最主要的病机。

**癫狂的阴阳判别是本语料明确的**：狂为阳（躁动）、癫为阴（静默），与中医教材一致，但丁甘仁强调两者**皆由顽痰积热**，所以治法相同（涤痰）而非相反。

**心与小肠相表里在本语料中体现为"心火下移小便赤涩"**，这一联结不如"心痰蒙窍"常用。

**心病的虚实倾向**：丁甘仁医案属温病学派，神志病多属**痰热实证夹阴虚**，而非纯虚。

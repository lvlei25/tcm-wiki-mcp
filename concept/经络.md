# 经络

> **类型**：理论总论（经络体系）
> **语料频次**：经络 252 / 十二经 82 / 经脉 81 / 络脉 49 / 奇经 33 / 十五络 18
> **分布**：《针灸大成》卷一「针道源流」与卷四「十二经穴主治」为主体，其余三书基本不用经络理论
> **主要出处**：《针灸大成·针道源流》《针灸大成·奇经八脉（节要）》《针灸大成·十二经穴主治》

## 一、体系定位

经络是本库中**连接「病位」与「取穴」的枢纽**。诊断 agent 的推理路径必经此处：

```
症状 → 辨证（判定病位）
  ↓
病位落在某脏某经 ← **经络是坐标系统**
  ↓
取该经的特定穴（俞募/五输/八脉八穴/络穴）
  ↓
施治
```

**经络的三层**：

| 层 | 内容 | 详见 |
|---|---|---|
| **正经** | 十二经脉（手足三阴三阳） | [[十二经脉]] |
| **奇经** | 奇经八脉 | [[奇经八脉]] |
| **络脉** | 十五络（十二经各一络 + 脾之大络） | 见下文 |

**语料缺项**：**「经别」「十二经别」在语料中 0 次**——《内经》的十二经别体系在本语料中未见记载，agent 不应引用。

## 二、经络的生理功能（原文）

**（1）运行气血，联络脏腑**

《针灸大成·手足阴阳流注论》：

> 歧伯曰：『凡人两手足，各有三阴脉、三阳脉，**以合为十二经**也。**手之三阴，从胸走至手，手之三阳，从手走至头；足之三阳，从头下走至足，足之三阴，从足上走入腹**。络脉传注，周流不息，故**经脉者，行血气，通阴阳，以荣于身者也**。其始从中焦，注手太阴、阳明，阳明注足阳明、太阴，太阴注手少阴、太阳，太阳注足太阳、少阴，少阴注手心主、少阳，少阳注足少阳、厥阴，厥阴复还注手太阴。其气常以**平旦为纪，以漏水下百刻，昼夜流行，与天同度，终而复始**也。』

**要点（四项）**：
1. **十二经的循行方向**——手三阴胸走手、手三阳手走头、足三阳头走足、足三阴足走腹（这是气血运行的四个方向）
2. **「行血气，通阴阳，以荣于身」**——经络的功能概括
3. **流注次序**从中焦起，昼行夜行，终而复始
4. **「平旦为纪，以漏水下百刻」**——以自然界计时，与 [[五输穴]]的时辰补泻同源

**注**：《灵枢》另有「行血气、营阴阳、调虚实、处百病」一语，**但此四句在本语料中 0 次**（仅「行血气」5 次）。agent 引用时须标明出处为《灵枢》而非本库语料。

**（2）络脉的功能**（同篇原文）

> **络脉者，本经之旁支而别出，以联络于十二经者也。本经之脉，由络脉而交他经**，他经之脉，亦由本经之络脉交还本经……

**要点**：**络脉是十二经之间的横向联络通道**，与经脉的纵向循行不同。这是理解原络配穴的基础（见 [[五输穴]]）。

**（2）经络与血的关系**（《医学衷中参西录》）

> 人身经络，皆有血融贯其间，内通脏腑，外溉周身，**血一停滞，气化即不能健运，劳瘵恒因之而成**。

见 [[气血]]、[[血痹]]。

**（3）经络与痰的关系**（丁甘仁医案）

痰随气升降，可阻滞经络：

> **胃络通于心包**，胃浊下降，痰亦随之而下也……痰浊有下降之路。

见 [[心火与痰蒙]]。

## 三、经络的诊断价值

### 3.1 寸口与人迎对比（十二经虚实判据）

《针灸大成·十二经病井荥俞经合补虚泻实》按经给出虚实脉象：

- **手三阴（心、肺、心包）**——候**寸口**
- **足三阴（肝、脾、肾）**——候**寸口**
- **手三阳（大肠、小肠、三焦）**——候**人迎**
- **足三阳（胃、膀胱、胆）**——候**人迎**

| 经 | 所属 | 虚实脉象 |
|---|---|---|
| 手太阴肺 | 辛金 | 盛：寸口大三倍于人迎；虚：反小于人迎 |
| 手阳明大肠 | 庚金 | 盛：人迎大三倍于寸口；虚：反小于寸口 |
| 足阳明胃 | 戊土 | 盛：人迎大三倍于寸口；虚：反小于寸口 |
| 足太阴脾 | 己土 | 盛：寸口大三倍于人迎；虚：反小于寸口 |
| 手少阴心 | 丁火 | 盛：**寸口大再倍于人迎**；虚：反小于人迎 |
| 手太阳小肠 | 丙火 | 盛：**人迎大再倍于寸口**；虚：反小于寸口 |
| 足太阳膀胱 | 壬水 | 盛：人迎大三倍于寸口；虚：反小于寸口 |

**要点**：**寸主脏、迎主腑**是核心判断规则。见 [[六经辨证]]。

### 3.2 经脉循行部位与症状定位

**症状所在的部位＝经脉循行所过**，这是最直接的定位法：

| 症状部位 | 循行经（举例） |
|---|---|
| 缺盆（锁骨上窝） | 肺经「缺盆中痛」 |
| 胁肋 | 足厥阴肝「两胁满痛」、胆经「心胁痛」 |
| 少腹 | 足厥阴肝「丈夫颓疝苦腰疼，妇人腹膨小腹肿」 |
| 咽喉 | 冲脉/任脉「至咽喉」 |
| 腘（膝后） | 足太阳膀胱「腘中痛」 |

**要点**：丁甘仁医案判病位常用此法，如「少腹胀痛」多归肝经、「缺盆中痛」归肺经。

### 3.3 是动／所生病

**这是经络辨证内部再分气血两层的细分**（原文明确）：

> **①邪在气，气留而不行，为是动病。②邪在血，血壅而不濡，为所生病。**

见 [[十二经脉]]的完整对照表。

## 五、经络与脏腑的关系

《针灸大成》按「脏腑 → 经 → 穴」组织全书，这是本库的诊断-取药结构依据：

```
五脏六腑
  ↓
十二经脉（+ 奇经八脉）
  ↓
腧穴（319 个 entity）
  ↓
主治症
```

**要点**：**脏腑辨证与经络辨证是同一坐标系的两层**——脏腑说"病在何脏"，经络说"该取何穴"。见 [[脏腑辨证]]。

## 六、语料分布的极不均衡（重要）

| 书 | 经络理论使用情况 |
|---|---|
| **《针灸大成》** | **唯一的经络理论来源**——卷一针道源流、卷四十二经穴主治、卷六奇经八脉 |
| 《医学衷中参西录》 | 少量（用经络解释血瘀、气化下陷） |
| 《傅青主女科》 | 极少（傅青主讲带脉、冲任，但不讲十二经） |
| 《丁甘仁医案》 | **基本不用经络辨证**（按卫气营血 + 脏腑辨证） |
| 《傅青主男科》 | 极少 |

**要点**：**三傅一录几乎不用经络辨证诊断**。agent 处理临床医案类问题时，**经络只在取穴时使用，不是主要辨证工具**；而《针灸大成》中的经络理论不能直接套用到医案辨证。

## 八、使用注意

**「十二经脉」一词在语料中仅 5 次**：语料用「十二经」（82 次）、「经脉」（81 次）、「经络」（252 次）。检索时须用简称。

**「经别」「十二经别」语料中 0 次**：《内经》的这一体系在本语料中完全缺失。agent 不应引用现代教材中的十二经别理论。

**「十五络」语料中 18 次**，主要在《针灸大成·经络》与原络配穴篇，指十二经各一络穴（列缺、偏历、内关、支正、通里、郄门、间使、外关、光明、蠡沟、飞扬、大钟）加大络（大包）。

**经络理论在本库中高度集中于一部书**：除《针灸大成》外，其余四部的经络论述极少。agent 做经络相关推理时应标明这是针灸体系的判断，而非内科辨证。

**经络与「卫气营血」分属两套辨证体系**：丁甘仁医案（温病派）不用经络辨六经，而用卫气营血分浅深；针灸大成（针灸派）则严格按经络定经。**两套体系须分开使用**，见 [[卫气营血辨证]]。

# 悬厘

> **类型**：穴位
> **语料频次**：3 次（分布：— / — / — / — / 针灸 3）
> **归属**：足少阳胆经

## 一、原文（《针灸大成》专条）
```
悬厘： 曲周上，颞颥下廉。 手足少阳、阳明之会。 《铜人》针三分，灸三壮。 《素注》针三分，留七呼。 主面皮赤肿，头偏痛，烦心不欲食，中焦客热，热病汗不出，目锐眦赤痛。
```

## 二、语料中的实际使用
《针灸大成》载3次，为该书腧穴条目。

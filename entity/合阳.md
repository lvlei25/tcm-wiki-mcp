# 合阳

> **类型**：穴位
> **语料频次**：5 次（分布：— / — / — / — / 针灸 5）
> **归属**：足太阳膀胱经

## 一、原文（《针灸大成》专条）
```
合阳： 膝约纹下三寸。 《铜人》针六分，灸五壮。 主腰脊强引腹痛，阴股热，胻酸肿，步履难，寒疝阴偏痛，女子崩中带下。
```

## 二、语料中的实际使用
《针灸大成》载5次，为该书腧穴条目。

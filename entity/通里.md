# 通里

> **类型**：穴位
> **语料频次**：42 次（分布：— / — / — / — / 针灸 42）
> **归属**：手少阴心经

## 一、原文（《针灸大成》专条）
```
通里： 掌后一寸陷中。 手少阴心脉之络，别走太阳小肠经。 《铜人》针三分，灸三壮。 《明堂》灸七壮。 主目眩头痛，热病先不乐，数日懊𢙐，数欠频呻悲，面热无汗，头风，暴喑不言，目痛心悸，肘臂臑痛，苦呕喉痹，少气遗溺，妇人经血过多崩中。 实则支满膈肿，泻之。 虚则不能言，补之。
```

## 二、语料中的实际使用
《针灸大成》载42次，为该书腧穴条目。

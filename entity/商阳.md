# 商阳

> **类型**：穴位
> **语料频次**：42 次（分布：— / — / — / 参西录 1 / 针灸 41）
> **归属**：手阳明大肠经

## 一、原文（《针灸大成》专条）
```
◎商阳： 在食指内侧去爪角韭叶。 针一分，灸三壮。
```

## 二、语料中的实际使用
《针灸大成》载41次，为该书腧穴条目。
另在《参西录》中出现1次，属临床配穴使用。

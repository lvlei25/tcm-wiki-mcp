# 脊中

> **类型**：穴位
> **语料频次**：16 次（分布：— / — / — / 参西录 2 / 针灸 14）
> **归属**：督脉

## 一、原文（《针灸大成》专条）
```
脊中③；腗络季胁引少腹而痛胀，刺譩嘻④；腰痛不可以转摇，急引阴卵，刺八髎与痛上，八髎在腰尻分间；鼠瘘寒热，还刺寒府，寒府在胕膝外解营。取膝上外者，使之拜；取足心者，使之跪也。』
```

## 二、语料中的实际使用
《针灸大成》载14次，为该书腧穴条目。
另在《参西录》中出现2次，属临床配穴使用。

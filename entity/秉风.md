# 秉风

> **类型**：穴位
> **语料频次**：4 次（分布：— / — / — / — / 针灸 4）
> **归属**：手太阳小肠经

## 一、原文（《针灸大成》专条）
```
秉风： 天髎外肩上小髃后，举臂有空。 手太阳、阳明、手足少阳四脉之会。 《铜人》灸五壮，针五分。 主肩痛不能举。
```

## 二、语料中的实际使用
《针灸大成》载4次，为该书腧穴条目。

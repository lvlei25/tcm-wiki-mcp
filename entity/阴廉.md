# 阴廉

> **类型**：穴位
> **语料频次**：4 次（分布：— / — / — / — / 针灸 4）
> **归属**：足厥阴肝经

## 一、原文（《针灸大成》专条）
```
阴廉： 羊矢下，去气冲二寸动脉中。 《铜人》针八分，留七呼，灸三壮。 主妇人绝产，若未经生产者，灸三壮，即有子。
```

## 二、语料中的实际使用
《针灸大成》载4次，为该书腧穴条目。

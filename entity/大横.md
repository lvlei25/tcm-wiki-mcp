# 大横

> **类型**：穴位
> **语料频次**：8 次（分布：— / — / — / — / 针灸 8）
> **归属**：足太阴脾经

## 一、原文（《针灸大成》专条）
```
大横： 腹哀下三寸五分，去腹中行各四寸半。 足太阴、阴维之会。 《铜人》针七分，灸五壮。 主大风逆气，多寒善悲，四肢不可举动，多汗洞痢。
```

## 二、语料中的实际使用
《针灸大成》载8次，为该书腧穴条目。

# 六腑

> **类型**：穴位
> **语料频次**：82 次（分布：丁 5 / 傅女 4 / — / 参西录 1 / 针灸 72）
> **归属**：经外奇穴

## 一、原文（《针灸大成》专条）
```
六腑： 腑者，府也。 胆、胃、大肠、小肠、三焦、膀胱，受五脏浊气，名传化之府，故为六腑。 五脏藏精而不泻，故满而不实。 六腑输泻而不藏，故实而不满。 如水谷入口，则胃实而肠虚，食下，则肠实而胃虚。
```

## 二、语料中的实际使用
《针灸大成》载72次，为该书腧穴条目。
另在《丁甘仁、傅女、参西录》中出现10次，属临床配穴使用。

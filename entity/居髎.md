# 居髎

> **类型**：穴位
> **语料频次**：9 次（分布：— / — / — / — / 针灸 9）
> **归属**：足少阳胆经

## 一、原文（《针灸大成》专条）
```
居髎： 章门下八寸三分，监骨上陷中。 《素注》章门下四寸三分。 足少阳、阳𫏋之会。 《铜人》针八分，留六呼，灸三壮。 主腰引小腹痛，肩引胸臂挛急，手臂不得举以至肩。
```

## 二、语料中的实际使用
《针灸大成》载9次，为该书腧穴条目。

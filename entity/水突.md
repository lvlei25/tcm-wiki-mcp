# 水突

> **类型**：穴位
> **语料频次**：4 次（分布：— / — / — / — / 针灸 4）
> **归属**：足阳明胃经

## 一、原文（《针灸大成》专条）
```
水突气舍连缺盆，气户库房屋翳屯，膺窗乳中延乳根，不容承满梁门起，关门太乙滑肉门。天枢外陵大巨存，水道归来气冲次，髀关伏兔走阴市，梁丘犊鼻足三里，上巨虚连条口位，下巨虚跳上丰隆，解溪冲阳陷谷中，内庭厉兑经穴终（左右九十穴）。
```

## 二、语料中的实际使用
《针灸大成》载4次，为该书腧穴条目。

- **归属**：足阳明胃经（胃）
  - **脏腑职司**（原文）：胃者，水谷之海，六腑之大原也
  - **循行与属性**：起头维，终厉兑，气血俱多，辰时注此
  - **是动病**：洒洒然振寒，善呻数欠，颜黑。病至恶人与火，闻木音则惕然而惊……甚则欲登高而歌，弃衣而走，贲响腹胀，是谓骭厥
  - **所生病**：狂疟温淫，汗出鼽衄，口㖞唇疹，颈肿，喉痹，大腹水肿，膝膑肿痛……中指不用
  - **补法**（五输穴母子补泻）：补用巳时，解溪，为经火。火生土，虚则补其母
  - **泻法**（五输穴母子补泻）：泻用辰时，厉兑，为井金。土生金，实则泻其子

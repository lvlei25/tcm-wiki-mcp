# 廉泉

> **类型**：穴位
> **语料频次**：26 次（分布：丁 10 / — / — / — / 针灸 16）
> **归属**：任脉

## 一、原文（《针灸大成》专条）
```
廉泉通。窥天突于璇玑，捣华盖于紫宫。登玉堂兮膻中集，履中庭兮鸠尾冲。瞻巨阙兮二脘上中，过建里兮下脘攸同。水分兮神阙缥缈，阴交兮气海鸿蒙。石门直兮关元、中极，曲骨横兮会阴乃终 ① 。
```

## 二、语料中的实际使用
《针灸大成》载16次，为该书腧穴条目。
另在《丁甘仁》中出现10次，属临床配穴使用。

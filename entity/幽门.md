# 幽门

> **类型**：穴位
> **语料频次**：21 次（分布：— / — / — / 参西录 10 / 针灸 11）
> **归属**：足少阴肾经

## 一、原文（《针灸大成》专条）
```
幽门： 侠巨阙两旁各一寸五分陷中，足少阴、冲脉之会。 《铜人》针五分，灸五壮。 主小腹胀满，呕吐涎沫，喜唾，心下烦闷，胸中引痛，满不嗜食，里急数咳，健忘，泄利脓血，目赤痛从内眦始，女子心痛，逆气，善吐食不下。
```

## 二、语料中的实际使用
《针灸大成》载11次，为该书腧穴条目。
另在《参西录》中出现10次，属临床配穴使用。

# 胞肓

> **类型**：穴位
> **语料频次**：3 次（分布：— / — / — / — / 针灸 3）
> **归属**：足太阳膀胱经

## 一、原文（《针灸大成》专条）
```
胞肓： 十九椎下两旁相去脊各三寸陷中，伏而取之。 《铜人》针五分，灸五七壮。 《明堂》灸三七壮。 《甲乙》灸三壮。 主腰脊急痛，食不消，腹坚急，肠鸣，淋沥，不得大小便，癃闭下肿。
```

## 二、语料中的实际使用
《针灸大成》载3次，为该书腧穴条目。

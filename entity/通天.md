# 通天

> **类型**：穴位
> **语料频次**：14 次（分布：丁 4 / — / — / 参西录 3 / 针灸 7）
> **归属**：足太阳膀胱经

## 一、原文（《针灸大成》专条）
```
通天： 承光后一寸五分。 《铜人》针三分，留七呼，灸三壮。 主颈项转侧难，瘿气，鼻衄，鼻疮，鼻窒，鼻多清涕，头旋，尸厥，口㖞，喘息，头重，暂起僵仆，瘿瘤。
```

## 二、语料中的实际使用
《针灸大成》载7次，为该书腧穴条目。
另在《丁甘仁、参西录》中出现7次，属临床配穴使用。

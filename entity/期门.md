# 期门

> **类型**：穴位
> **语料频次**：55 次（分布：— / — / — / — / 针灸 55）
> **归属**：足厥阴肝经

## 一、原文（《针灸大成》专条）
```
期门： 直乳二肋端，不容旁一寸五分。
```

## 二、语料中的实际使用
《针灸大成》载55次，为该书腧穴条目。

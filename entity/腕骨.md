# 腕骨

> **类型**：穴位
> **语料频次**：64 次（分布：— / — / — / — / 针灸 64）
> **归属**：手太阳小肠经

## 一、原文（《针灸大成》专条）
```
腕骨： 手外侧腕前起骨下陷中。 手太阳小肠脉所过为原。 小肠虚实皆拔之。 《铜人》针二分，留三呼，灸三壮。 主热病汗不出，胁下痛不得息，颈颔肿，寒热，耳鸣，目冷泪生翳，狂惕，偏枯，肘不得屈伸，痎疟头痛，烦闷，惊风，瘛疭，五指掣，头痛。
```

## 二、语料中的实际使用
《针灸大成》载64次，为该书腧穴条目。

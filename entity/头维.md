# 头维

> **类型**：穴位
> **语料频次**：25 次（分布：— / — / — / — / 针灸 25）
> **归属**：足阳明胃经

## 一、原文（《针灸大成》专条）
```
头维： 额角入发际，本神旁一寸五分，神庭旁四寸五分。 足阳明、少阳二脉之会。 《铜人》针三分。 《素注》针五分，禁灸。 主头痛如破，目痛如脱，目𥆧，目风泪出，偏风，视物不明。
```

## 二、语料中的实际使用
《针灸大成》载25次，为该书腧穴条目。

### 作为配穴出现于

- **作为公孙、后溪、内关的配穴出现 3 次**（公孙 1 次，后溪 1 次，内关 1 次）
- 所治病症（去重后按主穴分列）：

  - 随公孙：两眉角痛不已

- **操作**：针三分

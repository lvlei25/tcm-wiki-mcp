# 归来

> **类型**：穴位
> **语料频次**：10 次（分布：— / — / — / 参西录 1 / 针灸 9）
> **归属**：足阳明胃经

## 一、原文（《针灸大成》专条）
```
归来： 水道下二寸，去中行各二寸。 《铜人》灸五壮，针五分。 《素注》针八分。 主小腹贲豚，卵上入腹，引茎中痛，七疝，妇人血脏积冷。
```

## 二、语料中的实际使用
《针灸大成》载9次，为该书腧穴条目。
另在《参西录》中出现1次，属临床配穴使用。

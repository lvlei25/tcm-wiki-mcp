# 曲泽

> **类型**：穴位
> **语料频次**：25 次（分布：— / — / — / — / 针灸 25）
> **归属**：手厥阴心包经

## 一、原文（《针灸大成》专条）
```
曲泽： 肘内廉陷中，大筋内侧横纹中动脉是。 心包络脉所入为合水。 《铜人》灸三壮，针三分，留七呼。 主心痛，善惊，身热，烦渴口干，逆气呕涎血，心下澹澹，身热，风疹，臂肘手腕不时动摇，头清汗出不过肩，伤寒，逆气呕吐。
```

## 二、语料中的实际使用
《针灸大成》载25次，为该书腧穴条目。

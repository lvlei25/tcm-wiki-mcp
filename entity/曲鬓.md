# 曲鬓

> **类型**：穴位
> **语料频次**：4 次（分布：— / — / — / — / 针灸 4）
> **归属**：足少阳胆经

## 一、原文（《针灸大成》专条）
```
曲鬓翘，率谷天冲浮白次，窍阴完骨本神邀，阳白临泣目窗辟，正营承灵脑空摇，风池肩井渊液部，辄筋日月京门标，带脉五枢维道续，居髎环跳风市招，中渎阳关阳陵穴，阳交外丘光明宵，阳辅悬钟丘墟外，足临泣地五侠溪，第四指端窍阴毕（左右八十八穴）。
```

## 二、语料中的实际使用
《针灸大成》载4次，为该书腧穴条目。

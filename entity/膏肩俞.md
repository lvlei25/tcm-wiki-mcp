# 膏肩俞

> **类型**：穴位
> **语料频次**：1 次（分布：— / — / — / — / 针灸 1）
> **归属**：经外奇穴

## 一、原文（《针灸大成》专条）
```
◎膏肩俞： 在四椎下一分，五椎上二分两旁，去脊各三寸，四肋三间。
```

## 二、语料中的实际使用
《针灸大成》载1次，为该书腧穴条目。

# 颧髎

> **类型**：穴位
> **语料频次**：7 次（分布：— / — / — / — / 针灸 7）
> **归属**：手太阳小肠经

## 一、原文（《针灸大成》专条）
```
颧髎： 面頄骨下廉锐骨端陷中。 手少阳、太阳之会。 《素注》针三分。 《铜人》针二分。 主口㖞，面赤目黄，眼𥆧动不止，杂肿齿痛。
```

## 二、语料中的实际使用
《针灸大成》载7次，为该书腧穴条目。

# 大椎

> **类型**：穴位
> **语料频次**：29 次（分布：— / — / — / — / 针灸 29）
> **归属**：督脉

## 一、原文（《针灸大成》专条）
```
大椎： 一椎上，陷者宛宛中。 手足三阳、督脉之会。 《铜人》针五分，留三呼，泻五吸，灸以年为壮。 主肺胀胁满，呕吐上气，五劳七伤，乏力，温疟痎疟，气注背膊拘急，颈项强不得回顾，风劳食气、骨热，前板齿燥。
```

# 少海

> **类型**：穴位
> **语料频次**：36 次（分布：— / — / — / — / 针灸 36）
> **归属**：手少阴心经

## 一、原文（《针灸大成》专条）
```
◎少海： 在肘内廉节后，大骨外，去肘端五分，屈肘向头取之。 针三分， 灸三壮。
```

## 二、语料中的实际使用

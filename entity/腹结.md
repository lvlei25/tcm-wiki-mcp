# 腹结

> **类型**：穴位
> **语料频次**：9 次（分布：— / — / — / 参西录 1 / 针灸 8）
> **归属**：足太阴脾经

## 一、原文（《针灸大成》专条）
```
腹结于脐，循腹里，结于肋，散于胸中；其内者，着于脊。其病足大趾支内踝痛，转筋痛，膝内辅骨痛，阴股引髀而痛，阴器纽痛，下引脐两胁痛，引膺中脊内痛。治在燔针劫刺，以知为数，以痛为输，名曰孟秋痹也。
```

## 二、语料中的实际使用
《针灸大成》载8次，为该书腧穴条目。
另在《参西录》中出现1次，属临床配穴使用。

# 攒竹

> **类型**：穴位
> **语料频次**：49 次（分布：— / — / — / — / 针灸 49）
> **归属**：足太阳膀胱经

## 一、原文（《针灸大成》专条）
```
◎攒竹： 在两眉头小陷宛宛中。 针三分，三度刺，目大明，宜用锋针出血。 禁灸。
```

## 二、语料中的实际使用
《针灸大成》载49次，为该书腧穴条目。

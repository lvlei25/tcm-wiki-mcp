# 小肠俞

> **类型**：穴位
> **语料频次**：14 次（分布：— / — / — / — / 针灸 14）
> **归属**：足太阳膀胱经

## 一、原文（《针灸大成》专条）
```
小肠俞： 十八椎下两旁相去脊各一寸五分，伏而取之。 《铜人》针三分，留六呼，灸三壮。 主膀胱、三焦津液少，大、小肠寒热，小便赤不利，淋沥遗溺，小腹胀满，疞痛，泄利脓血。 五色赤痢下重，肿痛。 脚肿。 五痔，头痛，虚乏消渴，口干不可忍，妇人带下。
```

## 二、语料中的实际使用
《针灸大成》载14次，为该书腧穴条目。

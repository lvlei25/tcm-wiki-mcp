# 血海

> **类型**：穴位
> **语料频次**：36 次（分布：丁 1 / 傅女 10 / — / 参西录 12 / 针灸 13）
> **归属**：足太阴脾经
> **别名**：《针灸大成》作「百虫窠」

## 一、原文（《针灸大成》专条）
```
血海： 膝膑上内廉，白肉际二寸半。 《铜人》针五分，灸三壮。 主气逆腹胀，女子漏下恶血，月事不调。
```

## 二、语料中的实际使用
《针灸大成》载13次，为该书腧穴条目。
另在《丁甘仁、傅女、参西录》中出现23次，属临床配穴使用。

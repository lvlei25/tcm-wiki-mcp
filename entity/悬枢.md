# 悬枢

> **类型**：穴位
> **语料频次**：3 次（分布：— / — / — / — / 针灸 3）
> **归属**：经外奇穴

## 一、原文（《针灸大成》专条）
```
悬枢： 十三椎下，伏而取之。 《铜人》针三分，灸三壮。 主腰脊强不得屈伸，积气上下行，水谷不化，下利，腹中留积。
```

## 二、语料中的实际使用
《针灸大成》载3次，为该书腧穴条目。

# 囊底

> **类型**：穴位
> **语料频次**：2 次（分布：— / — / — / — / 针灸 2）
> **归属**：经外奇穴

## 一、原文（《针灸大成》专条）
```
◎囊底： 一穴，在阴囊十字纹中。 治肾脏风疮，及治小肠疝气，肾家一切症候，悉皆治之。 灸七壮，艾炷如鼠粪。
```

## 二、语料中的实际使用
《针灸大成》载2次，为该书腧穴条目。

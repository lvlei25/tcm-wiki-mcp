# 太白

> **类型**：穴位
> **语料频次**：50 次（分布：— / — / — / — / 针灸 50）
> **归属**：足太阴脾经

## 一、原文（《针灸大成》专条）
```
太白： 足大趾内侧，内踝前核骨下陷中。 脾脉所注为俞土。 《铜人》针三分，灸三壮。 主身热烦满，腹胀食不化，呕吐，泄泻脓血，腰痛大便难，气逆，霍乱腹中切痛，肠鸣，膝股胻酸转筋，身重骨痛，胃心痛，腹胀胸满，心痛脉缓。
```

## 二、语料中的实际使用
《针灸大成》载50次，为该书腧穴条目。

### 作为配穴出现于

- **作为公孙、内关的配穴出现 3 次**（公孙 2 次，内关 1 次）

  - 随公孙：气膈五噎，饮食不下；脾胃气虚，心腹胀满

# 腰俞

> **类型**：穴位
> **语料频次**：18 次（分布：— / — / — / — / 针灸 18）
> **归属**：督脉

## 一、原文（《针灸大成》专条）
```
◎腰俞： 在二十一椎下宛宛中，自大椎至此，折三尺，舒身以腹挺地，两手相重支额，纵四体，后乃取之。 针八分，灸七壮，至二十一壮。
```

## 二、语料中的实际使用
《针灸大成》载18次，为该书腧穴条目。

## 五、治法与配穴关系

### 作为配穴出现于

- **作为公孙、足临泣、后溪、内关的配穴出现 8 次**（公孙 2 次，足临泣 2 次，后溪 2 次，内关 2 次）
- 所治病症（去重后按主穴分列）：

  - 随公孙：闪挫腰痛，起止艰难；虚损湿滞腰痛，行动无力
  - 随足临泣：闪挫腰痛，起止艰难；虚损湿滞腰痛，行动无力
  - 随后溪：闪挫腰痛，起止艰难；虚损湿滞腰痛，行动无力
  - 随内关：闪挫腰痛，起止艰难；虚损湿滞腰痛，行动无力

### 操作与禁忌

- **操作**：针八分　留三呼　灸七壮

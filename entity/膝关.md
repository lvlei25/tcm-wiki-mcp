# 膝关

> **类型**：穴位
> **语料频次**：13 次（分布：— / — / — / — / 针灸 13）
> **归属**：足厥阴肝经

## 一、原文（《针灸大成》专条）
```
膝关： 犊鼻下二寸旁陷中。 《铜人》针四分，灸五壮。 主风痹，膝内廉痛引膑，不可屈伸，咽喉中痛。
```

## 二、语料中的实际使用
《针灸大成》载13次，为该书腧穴条目。

## 五、治法与配穴关系

### 作为配穴出现于

- **作为公孙、后溪、内关、足临泣的配穴出现 7 次**（公孙 2 次，后溪 2 次，内关 2 次，足临泣 1 次）
- 所治病症（去重后按主穴分列）：

  - 随公孙：中风四肢麻痹不仁；两膝红肿疼痛，名曰鹤膝风
  - 随足临泣：两膝红肿疼痛，名曰鹤膝风
  - 随后溪：中风四肢麻痹不仁；两膝红肿疼痛，名曰鹤膝风
  - 随内关：中风四肢麻痹不仁；两膝红肿疼痛，名曰鹤膝风

# 百虫窠

> **类型**：穴位
> **语料频次**：3 次（分布：— / — / — / — / 针灸 3）
> **归属**：经外奇穴

## 一、原文（《针灸大成》专条）
```
◎百虫窠： 二穴，即血海也。 在膝内廉上三寸，灸二七壮，针五分。 治下部生疮。
```

## 二、语料中的实际使用
《针灸大成》载3次，为该书腧穴条目。

# 翳风

> **类型**：穴位
> **语料频次**：18 次（分布：— / — / — / — / 针灸 18）
> **归属**：手少阳三焦经

## 一、原文（《针灸大成》专条）
```
翳风： 耳后尖角陷中，按之引耳中痛。 《针经》先以铜钱二十文，令患人咬之，寻取穴中。 手足少阳之会。 《素注》针三分。 《铜人》针七分，灸七壮。 《明堂》灸三壮。 针灸俱令人咬钱，令口开。 主耳鸣、耳聋，口眼㖞斜，脱颔颊肿，口噤不开，不能言，口吃，牙车急，小儿喜欠。
```

## 二、语料中的实际使用
《针灸大成》载18次，为该书腧穴条目。

# 附分

> **类型**：穴位
> **语料频次**：5 次（分布：— / — / — / 参西录 1 / 针灸 4）
> **归属**：足太阳膀胱经

## 一、原文（《针灸大成》专条）
```
附分： 二椎下，附项内廉，两旁相去脊各三寸，正坐取之。 手足太阳之会。 《铜人》针三分。 《素注》刺八分，灸五壮。 主肘不仁，肩背拘急，风冷客于腠理，颈痛不得回顾。
```

## 二、语料中的实际使用
《针灸大成》载4次，为该书腧穴条目。
另在《参西录》中出现1次，属临床配穴使用。

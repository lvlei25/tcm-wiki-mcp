# 长强

> **类型**：穴位
> **语料频次**：30 次（分布：— / — / — / — / 针灸 30）
> **归属**：督脉

## 一、原文（《针灸大成》专条）
```
◎长强： 在骶骨端下三分。 针三分，灸三十壮。 以上肩背部。
```

## 二、语料中的实际使用
《针灸大成》载30次，为该书腧穴条目。

### 作为配穴出现于

- **作为公孙、内关的配穴出现 4 次**（公孙 2 次，内关 2 次）

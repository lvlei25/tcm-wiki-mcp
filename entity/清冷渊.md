# 清冷渊

> **类型**：穴位
> **语料频次**：4 次（分布：— / — / — / — / 针灸 4）
> **归属**：经外奇穴

## 一、原文（《针灸大成》专条）
```
清冷渊： 肘上二寸，伸肘举臂取之。 《铜人》针二分，灸三壮。 主肩痹痛，臂臑不能举，不能带衣。
```

## 二、语料中的实际使用
《针灸大成》载4次，为该书腧穴条目。

# 臑俞

> **类型**：穴位
> **语料频次**：6 次（分布：— / — / — / — / 针灸 6）
> **归属**：手太阳小肠经

## 一、原文（《针灸大成》专条）
```
臑俞： 侠肩髃（手阳明穴）后大骨下，胛上廉陷中，举臂取之。 手太阳、阳维、阳𫏋三脉之会。 《铜人》针八分，灸三壮。 主臂酸无力，肩痛引胛，寒热气肿胫痛。
```

## 二、语料中的实际使用
《针灸大成》载6次，为该书腧穴条目。

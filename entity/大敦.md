# 大敦

> **类型**：穴位
> **语料频次**：75 次（分布：— / — / — / — / 针灸 75）
> **归属**：足厥阴肝经

## 一、原文（《针灸大成》专条）
```
大敦： 足大趾端，去爪甲如韭叶，及三毛中。 足厥阴肝脉所出为井木。 《铜人》针三分，留十呼，灸三壮。 主五淋，卒疝七疝，小便数遗不禁，阴头中痛，汗出，阴上入小腹，阴偏大，腹脐中痛，悒悒不乐，病左取右，病右取左。 腹胀肿病，小腹痛，中热喜寐，尸厥状如死人，妇人血崩不止，阴挺出，阴中痛。
```

## 二、语料中的实际使用
《针灸大成》载75次，为该书腧穴条目。

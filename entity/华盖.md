# 华盖

> **类型**：穴位
> **语料频次**：13 次（分布：丁 1 / — / — / 参西录 3 / 针灸 9）
> **归属**：任脉

## 一、原文（《针灸大成》专条）
```
华盖： 璇玑下一寸六分陷中，仰面取之。 《铜人》针三分，灸五壮。 《明下》灸三壮。 主喘急上气，咳逆哮嗽，喉痹咽肿，水浆不下，胸胁支满痛。
```

## 二、语料中的实际使用
《针灸大成》载9次，为该书腧穴条目。
另在《丁甘仁、参西录》中出现4次，属临床配穴使用。

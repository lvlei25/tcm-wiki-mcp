# 风市

> **类型**：穴位
> **语料频次**：38 次（分布：— / — / — / — / 针灸 38）
> **归属**：足少阳胆经

## 一、原文（《针灸大成》专条）
```
风市： 膝上外廉两筋中，以手着腿，中指尽处是。 针五分，灸五壮。 主中风腿膝无力，脚气，浑身搔痒，麻痹，厉风疮。
```

## 二、语料中的实际使用
《针灸大成》载38次，为该书腧穴条目。

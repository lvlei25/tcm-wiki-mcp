# 行间

> **类型**：穴位
> **语料频次**：81 次（分布：— / — / — / — / 针灸 81）
> **归属**：足厥阴肝经

## 一、原文（《针灸大成》专条）
```
行间： 足大趾缝间，动脉应手陷中。 足厥阴肝脉所溜为荥火。 肝实则泻之。 《素注》针三分。 《铜人》灸三壮，针六分，留十呼。 主呕逆，洞泄，遗溺癃闭，消渴嗜饮，善怒，四肢满，转筋，胸胁痛，小腹肿，咳逆呕血，茎中痛，腰疼不可俯仰，腹中胀，小肠气，肝心痛，色苍苍如死状，终日不得息，口㖞，癫疾，短气，四肢逆冷，嗌干烦渴，瞑不欲视，目中泪出，太息，便溺难，七疝寒疝，中风，肝积肥气，发痎疟，妇人小腹肿，面尘脱色，经血过多不止，崩中，小儿急惊风。
```

## 二、语料中的实际使用
《针灸大成》载81次，为该书腧穴条目。

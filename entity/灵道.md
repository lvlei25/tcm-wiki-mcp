# 灵道

> **类型**：穴位
> **语料频次**：14 次（分布：— / — / — / — / 针灸 14）
> **归属**：手少阴心经

## 一、原文（《针灸大成》专条）
```
灵道： 掌后一寸五分，手少阴心脉所行为经金。 《铜人》针三分，灸三壮。 主心痛，干呕，悲恐，相引瘛疭，肘挛，暴喑不能言。
```

## 二、语料中的实际使用
《针灸大成》载14次，为该书腧穴条目。

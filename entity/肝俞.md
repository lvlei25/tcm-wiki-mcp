# 肝俞

> **类型**：穴位
> **语料频次**：48 次（分布：— / — / — / — / 针灸 48）
> **归属**：足太阳膀胱经

## 一、原文（《针灸大成》专条）
```
肝俞： 九椎下两旁相去脊各一寸五分，正坐取之。
```

## 二、语料中的实际使用
《针灸大成》载48次，为该书腧穴条目。

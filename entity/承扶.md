# 承扶

> **类型**：穴位
> **语料频次**：6 次（分布：— / — / — / — / 针灸 6）
> **归属**：经外奇穴

## 一、原文（《针灸大成》专条）
```
承扶、秩边而胞肓。入志室兮肓门、胃仓，开意舍兮振彼阳纲。出魂门兮膈关，乃譩嘻乎神堂。膏肓兮在四椎之左右，魄户兮随附分而会阳。下、中、次、上之髎，白环、中膂之房。膀胱俞兮小肠，大肠俞兮在旁。三焦、肾俞兮胃俞接，脾、胆、肝、膈兮心俞当。厥阴、肺俞之募，风门、大杼之方。天柱坚兮玉枕、络却，通天溪兮见彼承光。自五处、曲差而下，造攒竹、睛明之场 ① 。
```

## 二、语料中的实际使用
《针灸大成》载6次，为该书腧穴条目。

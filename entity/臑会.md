# 臑会

> **类型**：穴位
> **语料频次**：7 次（分布：— / — / — / — / 针灸 7）
> **归属**：手少阳三焦经

## 一、原文（《针灸大成》专条）
```
臑会，又与手足少阳会于天髎，又与手足少阳、足阳明会于肩井。其在头也，与足少阳会于阳白，上于本神及临泣、目窗、上至正营、承灵，循于脑空，下至风池、日月；其与督脉会，则在风府及哑门。其为病也，苦寒热。凡三十二穴。
```

## 二、语料中的实际使用
《针灸大成》载7次，为该书腧穴条目。

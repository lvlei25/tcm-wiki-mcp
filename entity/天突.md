# 天突

> **类型**：穴位
> **语料频次**：45 次（分布：— / — / — / 参西录 12 / 针灸 33）
> **归属**：任脉

## 一、原文（《针灸大成》专条）
```
天突于璇玑，捣华盖于紫宫。登玉堂兮膻中集，履中庭兮鸠尾冲。瞻巨阙兮二脘上中，过建里兮下脘攸同。水分兮神阙缥缈，阴交兮气海鸿蒙。石门直兮关元、中极，曲骨横兮会阴乃终 ① 。
```

## 二、语料中的实际使用
《针灸大成》载33次，为该书腧穴条目。
另在《参西录》中出现12次，属临床配穴使用。

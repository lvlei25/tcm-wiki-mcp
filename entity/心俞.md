# 心俞

> **类型**：穴位
> **语料频次**：48 次（分布：— / — / — / — / 针灸 48）
> **归属**：足太阳膀胱经

## 一、原文（《针灸大成》专条）
```
心俞： 五椎下两旁相去脊各一寸五分，正坐取之。 《铜人》针三分，留七呼，得气即泻，不可灸。 《明堂》灸三壮。 《资生》云： 『刺中心一日死，其动为噫，岂可妄针。 』《千金》言： 『中风心急，灸心俞百壮，当权其缓急可也。 』 主偏风半身不遂，心气乱恍惚，心中风，偃卧不得倾侧，汗出唇赤，狂走发痫，语悲泣，心胸闷乱，咳吐血，黄疸，鼻衄，目𥆧目昏，呕吐不下食，健忘，小儿心气不足，数岁不语。
```

## 二、语料中的实际使用
《针灸大成》载48次，为该书腧穴条目。

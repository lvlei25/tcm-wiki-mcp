# 颊车

> **类型**：穴位
> **语料频次**：55 次（分布：丁 1 / — / — / — / 针灸 54）
> **归属**：足阳明胃经

## 一、原文（《针灸大成》专条）
```
◎颊车： 主落架风。 ## 经外奇穴（杨氏） 经外奇穴（杨氏）
```

## 二、语料中的实际使用
《针灸大成》载54次，为该书腧穴条目。
另在《丁甘仁》中出现1次，属临床配穴使用。

  - **循行与属性**：起头维，终厉兑，气血俱多，辰时注此
  - **是动病**：洒洒然振寒，善呻数欠，颜黑。病至恶人与火，闻木音则惕然而惊……甚则欲登高而歌，弃衣而走，贲响腹胀，是谓骭厥

# 志室

> **类型**：穴位
> **语料频次**：3 次（分布：— / — / — / — / 针灸 3）
> **归属**：经外奇穴

## 一、原文（《针灸大成》专条）
```
志室： 十四椎下两旁相去脊各三寸陷中，正坐取之。 《铜人》针九分，灸三壮。 《明堂》灸七壮。 主阴肿，阴痛，背痛，腰脊强直，俯仰不得，饮食不消，腹强直，梦遗失精，淋沥，吐逆，两胁急痛，霍乱。
```

## 二、语料中的实际使用
《针灸大成》载3次，为该书腧穴条目。

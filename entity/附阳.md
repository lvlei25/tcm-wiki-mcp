# 附阳

> **类型**：穴位
> **语料频次**：7 次（分布：— / — / — / — / 针灸 7）
> **归属**：足太阳膀胱经

## 一、原文（《针灸大成》专条）
```
附阳： 外踝上三寸，太阳前，少阳后，筋骨之间。 阳𫏋脉郄。 《铜人》针五分，灸三壮，留七呼。 《素注》针六分，留七呼，灸三壮。 《明堂》灸五壮。 主霍乱转筋，腰痛不能久立，坐不能起，髀枢股胻痛，痿厥，风痹不仁，头重杂痛，时有寒热，四肢不举。
```

## 二、语料中的实际使用
《针灸大成》载7次，为该书腧穴条目。

# 曲骨

> **类型**：穴位
> **语料频次**：6 次（分布：— / — / — / — / 针灸 6）
> **归属**：任脉

## 一、原文（《针灸大成》专条）
```
曲骨： 横骨上，中极下一寸，毛际陷中，动脉应手。 足厥阴、任脉之会。 《铜人》灸七壮、至七七壮。 针二寸。 《素注》针六分，留七呼。
```

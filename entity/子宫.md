# 子宫

> **类型**：穴位
> **语料频次**：32 次（分布：— / 傅女 17 / — / 参西录 7 / 针灸 8）
> **归属**：经外奇穴

## 一、原文（《针灸大成》专条）
```
◎子宫： 二穴，在中极两旁各开三寸。 针二寸，灸二七壮。 治妇人久无子嗣。
```

## 二、语料中的实际使用
《针灸大成》载8次，为该书腧穴条目。
另在《傅女、参西录》中出现24次，属临床配穴使用。

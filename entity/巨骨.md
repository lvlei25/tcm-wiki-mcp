# 巨骨

> **类型**：穴位
> **语料频次**：7 次（分布：— / — / — / — / 针灸 7）
> **归属**：手阳明大肠经

## 一、原文（《针灸大成》专条）
```
巨骨： 肩尖端上行，两叉骨罅间陷中。 手阳明、阳𫏋之会。 《铜人》灸五壮，针一寸半。 《明堂》灸三壮至七壮。 《素注》禁针。 针则倒悬，一食顷，乃得下针，针四分，泻之勿补，针出始得正卧，《明堂》灸三壮。 主惊痫，破心吐血，臂膊痛，胸中有瘀血，肩臂不得屈伸。
```

## 二、语料中的实际使用
《针灸大成》载7次，为该书腧穴条目。

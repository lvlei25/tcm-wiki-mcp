# 隐白

> **类型**：穴位
> **语料频次**：46 次（分布：— / — / — / 参西录 3 / 针灸 43）
> **归属**：足太阴脾经

## 一、原文（《针灸大成》专条）
```
隐白： 足大趾端内侧，去爪甲角如韭叶。 脾脉所出为井木。 《素注》针一分，留三呼。 《铜人》针三分，灸三壮。 主腹胀，喘满不得安卧，呕吐食不下，胸中热，暴泄，衄血，尸厥不识人，足寒不能温，妇人月事过时不止，小儿客忤，慢惊风。
```

## 二、语料中的实际使用
《针灸大成》载43次，为该书腧穴条目。
另在《参西录》中出现3次，属临床配穴使用。

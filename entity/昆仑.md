# 昆仑

> **类型**：穴位
> **语料频次**：81 次（分布：— / — / — / — / 针灸 81）
> **归属**：足太阳膀胱经

## 一、原文（《针灸大成》专条）
```
昆仑： 足外踝后五分，跟骨上陷中，细脉动应手。 足太阳膀胱脉所行为经火。 《素注》针五分，留十呼。 《铜人》针三分，灸三壮。 妊妇刺之落胎。 主腰尻脚气，足腨肿不得履地，鼽衄，腘如结，踝如裂，头痛，肩背拘急，咳喘满，腰脊内引痛，伛偻，阴肿痛，目眩痛如脱，疟多汗，心痛与背相接，妇人孕难，胞衣不出，小儿发痫瘛疭。
```

## 二、语料中的实际使用
《针灸大成》载81次，为该书腧穴条目。

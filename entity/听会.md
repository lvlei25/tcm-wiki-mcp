# 听会

> **类型**：穴位
> **语料频次**：31 次（分布：— / — / — / — / 针灸 31）
> **归属**：足少阳胆经

## 一、原文（《针灸大成》专条）
```
听会： 耳微前陷中，上关下一寸，动脉宛宛中，张口得之。 《铜人》针三分，留三呼，得气即泻，不须补。 日灸五壮，止三七壮，十日后依前报灸。 《明堂》针三分，灸三壮。 主耳鸣耳聋，牙车臼脱，相离一、二寸，牙车急不得嚼物，齿痛恶寒物，狂走瘛疭，恍惚不乐，中风口斜，手足不随。
```

## 二、语料中的实际使用
《针灸大成》载31次，为该书腧穴条目。

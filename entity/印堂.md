# 印堂

> **类型**：穴位
> **语料频次**：19 次（分布：— / — / — / — / 针灸 19）
> **归属**：经外奇穴

## 一、原文（《针灸大成》专条）
```
◎印堂： 一穴，在两眉中陷中是穴。 针一分，灸五壮。 治小儿惊风。
```

## 二、语料中的实际使用
《针灸大成》载19次，为该书腧穴条目。

## 五、治法与配穴关系

### 作为配穴出现于

- **作为公孙、后溪、内关的配穴出现 6 次**（公孙 2 次，后溪 2 次，内关 2 次）
- 所治病症（去重后按主穴分列）：

  - 随公孙：两眉角痛不已；中风不省人事
  - 随后溪：两眉角痛不已；中风不省人事
  - 随内关：两眉角痛不已；中风不省人事

### 操作与禁忌

- **操作**：针一分　灸五壮

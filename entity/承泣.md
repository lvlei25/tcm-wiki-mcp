# 承泣

> **类型**：穴位
> **语料频次**：7 次（分布：— / — / — / — / 针灸 7）
> **归属**：经外奇穴

## 一、原文（《针灸大成》专条）
```
承泣： 目下七分，直瞳子陷中。 足阳明、阳𫏋脉、任脉之会。 《铜人》灸三壮；禁针，针之令人目乌色。 《明堂》针四分半；不宜灸，灸后令人目下大如拳，息肉日加如桃，至三十日定不见物。 《资生》云： 『当不灸不针。 』
```

## 二、语料中的实际使用
《针灸大成》载7次，为该书腧穴条目。

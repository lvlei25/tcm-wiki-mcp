# 间使

> **类型**：穴位
> **语料频次**：66 次（分布：— / — / — / — / 针灸 66）
> **归属**：手厥阴心包经

## 一、原文（《针灸大成》专条）
```
间使： 掌后三寸，两筋间陷中。 心包络脉所行为经金。 《素注》针六分，留七呼。 《铜人》针三分，灸五壮。 《明堂》灸七壮。 《甲乙》灸三壮。 主伤寒结胸，心悬如饥，卒狂，胸中澹澹，恶风寒，呕沫，怵惕，寒中少气，掌中热，腋肿肘挛，卒心痛，多惊，中风气塞，涎上昏危，喑不得语，咽中如梗，鬼邪，霍乱干呕，妇人月水不调，血结成块，小儿客忤。
```

## 二、语料中的实际使用
《针灸大成》载66次，为该书腧穴条目。

# 肺俞

> **类型**：穴位
> **语料频次**：69 次（分布：丁 1 / — / — / 参西录 2 / 针灸 66）
> **归属**：足太阳膀胱经·背俞穴
> **语料所载主治**：咳嗽、喘促、肺痨

## 一、原文定位（《针灸大成》专条）
```
肺俞： 第三椎下两旁相去脊各一寸五分。 《千金》对乳引绳度之。 甄权以搭手，左取右，右取左，当中指末是，正坐取之。 《甲乙》针三分，留七呼，得气即泻。 甄权灸百壮。 《明下》灸三壮。 《素问》刺中肺三日死，其动为咳。 主瘿气，黄疸，劳瘵，口舌干，劳热上气，腰脊强痛，寒热喘满，虚烦，传尸骨蒸，肺痿咳嗽，肉痛皮痒，呕吐，支满不嗜食，狂走，欲自杀，背偻，肺中风，偃卧，胸满短气，瞀闷汗出，百毒病，食后吐水，小儿龟背。
```

## 二、语料中的实际使用
《针灸大成》载66次，是该书高频用穴；内容分布在卷四（腧穴主治歌诀）、卷五（脏腑辨证取穴）诸篇。
此外《丁甘仁、参西录》中亦有3次，属临床配穴使用。

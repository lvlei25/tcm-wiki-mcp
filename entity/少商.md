# 少商

> **类型**：穴位
> **语料频次**：78 次（分布：— / — / 傅男 1 / 参西录 6 / 针灸 71）
> **归属**：手太阴肺经

## 一、原文（《针灸大成》专条）
```
◎少商： 在大指内侧，去爪甲角如韭叶许。 针一分，宜用锋针出血，禁灸。 卯、手阳明大肠经
```

## 二、语料中的实际使用
《针灸大成》载71次，为该书腧穴条目。
另在《傅男、参西录》中出现7次，属临床配穴使用。

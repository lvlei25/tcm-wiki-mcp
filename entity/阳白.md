# 阳白

> **类型**：穴位
> **语料频次**：7 次（分布：— / — / — / — / 针灸 7）
> **归属**：足少阳胆经

## 一、原文（《针灸大成》专条）
```
阳白： 眉上一寸，直瞳子，手足阳明、少阳、阳维五脉之会。 《素注》针三分。 《铜人》针二分，灸三壮。 主瞳子痒痛，目上视，远视佴佴，昏夜无见，目痛目眵，背腠寒栗，重衣不得温。
```

## 二、语料中的实际使用
《针灸大成》载7次，为该书腧穴条目。

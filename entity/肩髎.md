# 肩髎

> **类型**：穴位
> **语料频次**：15 次（分布：— / — / — / — / 针灸 15）
> **归属**：手少阳三焦经

## 一、原文（《针灸大成》专条）
```
肩髎： 肩端腨上陷中，斜举臂取之。 《铜人》针七分，灸三壮。 《明堂》灸五壮。 主臂痛，肩重不能举。
```

## 二、语料中的实际使用
《针灸大成》载15次，为该书腧穴条目。

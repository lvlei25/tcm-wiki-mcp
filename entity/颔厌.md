# 颔厌

> **类型**：穴位
> **语料频次**：4 次（分布：— / — / — / — / 针灸 4）
> **归属**：足少阳胆经

## 一、原文（《针灸大成》专条）
```
颔厌： 曲周下，颞颥上廉。 手足少阳、阳明之会。 《铜人》灸三壮，针七分，留七呼，深刺令人耳聋。 主偏头痛，头风目眩，惊痫，手卷手腕痛，耳鸣，目无见，目外眦急，好嚏，颈痛，历节风汗出。
```

## 二、语料中的实际使用
《针灸大成》载4次，为该书腧穴条目。

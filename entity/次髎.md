# 次髎

> **类型**：穴位
> **语料频次**：2 次（分布：— / — / — / — / 针灸 2）
> **归属**：经外奇穴

## 一、原文（《针灸大成》专条）
```
次髎： 第二空侠脊陷中。 《铜人》针三分，灸七壮。 主小便赤淋，腰痛不得转摇，急引阴器痛不可忍，腰以下至足不仁，背腠寒，小便赤，心下坚胀，疝气下坠，足清气痛，肠鸣注泻，偏风，妇人赤白带下。
```

## 二、语料中的实际使用
《针灸大成》载2次，为该书腧穴条目。

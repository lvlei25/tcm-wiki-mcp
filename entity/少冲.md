# 少冲

> **类型**：穴位
> **语料频次**：42 次（分布：— / — / — / — / 针灸 42）
> **归属**：手少阴心经

## 一、原文（《针灸大成》专条）
```
◎少冲： 在小指内侧，去爪角韭叶。 针一分，灸一壮。 未、手太阳小肠经
```

## 二、语料中的实际使用
《针灸大成》载42次，为该书腧穴条目。

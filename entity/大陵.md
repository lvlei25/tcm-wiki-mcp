# 大陵

> **类型**：穴位
> **语料频次**：86 次（分布：— / — / — / — / 针灸 86）
> **归属**：手厥阴心包经

## 一、原文（《针灸大成》专条）
```
大陵： 掌后骨下，两筋间陷中。 手厥阴心包络脉所注为俞土。 心包络实泻之。 《铜人》针五分。 《素注》针六分，留七呼，灸三壮。 主热病汗不出，手心热，肘臂挛痛，腋肿，善笑不休，烦心，心悬若饥，心痛掌热，喜悲泣惊恐，目赤目黄，小便如血，呕?无度，狂言不乐，喉痹，口干，身热头痛，短气，胸胁痛，瘑疮疥癣。
```

## 二、语料中的实际使用
《针灸大成》载86次，为该书腧穴条目。

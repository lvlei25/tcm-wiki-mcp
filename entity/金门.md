# 金门

> **类型**：穴位
> **语料频次**：29 次（分布：— / — / — / — / 针灸 29）
> **归属**：足太阳膀胱经

## 一、原文（《针灸大成》专条）
```
◎金门： 在外踝下少后，丘墟后，申脉前。 针一分，灸三壮。
```

## 二、语料中的实际使用
《针灸大成》载29次，为该书腧穴条目。

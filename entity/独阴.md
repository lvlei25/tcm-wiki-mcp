# 独阴

> **类型**：穴位
> **语料频次**：5 次（分布：丁 1 / — / — / — / 针灸 4）
> **归属**：经外奇穴

## 一、原文（《针灸大成》专条）
```
◎独阴： 二穴，在足第二趾下，横纹中是穴。 治小肠疝气，又治死胎，胎衣不下，灸五壮。 又治女人干哕，呕吐红，经血不调。
```

## 二、语料中的实际使用
《针灸大成》载4次，为该书腧穴条目。
另在《丁甘仁》中出现1次，属临床配穴使用。

# 至阴

> **类型**：穴位
> **语料频次**：52 次（分布：— / 傅女 2 / 傅男 1 / 参西录 6 / 针灸 43）
> **归属**：足太阳膀胱经

## 一、原文（《针灸大成》专条）
```
至阴： 足小趾外侧，去爪甲角如韭叶。 足太阳脉所出为井金。 膀胱虚补之。 《铜人》针二分，灸三壮。 《素注》针一分，留五呼。 主目生翳，鼻塞头重，风寒从足小趾起，脉痹上下带胸胁痛无常处，转筋，寒疟，汗不出，烦心，足下热，小便不利，失精，目痛，大眦痛。
```

## 二、语料中的实际使用
《针灸大成》载43次，为该书腧穴条目。
另在《傅女、傅男、参西录》中出现9次，属临床配穴使用。

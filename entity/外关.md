# 外关

> **类型**：穴位
> **语料频次**：49 次（分布：— / — / — / — / 针灸 49）
> **归属**：手少阳三焦经

## 一、原文（《针灸大成》专条）
```
外关： 腕后二寸两骨间，与内关相对。 手少阳络，别走手心主。 《铜人》针三分，留七呼，灸二壮。 《明堂》灸三壮。 主耳聋，浑浑焞焞无闻，五指尽痛，不能握物。 实则肘挛，泻之；虚则不收，补之。 又治手臂不得屈伸。
```

## 二、语料中的实际使用
《针灸大成》载49次，为该书腧穴条目。

## 五、治法与配穴关系

### 八脉八穴（主客配对）

> 《针灸大成·八法交会八穴歌》：「八法交会八穴歌 公孙冲脉胃心胸，内关阴维下总同，临泣胆经连带脉，阳维目锐外关逢，后溪督脉内眦颈，申脉阳𫏋络亦通，列缺任脉行肺系，阴𫏋照海膈喉咙。」

- **所属**：手少阳三焦经，通阳维；本穴为主穴
- **配穴**：**足临泣**（通带脉），主客相应
- **主治摘要**（原文）：与足临泣主客相应

《八穴配合歌》：「八穴配合歌 公孙偏与内关合，列缺能消照海疴，临泣、外关分主客，后溪、申脉正相和。左针右病知高下，以意通经广按摩，补泻迎随分逆顺，五门八法是真科。」

要点：**「左针右病知高下」**——先取主穴，再视病位左右取配穴。

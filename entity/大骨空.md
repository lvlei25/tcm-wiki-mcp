# 大骨空

> **类型**：穴位
> **语料频次**：3 次（分布：— / — / — / — / 针灸 3）
> **归属**：经外奇穴

## 一、原文（《针灸大成》专条）
```
◎大骨空： 二穴。 在手大指中节上，屈指当骨尖陷中是穴。 治目久痛，及生翳膜内障，可灸七壮。
```

## 二、语料中的实际使用
《针灸大成》载3次，为该书腧穴条目。

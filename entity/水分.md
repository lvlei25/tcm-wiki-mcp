# 水分

> **类型**：穴位
> **语料频次**：48 次（分布：— / — / — / 参西录 3 / 针灸 45）
> **归属**：任脉

## 一、原文（《针灸大成》专条）
```
◎水分： 在脐上一寸。 水病灸之大良。 禁针，针之水尽即死。 其别病针八分，灸七壮，止四百壮。
```

## 二、语料中的实际使用
《针灸大成》载45次，为该书腧穴条目。
另在《参西录》中出现3次，属临床配穴使用。

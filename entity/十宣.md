# 十宣

> **类型**：穴位
> **语料频次**：27 次（分布：— / — / — / 参西录 3 / 针灸 24）
> **归属**：经外奇穴

## 一、原文（《针灸大成》专条）
```
◎十宣： 十穴，在手十指头上，去爪甲一分，每一指各一穴，两手指共十穴，故名十宣。 治乳蛾，用三棱针出血，大效。 或用软丝缚定本节前次节后，内侧中间，如眼状，加灸一火，两边都着艾，灸五壮，针尤妙。
```

## 二、语料中的实际使用
《针灸大成》载24次，为该书腧穴条目。
另在《参西录》中出现3次，属临床配穴使用。

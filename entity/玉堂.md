# 玉堂

> **类型**：穴位
> **语料频次**：8 次（分布：— / — / — / — / 针灸 8）
> **归属**：足少阴肾经

## 一、原文（《针灸大成》专条）
```
玉堂也；太阳根于至阴，结于目也；阳明根于厉兑，结于钳耳也；少阳根于窍阴，结于耳也；手太阳根于少泽，结于天窗、支正也；手少阳根于关冲，结于天牖、外关也；手阳明根于商阳，结于扶突、偏历也。』手三阴之经不载，不敢强注。又云：『四根者，耳根、鼻根、乳根、脚根也。三结者，胸结、肢结、便结也。』
```

## 二、语料中的实际使用
《针灸大成》载8次，为该书腧穴条目。

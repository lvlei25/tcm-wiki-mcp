# 彧中

> **类型**：穴位
> **语料频次**：6 次（分布：— / — / — / — / 针灸 6）
> **归属**：足少阴肾经

## 一、原文（《针灸大成》专条）
```
彧中： 俞府下一寸六分陷中，去胸中行各二寸，仰而取之。 《铜人》针四分，灸五壮。 《明堂》灸三壮。 主咳逆喘息不能食，胸胁支满，涎出多唾。
```

## 二、语料中的实际使用
《针灸大成》载6次，为该书腧穴条目。

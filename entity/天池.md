# 天池

> **类型**：穴位
> **语料频次**：12 次（分布：— / — / — / — / 针灸 12）
> **归属**：手厥阴心包经

## 一、原文（《针灸大成》专条）
```
天池，终中冲。多血少气，戌时注此。是动病：手心热，肘臂挛急，腋肿。甚则胸胁支满，心中澹澹，或大动，面赤，目黄，喜笑不休。是主脉所生病：烦心，心痛，掌中热。盛者，寸口大一倍于人迎。虚者，寸口反小于人迎也。补用亥时，中冲，为井木。木生火，虚则补其母。泻用戌时，大陵，为俞土。火生土，实则泻其子。
```

## 二、语料中的实际使用
《针灸大成》载12次，为该书腧穴条目。

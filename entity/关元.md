# 关元

> **类型**：穴位
> **语料频次**：67 次（分布：— / — / — / 参西录 1 / 针灸 66）
> **归属**：任脉·小肠募穴
> **语料所载主治**：虚劳、遗精、尿频、孕产要穴

## 一、原文定位（《针灸大成》专条）
```
关元： 脐下三寸。 小肠之募。 足三阴，任脉之会。 下纪者，关元也。 《素注》针一寸二分，留七呼，灸七壮。
```

## 二、语料中的实际使用
《针灸大成》载66次，是该书高频用穴；内容分布在卷四（腧穴主治歌诀）、卷五（脏腑辨证取穴）诸篇。
此外《参西录》中亦有1次，属临床配穴使用。

## 三、原文证据
> **（《参西录》）**「……，其背恶寒者，当灸之，附子汤主之。 陈修园曰∶此宜灸鬲关二穴以救太阳之寒，再灸关元一穴以助元阳之气。 元阳存于何处？盖人身有两气海，《内经》谓膈上为气海，此后天之气海，所藏者宗气也（即胸中大气）。 哲学家以脐下为气海，此先天之气海，所藏者祖气，即元气也。人身之元阳，以元气为体质，元气即以元阳为主宰，诚以其能斡旋全身则为元气，能温暖全身则为元阳，此元阳本于先天，原为先天之君火，以命门之相火为之辅佐者也（此与以心火为君火，以肝中所寄之少阳相火为相火者，有先天后天之分）。至下焦气……」（全书 1 次）

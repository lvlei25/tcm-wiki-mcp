> **类型**：穴位
> **语料频次**：5 次（分布：— / — / — / — / 针灸 5）

## 一、原文（《针灸大成》专条）
```
郄门： 掌后去腕五寸，手厥阴心包络脉隙。 《铜人》针三分，灸五壮。 主呕血，衄血，心痛，呕，哕，惊恐畏人，神气不足。
```

## 二、语料中的实际使用

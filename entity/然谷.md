# 然谷

> **类型**：穴位
> **语料频次**：47 次（分布：— / — / — / — / 针灸 47）
> **归属**：足少阴肾经

## 一、原文（《针灸大成》专条）
```
◎然谷： 在内踝前，大骨下陷中。 针三分，不宜见血，灸三壮。
```

## 二、语料中的实际使用
《针灸大成》载47次，为该书腧穴条目。

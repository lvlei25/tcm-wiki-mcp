# 申脉

> **类型**：穴位
> **语料频次**：57 次（分布：— / — / — / — / 针灸 57）
> **归属**：足太阳膀胱经

## 一、原文（《针灸大成》专条）
```
◎申脉： 在外踝下五分陷中，容爪甲白肉际，前后有筋，上有踝骨，下有 软骨，其穴居中。 针三分。
```

## 二、语料中的实际使用
《针灸大成》载57次，为该书腧穴条目。

## 五、治法与配穴关系

### 八脉八穴（主客配对）

> 《针灸大成·八法交会八穴歌》：「八法交会八穴歌 公孙冲脉胃心胸，内关阴维下总同，临泣胆经连带脉，阳维目锐外关逢，后溪督脉内眦颈，申脉阳𫏋络亦通，列缺任脉行肺系，阴𫏋照海膈喉咙。」

- **所属**：足太阳膀胱经，通阳跷；本穴为主穴
- **配穴**：**后溪**（通督脉），主客相应
- **主治摘要**（原文）：申脉阳跷络亦通

《八穴配合歌》：「八穴配合歌 公孙偏与内关合，列缺能消照海疴，临泣、外关分主客，后溪、申脉正相和。左针右病知高下，以意通经广按摩，补泻迎随分逆顺，五门八法是真科。」

要点：**「左针右病知高下」**——先取主穴，再视病位左右取配穴。

### 作为配穴出现于

- **作为公孙、后溪、内关、足临泣的配穴出现 11 次**（公孙 4 次，后溪 3 次，内关 3 次，足临泣 1 次）
- 所治病症（去重后按主穴分列）：

  - 随公孙：肾疟，令人洒热，腰脊强痛；咳嗽寒痰；头痛难低；足跗肿痛，久不能消
  - 随足临泣：足跗肿痛，久不能消
  - 随后溪：咳嗽寒痰；头痛难低；足跗肿痛，久不能消
  - 随内关：咳嗽寒痰；头痛难低；足跗肿痛，久不能消

### 操作与禁忌

- **操作**：针三分　留七呼　灸三壮

# 身柱

> **类型**：穴位
> **语料频次**：9 次（分布：— / — / — / — / 针灸 9）
> **归属**：督脉

## 一、原文（《针灸大成》专条）
```
身柱： 三椎下，俯而取之。 《铜人》针五分，灸七七壮，止百壮，《明堂》灸五壮。 《下经》灸三壮。 主腰脊痛，癫病狂走，瘛疭，怒欲杀人。 身热，妄言见鬼，小儿惊痫。 《难经》云： 『治洪长伏三脉。 风痫发狂，恶人与火，灸三椎，九椎。 』
```

## 二、语料中的实际使用
《针灸大成》载9次，为该书腧穴条目。

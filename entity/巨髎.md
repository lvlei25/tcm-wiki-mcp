# 巨髎

> **类型**：穴位
> **语料频次**：8 次（分布：— / — / — / — / 针灸 8）
> **归属**：经外奇穴

## 一、原文（《针灸大成》专条）
```
巨髎： 侠鼻孔旁八分，直瞳子，平水沟，手足阳明、阳𫏋脉之会。 《铜人》针三分，得气即泻；灸七壮。 《明堂》灸七七壮。 主瘛疭，唇颊肿痛，口㖞斜，目障无见，远视佴佴，淫肤白膜，翳覆瞳子，面风鼻杂肿臃痛，招摇视瞻，脚气膝肿。
```

## 二、语料中的实际使用
《针灸大成》载8次，为该书腧穴条目。

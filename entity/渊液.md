# 渊液

> **类型**：穴位
> **语料频次**：8 次（分布：— / — / — / — / 针灸 8）
> **归属**：经外奇穴

## 一、原文（《针灸大成》专条）
```
渊液泄兮肩井盈。临风池兮脑空鸣，穷窍阴兮完骨明。举浮白于天冲，接承灵于正营。目窗兮临泣，阳白兮本神。率谷回兮曲鬓出，悬厘降兮悬颅承。颔厌兮嘉客主人，听会兮瞳子髎迎 ① 。
```

## 二、语料中的实际使用
《针灸大成》载8次，为该书腧穴条目。

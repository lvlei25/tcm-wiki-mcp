# 髋骨

> **类型**：穴位
> **语料频次**：10 次（分布：— / — / — / — / 针灸 10）
> **归属**：经外奇穴

## 一、原文（《针灸大成》专条）
```
◎髋骨： 四穴，在梁丘两旁，各开一寸五分，两足共四穴。 治腿痛，灸七壮。
```

## 二、语料中的实际使用
《针灸大成》载10次，为该书腧穴条目。

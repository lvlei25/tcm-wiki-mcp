# 阳交

> **类型**：穴位
> **语料频次**：16 次（分布：丁 1 / — / — / 参西录 1 / 针灸 14）
> **归属**：足少阳胆经

## 一、原文（《针灸大成》专条）
```
阳交、阳陵。西出阳关兮，抵中渎、风市之境；环跳、居髎兮，循维道、五枢之宫。考夫带脉，询至京门。日月丽兮辄筋荣，渊液泄兮肩井盈。临风池兮脑空鸣，穷窍阴兮完骨明。举浮白于天冲，接承灵于正营。目窗兮临泣，阳白兮本神。率谷回兮曲鬓出，悬厘降兮悬颅承。颔厌兮嘉客主人，听会兮瞳子髎迎 ① 。
```

## 二、语料中的实际使用
《针灸大成》载14次，为该书腧穴条目。
另在《丁甘仁、参西录》中出现2次，属临床配穴使用。

# 阳关

> **类型**：穴位
> **语料频次**：13 次（分布：— / — / — / 参西录 1 / 针灸 12）
> **归属**：经外奇穴

## 一、原文（《针灸大成》专条）
```
阳关： 阳陵泉上三寸，犊鼻外陷中。 《铜人》针五分，禁灸。 主风痹不仁，膝痛不可屈伸。
```

## 二、语料中的实际使用
《针灸大成》载12次，为该书腧穴条目。
另在《参西录》中出现1次，属临床配穴使用。

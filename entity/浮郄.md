# 浮郄

> **类型**：穴位
> **语料频次**：3 次（分布：— / — / — / — / 针灸 3）
> **归属**：经外奇穴

## 一、原文（《针灸大成》专条）
```
浮郄： 委阳上一寸，展膝得之。 《铜人》针五分，灸三壮。 主霍乱转筋，小肠热，大肠结，胫外筋急，髀枢不仁，小便热，大便坚。
```

## 二、语料中的实际使用
《针灸大成》载3次，为该书腧穴条目。

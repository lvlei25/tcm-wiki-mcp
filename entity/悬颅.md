# 悬颅

> **类型**：穴位
> **语料频次**：6 次（分布：— / — / — / — / 针灸 6）
> **归属**：足少阳胆经

## 一、原文（《针灸大成》专条）
```
悬颅： 曲周上，颞颥中廉。 手足少阳、阳明之会。 《铜人》灸三壮，针三分，留三呼。 《明堂》针二分，《素注》针七分，留七呼，刺深令人耳无所闻。 主头痛，牙齿痛，面肤赤肿，热病烦满，汗不出，头偏痛引目外眦赤，身热，鼻洞浊下不止，传为鼽，目昏瞢瞑目。
```

## 二、语料中的实际使用
《针灸大成》载6次，为该书腧穴条目。

# 玉枕

> **类型**：穴位
> **语料频次**：8 次（分布：— / — / — / — / 针灸 8）
> **归属**：足太阳膀胱经

## 一、原文（《针灸大成》专条）
```
玉枕： 络却后一寸五分，侠脑户旁一寸三分，起肉枕骨上，入发际二寸。 《铜人》灸三壮，针三分，留三呼。 主目痛如脱，不能远视，内连系急，头风痛不可忍。 鼻窒不闻。
```

## 二、语料中的实际使用
《针灸大成》载8次，为该书腧穴条目。

# 天枢

> **类型**：穴位
> **语料频次**：27 次（分布：— / — / — / — / 针灸 27）
> **归属**：足阳明胃经

## 一、原文（《针灸大成》专条）
```
◎天枢： 主内伤脾胃，赤白痢疾，脾泄及脐腹鼓胀，症瘕。
```

## 二、语料中的实际使用
《针灸大成》载27次，为该书腧穴条目。

  - **脏腑职司**（原文）：胃者，水谷之海，六腑之大原也
  - **循行与属性**：起头维，终厉兑，气血俱多，辰时注此
  - **是动病**：洒洒然振寒，善呻数欠，颜黑。病至恶人与火，闻木音则惕然而惊……甚则欲登高而歌，弃衣而走，贲响腹胀，是谓骭厥

### 作为配穴出现于

- **作为公孙、足临泣、外关、后溪、列缺、内关的配穴出现 20 次**（公孙 5 次，足临泣 3 次，外关 3 次，后溪 3 次，列缺 3 次，内关 3 次）
- 所治病症（去重后按主穴分列）：

  - 随公孙：脐腹胀满，食不消化；泄泻不止，里急后重；腹中肠痛，下利不已；赤白痢疾，腹中冷痛；腹中寒痛，泄泻不止

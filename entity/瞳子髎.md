# 瞳子髎

> **类型**：穴位
> **语料频次**：14 次（分布：— / — / — / — / 针灸 14）
> **归属**：足少阳胆经

## 一、原文（《针灸大成》专条）
```
瞳子髎，终窍阴。多气少血，子时注此。是动病：口苦，善太息，心胁痛，不能转侧，甚则面微有尘，体无膏泽，足外反热，是为阳厥。是主骨所生病：头角颔痛，目锐眦痛，缺盆中肿痛，腋下肿，马刀挟瘿，汗出振寒，疟，胸胁、肋、髀、膝外至胫绝骨、外踝前及诸节皆痛，小指次指不用。盛者，人迎大一倍于寸口。虚者，人迎反小于寸口也。补用丑时，侠溪，为荥水。水生木，虚则补其母。丘墟为原，皆取之。泻用子时，阳辅，为经火。木生火，实则泻其子。
```

## 二、语料中的实际使用
《针灸大成》载14次，为该书腧穴条目。

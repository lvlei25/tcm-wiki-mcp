# 少府

> **类型**：穴位
> **语料频次**：13 次（分布：— / — / — / — / 针灸 13）
> **归属**：手少阴心经

## 一、原文（《针灸大成》专条）
```
少府： 手小指本节后，骨缝陷中，直劳宫。 手少阴心脉所溜为荥火。 《铜人》针二分，灸七壮。 《明堂》灸三壮。 主烦满少气，悲恐畏人，掌中热，臂酸，肘腋挛急，胸中痛，手蜷不伸，痎疟久不愈，振寒，阴挺出，阴痒阴痛，遗尿偏坠，小便不利，太息。
```

## 二、语料中的实际使用
《针灸大成》载13次，为该书腧穴条目。

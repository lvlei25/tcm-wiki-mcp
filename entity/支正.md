# 支正

> **类型**：穴位
> **语料频次**：11 次（分布：— / — / — / — / 针灸 11）
> **归属**：手太阳小肠经

## 一、原文（《针灸大成》专条）
```
支正： 腕后五寸，手太阳络脉，别走少阴。 《铜人》针三分，灸三壮。 《明堂》灸五壮。 主风虚，惊恐悲愁，癫狂，五劳，四肢虚弱，肘臂挛难屈伸，手不握，十指尽痛，热痛先腰颈酸，喜渴，强项，疣目。 实则节弛肘废，泻之，虚则生疣小如指，痂疥，补之。
```

## 二、语料中的实际使用
《针灸大成》载11次，为该书腧穴条目。

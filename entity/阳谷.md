# 阳谷

> **类型**：穴位
> **语料频次**：36 次（分布：— / — / — / — / 针灸 36）
> **归属**：手太阳小肠经

## 一、原文（《针灸大成》专条）
```
阳谷： 手外侧腕中，锐骨下陷中。 手太阳小肠脉所行为经火。 《素注》灸三壮，针二分，留三呼。 《甲乙》留二呼。 主癫疾狂走，热病汗不出，胁痛，颈颔肿，寒热，耳聋耳鸣，齿龋痛，臂外侧痛不举，吐舌，戾颈，妄言，左右顾，目眩，小儿瘛疭，舌强不嗍乳。
```

## 二、语料中的实际使用
《针灸大成》载36次，为该书腧穴条目。

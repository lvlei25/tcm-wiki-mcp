# 筋缩

> **类型**：穴位
> **语料频次**：11 次（分布：— / — / 傅男 2 / 参西录 1 / 针灸 8）
> **归属**：督脉

## 一、原文（《针灸大成》专条）
```
筋缩： 九椎下，俯而取之。 《铜人》针五分，灸三壮。 《明下》灸七壮。 主癫疾狂走，脊急强，目转反戴，上视，目瞪，痫病多言，心痛。
```

## 二、语料中的实际使用
《针灸大成》载8次，为该书腧穴条目。
另在《傅男、参西录》中出现3次，属临床配穴使用。

# 八邪

> **类型**：穴位
> **语料频次**：8 次（分布：— / — / — / — / 针灸 8）
> **归属**：经外奇穴

## 一、原文（《针灸大成》专条）
```
◎八邪： 八穴。 在手五指歧骨间，左右手各四穴。
```

## 二、语料中的实际使用
《针灸大成》载8次，为该书腧穴条目。

## 五、治法与配穴关系

### 作为配穴出现于

- **作为公孙、后溪、内关、足临泣、外关的配穴出现 8 次**（公孙 2 次，后溪 2 次，内关 2 次，足临泣 1 次，外关 1 次）
- 所治病症（去重后按主穴分列）：

  - 随公孙：破伤风症；中风拘挛
  - 随足临泣：中风拘挛
  - 随外关：中风拘挛
  - 随后溪：破伤风症；中风拘挛
  - 随内关：破伤风症；中风拘挛

### 操作与禁忌

- **操作**：针一分　灸七壮

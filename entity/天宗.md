# 天宗

> **类型**：穴位
> **语料频次**：4 次（分布：— / — / — / 参西录 1 / 针灸 3）
> **归属**：手太阳小肠经

## 一、原文（《针灸大成》专条）
```
天宗： 秉风后大骨下陷中。 《铜人》灸三壮，针五分，留六呼。 主肩臂酸疼，肘外后廉痛，颊颔肿。
```

## 二、语料中的实际使用
《针灸大成》载3次，为该书腧穴条目。
另在《参西录》中出现1次，属临床配穴使用。

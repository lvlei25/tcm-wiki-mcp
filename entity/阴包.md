# 阴包

> **类型**：穴位
> **语料频次**：5 次（分布：— / — / — / — / 针灸 5）
> **归属**：足厥阴肝经

## 一、原文（《针灸大成》专条）
```
阴包： 膝上四寸，股内廉两筋间，蜷足取之。 看膝内侧，必有槽中。 《铜人》针六分，灸三壮。 《下经》针七分。 主腰尻引小腹痛，小便难，遗溺，妇人月水不调。
```

## 二、语料中的实际使用
《针灸大成》载5次，为该书腧穴条目。

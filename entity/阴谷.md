# 阴谷

> **类型**：穴位
> **语料频次**：30 次（分布：— / — / — / — / 针灸 30）
> **归属**：足少阴肾经

## 一、原文（《针灸大成》专条）
```
阴谷： 膝下内辅骨后，大筋下，小筋上，按之应手，屈膝乃得之。 足少阴肾脉所入为合水。 《铜人》针四分，留七呼，灸三壮。 主膝痛如锥，不得屈伸。 舌纵涎下，烦逆，溺难，小便急引阴痛，阴痿，股内廉痛，妇人漏下不止，腹胀满不得息，小便黄，男子如蛊，女子如娠。
```

## 二、语料中的实际使用
《针灸大成》载30次，为该书腧穴条目。

## 五、治法与配穴关系

### 作为配穴出现于

- **作为公孙、足临泣、外关、后溪、列缺、内关的配穴出现 13 次**（公孙 3 次，足临泣 2 次，外关 2 次，后溪 2 次，列缺 2 次，内关 2 次）
- 所治病症（去重后按主穴分列）：

  - 随公孙：谷疸，食毕则心眩，心中拂郁，遍体发黄；中暑自热，小便不利；小便淋血不止，阴器痛
  - 随足临泣：中暑自热，小便不利；小便淋血不止，阴器痛

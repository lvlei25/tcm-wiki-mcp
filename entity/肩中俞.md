# 肩中俞

> **类型**：穴位
> **语料频次**：3 次（分布：— / — / — / — / 针灸 3）
> **归属**：手太阳小肠经

## 一、原文（《针灸大成》专条）
```
肩中俞： 肩胛内廉，去脊二寸陷中。 《素注》针六分，灸三壮。 《铜人》针三分，留七呼，灸十壮。 主咳嗽，上气唾血，寒热，目视不明。
```

## 二、语料中的实际使用
《针灸大成》载3次，为该书腧穴条目。

# 客主人

> **类型**：穴位
> **语料频次**：7 次（分布：— / — / — / — / 针灸 7）
> **归属**：足少阳胆经

## 一、原文（《针灸大成》专条）
```
客主人内陷，中脉，为内漏耳聋；刺膝膑，出液为跛；刺臂太阴脉，出血多，立死；刺足少阴脉，重虚出血，为舌难以言；刺膺中陷，中肺，为喘逆仰息。刺肘中内陷，气归之，为不屈伸；刺阴股下三寸内陷，令人遗溺；刺腋下胁间内陷，令人咳；刺少腹，中膀胱，溺出，令人少腹满；刺腨肠内陷，为肿；刺眶上陷骨，中脉，为漏为盲；刺关节中，液出，不得屈伸。
```

## 二、语料中的实际使用
《针灸大成》载7次，为该书腧穴条目。

# 极泉

> **类型**：穴位
> **语料频次**：9 次（分布：— / — / — / — / 针灸 9）
> **归属**：手少阴心经

## 一、原文（《针灸大成》专条）
```
极泉： 臂内腋下筋间，动脉入胸。 《铜人》针三分，灸七壮。 主臂肘厥寒，四肢不收，心痛干呕，烦渴，目黄，胁满痛，悲愁不乐。
```

## 二、语料中的实际使用
《针灸大成》载9次，为该书腧穴条目。

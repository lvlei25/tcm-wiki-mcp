# Entity 文档规范

> 本目录存放**具体可指认的事物**：药物、方剂、穴位、经脉、古籍、医家。

## 命名
实体名.md，用正名（简体）。药物统一用正名，不用炮制变体——炮制信息写进正文。

## 必备结构

```markdown
# 实体名

> **类型**：药物 / 方剂 / 穴位 / 经脉 / 古籍 / 医家
> **语料频次**：N 次（分布：丁x / 傅女x / 傅男x / 参西录x / 针灸x）
> **别名**：语料中出现的炮制变体、简称

## 一、出处与身份
朝代、作者、文献位置（仅写语料中能查到的）。

## 二、原文证据
≥2 条原文，含**实际配伍/取穴/论述**的上下文，标出处。

## 三、语料中的用法
该实体在五部书中的实际使用方式。药物写常见配伍；穴位写主治；方剂写主治病证。

## 四、相关条目
`[[配伍过的药]]`、`[[同经穴]]`、`[[主治病证（concept）]]`
```

## 硬性要求

1. **别名列必须来自语料实测**（keywords.txt 药名区的炮制归一化记录）
2. 药物写清炮制差异是否影响功效论述
3. 穴位注明**所属经脉**与**语料中的主治症**
4. 方剂注明**原文所标主治**
5. 不确定的信息标注「语料未见」，不猜测

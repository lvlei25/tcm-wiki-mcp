# 委阳

> **类型**：穴位
> **语料频次**：6 次（分布：— / — / — / — / 针灸 6）
> **归属**：足太阳膀胱经

## 一、原文（《针灸大成》专条）
```
委阳： 承扶下一尺六寸，穴在足太阳之前，少阳之后，出于腘中外廉两筋间，三焦下辅俞，足太阳之别络。 《素注》针七分，留五呼，灸三壮。 主腋下肿痛，胸满膨膨，筋急身热。 飞尸遁疰，痿厥不仁。 小便淋沥。
```

## 二、语料中的实际使用
《针灸大成》载6次，为该书腧穴条目。

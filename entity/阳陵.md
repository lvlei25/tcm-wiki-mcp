# 阳陵

> **类型**：穴位
> **语料频次**：83 次（分布：— / — / — / — / 针灸 83）
> **归属**：经外奇穴

## 一、原文（《针灸大成》专条）
```
◎阳陵： 在膝下一寸，外廉陷中，外尖骨前。 针六分，灸七壮。
```

## 二、语料中的实际使用
《针灸大成》载83次，为该书腧穴条目。

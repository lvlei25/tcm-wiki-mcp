# 神庭

> **类型**：穴位
> **语料频次**：25 次（分布：— / — / — / — / 针灸 25）
> **归属**：经外奇穴

## 一、原文（《针灸大成》专条）
```
神庭： 直鼻上入发际五分。 足太阳、督脉之会。 《素注》灸三壮。 《铜人》灸二七壮，止七七壮。 禁针，针则发狂，目失睛。 主登高而歌，弃衣而走。 角弓反张，吐舌，癫疾风痫，目上视不识人，头风目眩，鼻出清涕不止，目泪出。 惊悸不得安寝，呕吐烦满。 寒热头痛，喘渴。
```

## 二、语料中的实际使用
《针灸大成》载25次，为该书腧穴条目。

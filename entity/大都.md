# 大都

> **类型**：穴位
> **语料频次**：32 次（分布：— / — / — / 参西录 4 / 针灸 28）
> **归属**：足太阴脾经

## 一、原文（《针灸大成》专条）
```
大都： 足大趾本节后，内侧陷中，骨缝赤白肉际。 脾脉所溜为荥火。 脾虚补之。 《铜人》针三分，灸三壮。 主热病汗不出，不得卧，身重骨疼，伤寒手足逆冷，腹满善呕，烦热闷乱，吐逆目眩，腰痛不可俯仰，绕踝风，胃心痛，腹胀胸满，心蛔痛，小儿客忤。
```

## 二、语料中的实际使用
《针灸大成》载28次，为该书腧穴条目。
另在《参西录》中出现4次，属临床配穴使用。

# 脑户

> **类型**：穴位
> **语料频次**：12 次（分布：— / — / — / — / 针灸 12）
> **归属**：督脉

## 一、原文（《针灸大成》专条）
```
脑户，入脑立死；刺舌下，中脉太过，血出不止为喑；刺足下布络，中脉，血不出为肿；刺郄，中大脉，令人仆脱色；刺气街，中脉，血不出，为肿鼠仆；刺脊间，中髓为伛；刺乳上，中乳房，为肿根蚀；刺缺盆中内陷，气泄，令人喘咳逆；刺手鱼腹内陷，为肿。
```

## 二、语料中的实际使用
《针灸大成》载12次，为该书腧穴条目。

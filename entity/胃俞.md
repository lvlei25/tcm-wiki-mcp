# 胃俞

> **类型**：穴位
> **语料频次**：28 次（分布：— / — / — / — / 针灸 28）
> **归属**：足太阳膀胱经

## 一、原文（《针灸大成》专条）
```
胃俞： 十二椎下两旁相去脊各一寸五分，正坐取之。 《铜人》针三分，留七呼，灸随年为壮。 《明堂》灸三壮。 《下经》灸七壮。 主霍乱，胃寒，腹胀而鸣，翻胃呕吐，不嗜食，多食羸瘦，目不明，腹痛，胸胁支满，脊痛筋挛，小儿羸瘦，不生肌肤。
```

## 二、语料中的实际使用
《针灸大成》载28次，为该书腧穴条目。

# 至阳

> **类型**：穴位
> **语料频次**：20 次（分布：— / 傅女 2 / — / 参西录 4 / 针灸 14）
> **归属**：督脉

## 一、原文（《针灸大成》专条）
```
至阳： 七椎下，俯而取之。 《铜人》针五分，灸三壮。 《明下》灸七壮。 主腰脊痛，胃中寒气，不能食，胸胁支满，身羸瘦，背中气上下行，腹中鸣，寒热解筩，淫泺胫酸，四肢重痛，少气难言，卒疰忤，攻心胸。
```

## 二、语料中的实际使用
《针灸大成》载14次，为该书腧穴条目。
另在《傅女、参西录》中出现6次，属临床配穴使用。

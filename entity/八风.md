# 八风

> **类型**：穴位
> **语料频次**：8 次（分布：— / — / — / — / 针灸 8）
> **归属**：经外奇穴

## 一、原文（《针灸大成》专条）
```
◎八风： 八穴，在足五趾歧骨间，两足共八穴，故名八风。 治脚背红肿，针一分，灸五壮。
```

## 二、语料中的实际使用
《针灸大成》载8次，为该书腧穴条目。

# 淋浊

> **类型**：病名
> **语料频次**：6 次（分布：丁 3 / — / — / 参西录 3 / —）
> **体系归属**：丁甘仁医案设专章

## 一、病名界定
小便病

## 二、语料中的分布特点
分布：丁甘仁 3、参西录 3。以《丁甘仁》为主（3 次）。

## 三、原文证据

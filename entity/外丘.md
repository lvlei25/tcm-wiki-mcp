# 外丘

> **类型**：穴位
> **语料频次**：4 次（分布：— / — / — / — / 针灸 4）
> **归属**：足少阳胆经

## 一、原文（《针灸大成》专条）
```
外丘： 外踝上七寸，少阳所生。 《铜人》针三分，灸三壮。 主胸胀满，肤痛痿痹，颈项痛，恶风寒，猘犬伤毒不出，发寒热，速以三壮艾，可灸所啮处，及足少阳络。 癫疾，小儿龟胸。 光明 外踝上五寸。 足少阳之络，别走厥阴。 《铜人》针六分，留七呼，灸五壮。 《明下》灸七壮。 主淫泺，胫酸胻疼，不能久立，热病汗不出，卒狂。 与阳辅疗法同，虚则痿躄，坐不能起，补之。 实则足胻热膝痛，身体不仁，善啮颊，泻之。
```

## 二、语料中的实际使用
《针灸大成》载4次，为该书腧穴条目。

# 阳池

> **类型**：穴位
> **语料频次**：31 次（分布：— / — / — / — / 针灸 31）
> **归属**：手少阳三焦经

## 一、原文（《针灸大成》专条）
```
◎阳池： 在手表腕上陷中。 针二分，禁灸。
```

## 二、语料中的实际使用
《针灸大成》载31次，为该书腧穴条目。

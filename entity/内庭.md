# 内庭

> **类型**：穴位
> **语料频次**：64 次（分布：— / 傅女 1 / — / — / 针灸 63）
> **归属**：足阳明胃经

## 一、原文（《针灸大成》专条）
```
内庭： 足大趾次趾外间陷中。 足阳明胃脉所溜为荥水。 《铜人》灸三壮，针三分，留十呼。 主四肢厥逆，腹胀满，数欠，恶闻人声，振寒，咽中引痛，口㖞，上齿龋，疟不嗜食，脑皮肤痛，鼻衄不止，伤寒手足逆冷，汗不出，赤白痢。
```

## 二、语料中的实际使用
《针灸大成》载63次，为该书腧穴条目。
另在《傅女》中出现1次，属临床配穴使用。

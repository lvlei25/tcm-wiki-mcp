# 公孙

> **类型**：穴位
> **语料频次**：62 次（分布：— / — / — / 参西录 3 / 针灸 59）
> **归属**：足太阴脾经

## 一、原文（《针灸大成》专条）
```
公孙： 足大趾本节后一寸，内踝前。 足太阴络脉，别走阳明胃经。 《铜人》针四分，灸三壮。 主寒疟，不嗜食，痫气，好太息，多寒热汗出，病至则喜呕，呕已乃衰。 头面肿起，烦心狂言，多饮，胆虚，厥气上逆则霍乱，实则肠中切痛泻之，虚则鼓胀补之。
```

## 二、语料中的实际使用
《针灸大成》载59次，为该书腧穴条目。
另在《参西录》中出现3次，属临床配穴使用。

## 五、治法与配穴关系

### 八脉八穴（主客配对）

> 《针灸大成·八法交会八穴歌》：「八法交会八穴歌 公孙冲脉胃心胸，内关阴维下总同，临泣胆经连带脉，阳维目锐外关逢，后溪督脉内眦颈，申脉阳𫏋络亦通，列缺任脉行肺系，阴𫏋照海膈喉咙。」

- **所属**：足太阴脾经，通冲脉；本穴为主穴
- **配穴**：**内关**（通阴维），主客相应
- **主治摘要**（原文）：九种心疼延闷，结胸翻胃难停，酒食积聚胃肠鸣，水食气疾膈病。脐痛腹疼胁胀，肠风疟疾心疼，胎衣不下血迷心，泄泻公孙立应

《八穴配合歌》：「八穴配合歌 公孙偏与内关合，列缺能消照海疴，临泣、外关分主客，后溪、申脉正相和。左针右病知高下，以意通经广按摩，补泻迎随分逆顺，五门八法是真科。」

要点：**「左针右病知高下」**——先取主穴，再视病位左右取配穴。

### 病症配穴（《针灸大成·八脉图并治症穴》）

共 135 条，节录如下（每条格式：病症 → 配穴）：

- 九种心疼，一切冷气 → 大陵、中脘、隐白
- 痰膈涎闷，胸中隐痛 → 劳宫、膻中、间使
- 气膈五噎，饮食不下 → 膻中、三里、太白
- 脐腹胀满，食不消化 → 天枢、水分、内庭
- 胁肋下痛，起止艰难 → 支沟、章门、阳陵泉
- 泄泻不止，里急后重 → 下脘、天枢、照海
- 胸中刺痛，隐隐不乐 → 内关、大陵、彧中
- 胃脘停痰，口吐清水 → 巨阙、中脘、厉兑
- 心疟，令人心内怔忡 → 神门、心俞、百劳
- 脾疟，令人怕寒腹痛 → 商丘、脾俞、三里
- 肺疟，令人心寒怕惊 → 列缺、肺俞、合谷
- 肾疟，令人洒热，腰脊强痛 → 大钟、肾俞、申脉
- 疟疾先寒后热 → 后溪、曲池、劳宫
- 疟疾心胸疼痛 → 内关、上脘、大陵

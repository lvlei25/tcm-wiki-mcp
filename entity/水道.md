# 水道

> **类型**：穴位
> **语料频次**：44 次（分布：丁 9 / 傅女 3 / — / 参西录 16 / 针灸 16）
> **归属**：足阳明胃经

## 一、原文（《针灸大成》专条）
```
水道： 大巨下三寸，去中行各二寸。 《铜人》灸五壮，针三分半。 《素注》针二分半。 主腰骨强急，膀胱有寒，三焦结热，妇人小腹胀满，痛引阴中，胞中瘕，子门寒，大小便不通。
```

## 二、语料中的实际使用
《针灸大成》载16次，为该书腧穴条目。
另在《丁甘仁、傅女、参西录》中出现28次，属临床配穴使用。

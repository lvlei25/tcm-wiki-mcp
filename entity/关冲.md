# 关冲

> **类型**：穴位
> **语料频次**：36 次（分布：— / — / — / 参西录 2 / 针灸 34）
> **归属**：手少阳三焦经

## 一、原文（《针灸大成》专条）
```
关冲： 手小指次指外侧，去爪甲角如韭叶。 手少阳三焦脉所出为井金。 《铜人》针一分，留三呼，灸一壮。 《素注》灸三壮。 主喉痹喉闭，舌卷口干，头痛，霍乱，胸中气噎，不嗜食，臂肘痛不可举，目生翳膜，视物不明。
```

## 二、语料中的实际使用
《针灸大成》载34次，为该书腧穴条目。
另在《参西录》中出现2次，属临床配穴使用。

# 神道

> **类型**：穴位
> **语料频次**：8 次（分布：— / — / — / — / 针灸 8）
> **归属**：督脉

## 一、原文（《针灸大成》专条）
```
神道： 五椎下，俯而取之。 《铜人》灸七七壮，止百壮，禁针。 《明下》灸三壮，针五分。 《千金》灸五壮。 主伤寒发热，头痛，进退往来，痎疟，恍惚，悲愁健忘，惊悸。 失欠、牙车蹉，张口不合。 小儿风瘑，瘛疭，可灸七壮。
```

## 二、语料中的实际使用
《针灸大成》载8次，为该书腧穴条目。

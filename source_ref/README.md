# source_ref —— 知识来源

>本目录存放**诊断知识的上游来源**：被引用的古籍、被援引的医家学派。
>
> **为什么单独成目录**：它们不是诊断实体。古籍不会出现在证候推理链里，
> 医家也不会被"诊断"出来——它们是**知识出处**，用于溯源与校勘。
>
> 诊断 agent 的推理链是：
> ```
> 症状（entity）
>   └─ 病机／证候（concept）← 辨证体系
>        └─ 治法（concept）
>             └─ 方剂（entity）
>                  └─ 药物（entity）
> ```
> 古籍与医家位于这条链**之外**，只作为「依据出处」被引用。

## 使用约定

-概念文档与实体文档中的「原文证据」段落会标注 `《书名》`，其对应文档在 `books/`
- 医家条目记录学派归属与学术倾向，用于理解某条理论的学派来源
- **不参与**症状→病机→治法→方药的推理链
